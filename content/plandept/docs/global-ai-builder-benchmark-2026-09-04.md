# 해외 AI 홈페이지 서비스 벤치마크 & 온스토리 차별화 전략

작성: 기술참모 · 2026-09-04 · 조사 기준일 2026-09-04
요청: 회장님 — "AI를 최대한 활용한 아이디어로 승부하는 브랜드 AI 홈페이지 제작 업체가 되고 싶다"

---

## 0. 세 줄 결론

1. **Polsia는 따라 할 모델이 아니라 반면교사입니다.** ARR 120억 원(약 $12M)을 벌지만 Trustpilot 1.8/5(79건 중 74%가 1점), 가입 첫 달 이탈률 약 50%, 만들어진 회사 중 **1달러라도 번 곳은 10%**입니다. "AI가 알아서 다 한다"는 약속이 지켜지지 않아서 생긴 평판입니다. 배울 것은 **자율 에이전트라는 그림**이고, 피할 것은 **사람 승인 없는 완전 자동화**입니다.
2. **SNS 자동 게시는 기술적으로 이미 다 나온 기능이고, 따라 하기 어렵지 않습니다.** 인스타그램·쓰레드·페이스북은 API 비용 0원, 다만 **Meta 앱 심사 6~8주**가 걸립니다(지금 신청해야 시연에 씁니다). X는 게시 건당 $0.015, **링크를 넣으면 $0.20(약 280원)** 으로 뜁니다. 진짜 어려운 곳은 따로 있습니다 — **네이버 블로그·스마트플레이스, 카카오 채널, 당근 비즈프로필은 API가 아예 없습니다.** 세계 어느 서비스도 여기엔 못 씁니다.
3. **온스토리가 이미 기획해 둔 "스토리 넛지"(화요일 카톡 → 사장님 음성 → AI가 글) 는 조사한 해외 20개 서비스 어디에도 없는 기능입니다.** 여기에 인스타·쓰레드 자동 발행을 붙이면 **"음성 한 번 → 홈페이지 + SNS 동시 게시"** 라는, 아임웹·카페24·홈온은 물론 Wix·GoDaddy에도 없는 조합이 만들어집니다. 이게 제가 추천하는 1순위 혁신 기능입니다.

### 회장님께 드리는 해석

Polsia가 유명해진 이유는 기능이 아니라 **"AI가 회사를 대신 운영한다"는 한 문장** 입니다. 그런데 그 약속을 못 지켜서 별점이 1.8입니다. 특히 **"허락 없이 고객에게 메일을 보냈다"** 는 불만이 반복됩니다.

여기서 온스토리가 가져갈 교훈은 명확합니다.

- **가져올 것**: 한 문장으로 설명되는 자율 에이전트 컨셉, "사장님이 자는 동안에도 가게가 알려진다"는 이야기.
- **버릴 것**: 사람 승인 없는 자동 발행. 조사해 보니 **Wix·GoDaddy·Shopify 등 대형 업체는 전부 "승인 게이트"를 둡니다.** Wix의 마케팅 에이전트 Kleo 도움말에는 "**절대 대신 게시하지 않고 항상 승인을 요청한다**"고 명시돼 있습니다. 우리도 반드시 사장님이 "응" 한 번 눌러야 나가게 설계해야 합니다. 이건 제약이 아니라 **신뢰 장치**이고, Polsia와 우리를 가르는 지점입니다.

> AI가 글과 사진을 다 만들어 놓고 → 카톡으로 "이거 그대로 올리시면 됩니다" + **복사 버튼 + 네이버/당근 앱 바로 열기 링크** → 사장님은 붙여넣기 한 번.

## 6. 제 추천 — "말하면 알아서 알려지는 홈페이지"

### 6-1. 1순위: **A — 원소스 멀티포스트 (스토리 넛지의 확장)**

이미 확정된 스토리 넛지(화요일 12시 카톡 → 사장님이 음성 녹음 → AI가 3~5문장으로 정리 → 사이트 게시)에 **딱 한 단계만 더 붙입니다.**

```
[화요일 12시] 카톡: "이번 주 어떤 일 하셨어요? 눌러서 말씀만 해주세요"
        ↓ (사장님 음성 30초 + 사진 3장)
[AI]  ├─ 홈페이지 스토리 글      (3~5문장, 150~300자)
      ├─ 인스타 캡션 + 해시태그   (사진 자동 정사각 크롭)
      ├─ 쓰레드 글               (짧게)
      └─ 네이버 블로그 초안       (길게, 복사용)
        ↓
[카톡] "이렇게 나갑니다. 확인하시고 [게시] 눌러주세요"  ← ★ 승인 게이트
        ↓
홈페이지 + 인스타 + 쓰레드 동시 게시 / 네이버는 복사 + 앱 열기
```

**왜 이게 이기는가**

1. **세계에 없습니다.** Wix·GoDaddy는 SNS 게시는 되지만 **음성 입력이 없고**, 홈페이지 글과 SNS 글이 따로 놉니다. Durable·BASE·凡科는 글만 만들고 발행은 수동입니다. **"카톡으로 말 한 번 → 4곳 동시"는 조사한 20개 중 0곳입니다.**
2. **국내엔 더 없습니다.** 아임웹·카페24·홈온은 SNS 자동 게시 자체가 없습니다.
3. **한국 사장님 현실에 맞습니다.** 50~60대 인테리어 사장님이 노트북 앞에 앉아 블로그를 쓰지 않습니다. 하지만 **카톡 음성은 매일 씁니다.**
4. **한 문장으로 팔립니다.** — **"말만 하세요. 홈페이지도 인스타도 알아서 올라갑니다."**
5. **이미 8할이 기획돼 있습니다.** N1~N4 세션이 그대로 살아 있고, 추가되는 건 Meta API 연동 한 덩어리입니다.

**해야 할 일 / 순서**

| 단계 | 내용 | 소요 | 누가 |
|---|---|---|---|
| 0 | **Meta 개발자 앱 생성 + 사업자 인증 서류 제출** | **오늘 시작 → 6~8주 대기** | 회장님(서류) + 클코팀장(앱) |
| 1 | 스토리 넛지 N1~N4 (기존 계획대로) | 기존 일정 | 클코팀장 |
| 2 | AI 다중 출력(사이트/인스타/쓰레드/블로그 4종 동시 생성) | 세션 1개 | 클코팀장 |
| 3 | 인스타·쓰레드 계정 연결 UI + 발행 API | 세션 2개 | 클코팀장 |
| 4 | 승인 게이트(카톡 확인 → 게시) | 세션 1개 | 클코팀장 |

**0번이 제일 중요합니다.** 심사가 6~8주라, 지금 신청하지 않으면 위젯·시연이 다 끝나고도 이 기능을 못 켭니다. **오늘 시작하면 10월 말~11월 초에 열립니다.**

### 6-2. 2순위: **B — AI 검색 노출 (반나절짜리인데 이야기가 큽니다)**

회장님과 논의 중인 "검색 노출을 결제 후로 할까" 문제와 직접 연결됩니다. 네이버 검색 노출은 우리가 통제할 수 없지만, **ChatGPT·제미나이·퍼플렉시티가 우리 손님 가게를 추천하게 만드는 것**은 기술적으로 통제 가능합니다.

- 각 사이트에 `llms.txt` 자동 생성 (AI 크롤러용 요약 파일)
- 구조화 데이터(JSON-LD: LocalBusiness, 영업시간, 지역, 서비스, 리뷰) 자동 삽입
- 스토리 글에서 자주 나오는 질문을 뽑아 FAQ 자동 생성
- 대시보드에 "**AI 검색 노출 점수**" 표시

**세일즈 문구**: "네이버에만 나오는 홈페이지는 이제 반쪽입니다. 온스토리는 **ChatGPT가 사장님 가게를 추천하도록** 만듭니다."

Squarespace가 이걸 유료 상품으로 팔고 있고, **국내엔 아직 아무도 안 합니다.** 구현은 반나절~하루입니다.

### 6-3. 3순위: **E — 사이트 건강검진 (완성도 문제의 정면 해결)**

회장님이 "디자인이 너무 허접해서 49,000원 낼 고객이 있을지 의문"이라고 하셨는데, 제가 실제 5개 사이트를 확인한 결과 **디자인보다 빈칸이 문제**였습니다("안내 문구를 입력해 주세요", 가격이 `500000`으로 그대로 노출, 테스트 문구 방치).

- 편집기 상단에 **"이 사이트 완성도 62점"** 표시
- "사진 없는 섹션 3개 / 빈 문구 2곳 / 전화번호 미입력" 체크리스트
- 한 항목 채울 때마다 점수 상승 → **90점 넘으면 "검색 노출 켜기" 버튼 활성화**

이러면 §5의 완성도 게이트 논의도 자동으로 해결되고, **AI가 잔소리하는 게 아니라 도와주는 느낌**이 됩니다.
