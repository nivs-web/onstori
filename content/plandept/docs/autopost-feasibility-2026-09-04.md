## 1. "이미 구현한 사이트 있으면 들어가보고 싶어"

**결론부터: 음성 한 번으로 홈페이지 + 인스타 + 쓰레드를 동시에 올리는 서비스는 없습니다.** 시장이 정확히 두 조각으로 갈라져 있고 가운데가 비어 있습니다.

### 회장님이 오늘 직접 들어가 보실 곳

**① 자동 발행까지 되는데 음성이 없는 쪽**

- **Blaze Autopilot** — https://www.blaze.ai/ai-marketing-agent
  홈페이지 주소만 넣으면 사이트를 읽어 전략·브랜드를 세우고 소셜 10개 채널 + 블로그 + 뉴스레터에 **자동으로 올립니다.** 우리가 만들려는 것에서 음성 입력 하나만 빠진 물건입니다. **무료 체험이 있고 카드도 안 넣습니다 — 30분이면 직접 확인 가능합니다.**
- **Predis.ai** — https://predis.ai/auto-post/
  AI가 만들고 예약대로 자동 게시. **검토 모드와 완전 자율 모드를 고를 수 있습니다.** 월 $40(첫해 할인가), 자동 발행 월 60건. 쓰레드는 지원 안 합니다.
- **Mirra (미리내 AI, 한국)** — https://www.mirra.my/ko
  국내 업체이고 **쓰레드·인스타·유튜브·X·틱톡·링크드인**을 지원합니다. 승인한 콘텐츠를 예약 발행하는 방식. 무료 50크레딧, $19~$199/월. **한국 경쟁자 중 가장 가까운 물건이니 꼭 보십시오.**

**② 홈페이지 → SNS 자동 연동이 실제로 되는 유일한 검증품**

- **Blog2Social** (워드프레스 플러그인, 독일) — https://wordpress.org/plugins/blog2social/
  **사이트에 글을 올리면 25개 네트워크(인스타그램·쓰레드·페이스북·구글비즈니스 포함)에 자동 게시**됩니다. **5만+ 설치, 별점 4.5/5(리뷰 2,097개).** 이 카테고리에서 유일하게 검증된 물건입니다.
  → 우리가 만들려는 기능이 기술적으로 가능하다는 **가장 확실한 증거**입니다. 이미 5만 곳이 쓰고 있습니다.

**③ 음성은 되는데 발행이 안 되는 쪽 (전부 "복사해서 붙여넣기"에서 끝남)**

- **Clipsy** — https://goclipsy.com/ — 음성 메모 → **쓰레드 포함 7개 플랫폼 문안**. 무료 5회.
- **AudioPen** — https://audiopen.ai — 음성을 다듬어진 글로. 20만+ 사용자.
- **TalkNotes** — https://talknotes.io — 음성 → 100여 종 출력 포맷.

**④ 네이버 블로그 자동 포스팅 (한국)**

- **가제트(Gazet)** — https://gazet.ai/ — ㈜위노보스. 30초에 1,500자 글 생성 + **네이버 블로그 자동 포스팅**. 월 19,800원~, 14일 체험.

### 그래서 빈 자리가 어디인가

> **음성 입력 + 홈페이지 발행 + 인스타/쓰레드 동시 게시를 하나로 묶은 한국어 제품은 조사 범위에서 발견되지 않았습니다.**

Blaze는 음성이 없고, Clipsy는 발행이 없고, Blog2Social은 워드프레스를 깔 줄 알아야 하고, Mirra는 홈페이지가 없습니다. **그 넷을 하나로 합친 게 온스토리입니다.**

## 2. 인스타·쓰레드 진짜 무료인가 (Meta 공식 문서 직접 확인)

### 판정: **예, 진짜 무료입니다.**

- Meta 공식 문서 어디에도 Instagram Content Publishing / Threads 발행에 대한 **호출당 과금·구독료·유료 티어가 없습니다.** 가격 섹션 자체가 존재하지 않습니다.
- 접근 등급(Standard → Advanced)은 **돈이 아니라 심사로** 올라갑니다. 유료 업그레이드 경로가 아닙니다.
- 대조군: Meta가 실제로 돈을 받는 건 **WhatsApp Business** 하나입니다(2025-07부터 메시지 단위 과금).

### "추후 유료화 될 수 있지 않아?" — 신호는 없고, 오히려 반대입니다

- **2026-04-23, Meta는 서드파티 관리 툴 대상 Instagram API를 무상으로 확대했습니다** (파트너십 광고 라벨을 발행 시점에 붙이기, Reels 지표 추가, API로 좋아요). 과금 언급 전혀 없음.
- X가 유료로 간 이유는 **읽기(데이터 판매, LLM 학습용)** 때문이었습니다. 우리가 쓰는 건 **쓰기(발행)** 이고, Meta 입장에서 이건 자기 플랫폼에 콘텐츠를 공급해 주는 도구라 과금할 유인이 약합니다.
- ⚠ 주의: 2026년 5월 Meta가 발표한 유료 구독(Instagram Plus $3.99 등)은 **소비자 대상이지 개발자 API와 무관**합니다. 기사만 보면 "Meta가 유료화했다"로 오독하기 쉽습니다.

**단, "영원히 무료"는 보장 못 합니다.** 사업계획에 "API 유료화 시 원가 전가" 조항 한 줄은 넣어두는 게 맞습니다.

### 진짜 비용은 돈이 아니라 여기 있습니다 ⚠

**연 1회 DPA(Data Protection Assessment, 개인정보 보호 평가)를 통보받고 60일 안에 완료하지 못하면 플랫폼 접근을 잃습니다.** 답변이 "불완전하거나 모호해도" 잃습니다. 알림은 앱 관리자 이메일로만 옵니다.

> **놓치면 전 고객의 SNS 자동 게시가 한꺼번에 멈춥니다.** 이게 이 사업의 최대 단일 운영 리스크입니다. 캘린더에 못 박아 관리해야 합니다.

같은 성격으로 **Data Use Checkup(연 1회)** 도 있습니다.

### 규모가 커지면 한도에 걸리나? → **안 걸립니다**

Instagram 한도는 앱 전체 총량이 아니라 **"앱 × 계정" 쌍마다** 따로 계산됩니다(계정당 최소 48,000 호출/24h). **고객이 늘면 한도도 같이 늘어납니다.** 100명이든 1,000명이든 천장이 없습니다.

발행 한도는 계정당 **인스타 100건/24시간, 쓰레드 250건/24시간**.

### 구현 시 함정 (클코팀장에게 넘길 때 반드시 포함)

- **이미지는 JPEG만 됩니다.** PNG·WebP·HEIC 전부 거부. 최대 8MB.
- **종횡비 4:5 ~ 1.91:1.** 안전 기본값은 **4:5 (1080×1350)**. (인스타 앱은 2025년 3:4로 갔지만 공식 API 문서는 여전히 4:5 하한이라 실측 전엔 4:5 고정)
- 스토리·릴스도 API로 발행 가능. `alt_text`는 이미지에만 됩니다.
- 토큰 60일 만료 → 갱신 크론 필수.

## 3. "글도 매일 여러 개 올리게 열어주자"

### 채널마다 답이 다릅니다

| 채널 | 권고 | 이유 |
|---|---|---|
| **홈페이지 스토리** | **무제한으로 여십시오** | 내 사이트라 제재가 없습니다. 많이 쌓일수록 락인도 SEO도 강해집니다 |
| **인스타·쓰레드** | 하루 1~2건 상한 | 한도(100/250)는 여유롭지만 **다계정 동일 콘텐츠 살포가 Meta 스팸 판정 사유**입니다 |
| **네이버 블로그** | **하루 1개 상한** | 아래 5장. 같은 날 5개 이상 발행은 업계에서 위험 신호로 봅니다 |

### ⚠ 반드시 넣어야 할 안전장치 — 이게 제일 중요합니다

Meta 개발자 정책은 **"높은 빈도로 봇을 만들어 돌리는 것"** 을 명시적으로 금지하고, 위반 앱은 **기능 제한 → 일시중지 → 플랫폼 제거**까지 갑니다. 네이버는 같은 문장이 여러 블로그에 퍼지면 **원본 1개만 남기고 나머지를 복사글로 처리**합니다.

우리가 템플릿 문장(인사말·맺음말 같은 상용구)을 써서 100명 사장님에게 뿌리면, **양쪽에서 동시에 걸립니다.**

**설계 4줄:**

1. 상용구·정형 문장을 **아예 만들지 않는다** (인사말/맺음말 템플릿 금지)
2. 발행 전 **문장 단위 중복 검사(n-gram)** — 다른 고객 글과 겹치면 재생성
3. 계정 간 **발행 시각을 흩뿌린다**(지터). 정각 동시 발행 금지
4. 계정별 일일 상한을 Meta 한도보다 **훨씬 낮게** 자체 설정

> 경쟁사가 "하루 수십 개"를 팔 때 우리는 **"계정을 태우지 않는 속도"** 를 팝니다. 이게 오히려 상품이 됩니다.

## 4. "요일 설정하면 자동으로 메시지 날아오게" — 지금 당장 됩니다

| 방법 | 요일 자유 설정 | 반복 | 상태 |
|---|---|---|---|
| **문자(솔라피)** | **O** | **O** | **이미 라이브** — G2에서 연결 완료(sms:true) |
| 카톡 개인 1:1 예약 | O | **X (반복 불가, 월 4개 수동)** | 회장님 손이 감 |
| 알림톡 | O | O | 사업자등록·채널·템플릿 심사 필요 |

**회장님 아이디어대로 "요일 선택 → 자동 발송 → 대시보드에서 거절 → 매일 알림 옵션"은 문자로 지금 만들 수 있습니다.** 카톡을 고집하면 반복 예약이 안 돼서 매달 회장님이 손으로 넣어야 합니다.

**권고 순서**: ①문자로 먼저 자동화(요일·시각·빈도 설정 UI) → ②사업자등록 나오면 알림톡으로 이관(비용 4.8원/건, 카톡으로 도착) → ③카톡 개인 발송은 초기 5~10명 수작업 때만.

설정 화면에 넣을 것: 요일 선택 / 시각 / **빈도(주 1회·주 2회·매일)** / **"이번 주 건너뛰기"** / 3회 무응답 시 자동 완화.

## 5. 네이버 블로그 복붙 메뉴 — 저품질 걸리나

### 네이버 공식 입장 (검색 공식블로그, 2024)

> **"좋은 문서라면 문서 생성 방식과 관계없이 검색에 노출이 가능합니다"**

**AI로 썼다는 사실 자체는 저품질 사유가 아닙니다.** 네이버 자신이 2023년에 블로그용 AI 작문 도구('클로바 for Writing')를 창작자에게 공급했습니다.

### 네이버가 실제로 제외하는 것

1. 타 문서 단순 복사
2. 유사 키워드 반복 삽입
3. 문맥이 안 이어지는 자동 생성 콘텐츠
4. **AI로 같은 내용의 글을 반복적으로 대량 업로드**
5. 기존 콘텐츠 조합·변형

### 우리에게 실제로 위험한 것 (순위대로)

| 위험 | 크기 | 설명 |
|---|---|---|
| **중복·유사 문서** | **매우 높음** | 같은 템플릿 문장이 여러 사장님 블로그에 → 원본 빼고 전부 복사글 처리. **AI 여부보다 압도적으로 큰 위험** |
| 대량 발행 | 높음 | 하루 5개 이상 = 위험 신호(업계 통설) |
| 짧고 정보 없는 글 | 높음 | 300자 미만 반복 |
| 키워드 반복 | 높음 | 웹마스터 가이드 스팸 항목 명시 |
| 사진 없음·펌 사진 | 중간~높음 | 직접 촬영 원본 권장(업계 통설, 네이버 공식 확인은 없음) |
| **AI가 썼다는 사실** | **낮음** | 공식적으로 무관 |

### 그래서 이렇게 설계합니다 — "완성 원고"가 아니라 "빈칸 있는 뼈대"

AI가 제목 후보·소제목·FAQ 틀·체크리스트를 만들고, **본문 핵심 문단은 사장님 음성 내용으로만 채웁니다.** 사장님이 실제로 한 말이 들어가면 네이버가 요구하는 '솔직한 경험'과 '독창성'이 구조적으로 충족되고, 동시에 고객 간 중복이 원천 차단됩니다.

**복붙 메뉴는 이렇게:**

- 글 복사 / 사진 복사 버튼 + **"이 순서대로 하세요" 3단계 안내**
- **사진 3장 이상 업로드 안 하면 복사 버튼 비활성화** (직접 찍은 사진 강제)
- **하루 1개 상한** — "오늘은 이미 올리셨어요, 내일 하세요"
- 온보딩에 한 줄 고지: *"AI 초안 사용 자체는 네이버 정책 위반이 아니지만, 손대지 않고 그대로 올리면 어뷰징으로 분류될 수 있습니다."* → 책임 소재를 분명히
- ⚠ **EXIF 어쩌고는 마케팅 문구로 쓰지 마십시오.** 근거가 없습니다.

### 2026년 네이버의 진짜 변화 — 이게 더 중요합니다

- **AI 브리핑이 검색 쿼리의 약 20%를 처리**합니다(2026-06 AI탭 정식 출시).
- 네이버는 2026년 6월 **'네이버 메이트'** 를 시작해 **"AI 브리핑에 얼마나 자주 인용됐는지"** 를 기준으로 매달 약 3,000명에게 월 30만~1,000만 원을 지급합니다(연 200억 규모).

> **블로그의 평가 기준이 "검색 순위"에서 "AI가 인용할 가치"로 옮겨갔습니다.** 그래서 우리 AI는 **FAQ·비교표·체크리스트·구체적 수치**가 들어간 구조로 글을 써야 합니다. 이건 §6-2의 GEO 아이디어와 정확히 같은 방향입니다.

### 국내 경쟁자들이 이걸 어떻게 다루나 → 아무도 책임 안 집니다

- 블로그 팩토리(189~409만 원 영구 라이선스), Mublo(110만 원), 에이블로 등 전부 **"가이드라인 준수 권장"** 수준이고 계약상 보증은 없습니다.
- 특히 에이블로는 *"계정 없이 AI가 여러 블로그에 자동 배포"* 라 **유사문서 위험이 구조적으로 최상**입니다.

> **여기가 우리 차별점입니다. "저품질 안 나게 설계된 유일한 서비스"** 로 포지셔닝할 수 있습니다.

### 지역 업종이면 순서를 바꾸십시오

2026년 네이버 플레이스 순위는 정보 입력이 아니라 **행동 신호**(저장·예약·문의·리뷰의 양과 최신성·재방문)로 결정됩니다. 인테리어·수리 사장님에게는 **①스마트플레이스(리뷰) → ②블로그(경험 콘텐츠)** 순서가 맞습니다. 블로그는 "순위용"이 아니라 **"AI 브리핑에 인용될 경험 자산"** 으로 팔아야 합니다.

## 6. "인스타·쓰레드 없으면 Polsia처럼 자동 생성 되게"

### 판정: **불가능합니다. 시도하면 앱이 통째로 잘립니다.**

- **API가 없습니다.** Instagram Platform·Threads API 전체에 계정 생성 엔드포인트가 존재하지 않습니다.
- **약관이 명시적으로 금지합니다.** Instagram 이용약관 원문:
  > "This includes creating accounts or collecting information in an **automated way** without our express permission."
  > "you can't create an account for someone else **unless you have their express permission**."
- **Meta Platform Terms §6.a.iii**: 개발자는 사용자의 **로그인 자격증명을 별도로 요청·수집해서는 안 됩니다.** → 사장님 ID/PW를 받아 대신 가입시키는 방식도 여기서 막힙니다.
- 제재: 앱 **플랫폼 제거** + 생성 계정 일괄 비활성화 + 개발자 계정 제재.
- 화이트라벨/파트너 프로그램으로 우회하는 길도 **없습니다.** Meta가 지원하는 유일한 멀티테넌트 방식은 **Facebook Login for Business + 자산 위임(OAuth)** 입니다.
- **쓰레드는 인스타 계정이 있어야 합니다**(일부 EU에서 분리 가입 테스트 중이나 전면 롤아웃 아님). 설계는 "인스타 필수" 전제로.

### 그럼 계정 없는 사장님은?

**3분짜리 온보딩 위저드**를 만듭니다. 이건 오히려 우리 상품이 됩니다.

```
1) 인스타 앱 → 프로필 → 설정 → "프로페셔널 계정으로 전환"  (화면 캡처 3장)
2) 온스토리에서 [인스타 연결] 누르기 → 로그인 → 권한 허용
3) 끝. 다음 주 화요일부터 자동으로 올라갑니다.
```

50~60대 사장님에게 "프로페셔널 계정 전환"은 혼자선 어려운 일입니다. **이걸 손잡고 끝내주는 것 자체가 49,000원의 가치**입니다.

## 7. "2주 매일 글 쌓이면 못 버리고 결제하지 않을까"

### 전략적으로 맞습니다. 이게 교과서적인 전환율 설계입니다.

무료체험(free trial)의 유료 전환율 벤치마크는 **양호 8~12% / 우수 15~25%** 입니다(B2B SaaS 1,000곳 이상 조사). 프리미엄(freemium)은 3~8%로 훨씬 낮습니다. **체험 방식이 프리미엄보다 2~3배 유리합니다.**

그리고 락인의 원천은 **"내가 만든 것"** 입니다. 2주간 사장님이 자기 목소리로 10~14개 이야기를 쌓았다면, 그건 템플릿 홈페이지가 아니라 **사장님의 기록**이 됩니다. 이걸 버리는 건 심리적으로 어렵습니다.

### 다만 조건이 셋 있습니다

1. **매일 쓰게 만들려면 매일 물어봐야 합니다.** 주 1회 넛지로는 2주에 2개밖에 안 쌓입니다. → **체험 기간에는 "매일 알림" 기본값**, 결제 후 사장님이 주 1회로 낮추는 구조가 맞습니다. (회장님 말씀대로 대시보드에서 조절)
2. **첫 글이 3분 안에 올라가야 합니다.** 첫날 한 번도 못 올리면 2주 내내 안 씁니다.
3. **버리기 아깝게 만들되, 인질로 잡으면 안 됩니다.** 결제 안 하면 삭제는 이미 정하셨는데, **삭제 전에 "내 글 전부 내려받기(PDF·텍스트)" 버튼**을 반드시 주십시오. 이게 없으면 나쁜 후기가 남습니다. 있어도 대부분은 안 누르고 결제합니다.

### 체험 기간 재권고: **7일 → 14일**

회장님이 7일로 정하셨지만, **2주 매일 쓰기 전략과 7일은 서로 모순**입니다. 7일이면 최대 7개, 그나마 첫 이틀은 세팅하다 갑니다. **14일이면 10~14개**가 쌓이고, 이게 "버리기 아까운" 임계점입니다. 홈온은 24시간, 가제트는 14일, Predis는 7일입니다.

## 8. 하단 유료 전환 바 — 업계 표준입니다

### 다른 곳은 이렇게 합니다

| 빌더 | 위치 | 형태 | 제거 조건 |
|---|---|---|---|
| **Wix** | 상단 배너 | 사이트 상단 띠 + 푸터 "Proudly Created With Wix" | 유료 플랜 |
| **Jimdo** | 푸터 + 임프린트 | Jimdo 광고 + `*.jimdofree.com` 도메인 | 유료 + 자체 도메인 |
| **Webador** | 하단 | 광고. **사이트 색상에 맞춰 자동 변색** | Pro 이상(Lite도 광고 있음) |
| **Squarespace** | 선택 배지 | "Powered By Squarespace" — **강제 아님, 원하는 사람만** | — |
| **아임웹** | 하단 배너 | 숨기기 FAQ 문서 존재 | 미확인 |

**Webador의 "색상 자동 매칭"이 가장 영리합니다** — 거슬리게는 하되 사이트를 망치지는 않습니다.

### ⚠ 그런데 회장님 첨부 화면은 두 가지가 섞여 있습니다

보내주신 이미지(🎉 이제 고객에게 보여줄 차례입니다 / 체험 종료까지 23시간 57분 / [수정하기 미리 체험하기] [활성화하기])는 **사장님에게만 보이는 관리 화면 바**입니다. 손님이 보는 홈페이지 하단 광고와는 다른 물건입니다.

**저는 이렇게 나누기를 권합니다.**

| 어디 | 무엇을 | 왜 |
|---|---|---|
| **사장님 화면**(편집·미리보기) | **크고 분명하게** — 카운트다운 + [지금 활성화] + 오늘의 혜택 | 압박은 사장님에게만 유효합니다 |
| **손님이 보는 사이트** | **작은 배지 하나** ("온스토리로 만든 홈페이지") | 크게 걸면 사장님이 **주소를 아무에게도 안 뿌립니다** |

**이유가 중요합니다.** 회장님 의도는 "기능 테스트만 하게 하고 실제 운영은 못 하게"인데, **그러면 락인이 안 생깁니다.** 락인은 "내 사이트를 손님에게 보여줬고 문의가 왔다"는 경험에서 나옵니다. 손님용 화면을 광고로 도배하면 사장님이 주소를 안 뿌리고 → 문의가 0건이고 → **결제할 이유가 사라집니다.**

체험 중 P5 진입 조건이 "문의가 실제로 왔다"인 걸 기억하시면, 손님 화면은 **깨끗하게 두는 쪽이 돈이 됩니다.**

### 효과 근거는 솔직히 말씀드리면 약합니다

"하단 배너가 전환율을 몇 % 올린다"는 통제된 데이터는 공개된 게 없습니다. 근거는 두 가지뿐입니다.

- **업계 전체가 예외 없이 하고 있다**는 사실 자체
- **Mailchimp 사례**: 2009년 프리미엄 전환 때 무료 사용자 이메일 푸터에 배지를 넣고 추천 보상($30)을 붙여 1년 만에 사용자 8.5만 → 45만, 유료 +150%, 이익 +650%. 단 배지만의 기여를 분리한 수치는 아닙니다.

**반대 근거도 있습니다**: Squarespace는 강제 배지를 버리고 **자발적 옵션**으로 돌렸습니다. 브랜드 비용이 효과를 정당화하지 못했을 가능성입니다.

→ 배지를 **압박 장치**가 아니라 **유입 채널**(손님이 배지를 보고 온스토리로 들어옴)로 설계하고, 시연 때 A/B로 확인하십시오.

### 회장님이 꼭 기억하실 한 가지

우리는 토큰비가 매출의 0.4%라 **안 잘라도 됩니다.** 이건 흉내낼 수 없는 차별점입니다 — 저들은 원가 구조상 못 하는 게 아니라 **이미 그렇게 팔아버려서** 못 바꿉니다.
