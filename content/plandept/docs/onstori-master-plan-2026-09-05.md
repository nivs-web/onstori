# 1장. 멘트 확정

## 1-1. 확정 — 히어로

> ## 홈페이지는 텅 빈 상가입니다.
> ## 스토리에는 진짜 사람이 있습니다.
>
> 사장님이 들려주시는 스토리가
> 사업을 굴러가게 만듭니다.
>
> **온스토리.**

**참모 의견: 이게 지금까지 나온 것 중 제일 좋습니다.** 이유가 셋입니다.

1. **경쟁을 한 문장에서 끝냅니다.** 재밋·홈온·아임웹이 파는 것을 «텅 빈 상가»라고 부르는 순간, 그들과 가격으로 비교되지 않습니다. 비교 자체가 성립하지 않습니다.
2. **«진짜 사람»이 우리 방어선입니다.** AI가 만든 홈페이지는 이제 3분이면 나옵니다. 그런데 사장님이 20년간 겪은 이야기는 AI가 못 만듭니다. 우리가 파는 게 «못 만드는 것»이라고 선언하는 문장입니다.
3. **소상공인에게 «상가»는 몸으로 아는 단어입니다.** 빈 상가 앞을 지나본 사람, 빈 가게에서 손님을 기다려 본 사람에게 이 비유는 설명이 필요 없습니다.

## 1-2. 확정 — 서브서브 4개 (히어로 아래 한 줄씩)

사업을 이해시키는 순서로 배열합니다. **무엇을 → 어떻게 → 걱정 없애기 → 왜 지금**.

| 순서 | 문구 | 역할 |
|---|---|---|
| ① | **사장님은 60초만 말하세요. 나머지 다섯 곳은 저희가 채웁니다.** | 무엇을 해주는가 |
| ② | **질문은 저희가 드립니다. 사장님은 대답만 하세요.** | 어떻게 쉬운가 |
| ③ | **얼굴 안 나와도 됩니다. 목소리 60초면 유튜브 사장님입니다.** | 제일 큰 걱정 제거 |
| ④ | **3년 뒤에도 검색되는 영상. 오늘 한 편이면 시작입니다.** | 왜 지금 해야 하는가 |

## 1-3. 보관 — 나머지 멘트 전부

나중에 랜딩 하위 섹션·문자 메시지·명함·전단·광고 소재로 씁니다.

**방향 A — 사업이 굴러갑니다**

- 홈페이지를 만들어 드리지 않습니다. 사장님 사업이 굴러가게 만듭니다.
- 말할 줄 아시면, 마케팅하실 수 있습니다.
- 오늘 60초. 다섯 곳이 한꺼번에 채워집니다.
- 광고비 대신 목소리로. 하루 60초면 됩니다.
- 사장님 목소리 60초가, 다섯 곳의 콘텐츠가 됩니다.

**방향 B — 먼저 올린 사람이 가져갑니다**

- 유튜브는 먼저 올린 가게가 가져갑니다. 사장님 업종, 아직 비어 있습니다.
- 내 사업으로 유튜브, 언제까지 미루실 건가요.
- 옆 가게가 시작하기 전에. 오늘 60초.

**방향 C — 신뢰·기록 (이번에 새로 뽑은 것)**

- 텅 빈 홈페이지에는 아무도 전화하지 않습니다.
- 사장님이 20년 쌓은 이야기, 아직 아무 데도 없습니다.
- 남의 사진 말고 사장님 손이 나오는 홈페이지.
- 1년 뒤, 사장님 가게는 52편의 이야기를 가진 가게가 됩니다.
- 검색하면 나오는 가게와, 안 나오는 가게.

**기능 안내용 짧은 문구**

- 직접 찍은 사진으로 넣으시면 이야기에 신뢰가 쌓입니다. *(사진 선택 화면)*
- 오늘은 그냥 직접 쓸래요. *(도망갈 구멍)*
- 없는 말이 들어갔는지 «제가 한 말»로 확인해 보세요. *(초안 확인 화면)*

## 2-3. 자막 — 최종 확정

| 항목 | 확정 |
|---|---|
| 음성 인식 | **AssemblyAI Universal-2** — 단어 단위 타임스탬프 + 한국어, 분당 $0.0025(**3.4원/건**) |
| ⚠ 쓰면 안 되는 것 | **OpenAI 신규 모델(gpt-transcribe)은 단어 타임스탬프 미지원** — `whisper-1`만 됨. Gemini는 타임스탬프 켜면 정확도 저하가 공식 문서에 명시 |
| 렌더링 | ffmpeg + libass |
| ⚠ **최대 기술 리스크** | **libass가 한글 단어 중간에서 줄을 끊습니다.** 해법으로 알려진 `wrap_unicode`는 한국어에서 형태소 경계로 끊어 **더 나빠집니다**(이슈 #694, 3년째 미해결) |
| **해결** | 라이브러리에 맡기지 않고 **우리가 어절(띄어쓰기) 기준으로 직접 나눠 `\N` 삽입.** 줄당 12~16자. 형태소 분석기 불필요 |
| ⚠ 폰트 | **컨테이너에 한글 폰트를 반드시 임베드.** 없으면 자막이 통째로 깨짐 |

> «대량 생산되었거나, 일반적이거나, 반복적이거나, 조작적이지 않을 것»
> «**대량 생산 인상을 주는 일반적·비독창적 템플릿으로 만든 AI 콘텐츠**» 금지 — 단 «제작자 고유의 통찰이나 관점»이 더해지면 예외

**모든 고객 영상이 같은 템플릿으로 나오면 정면으로 걸립니다.** 그래서 제품 규칙 넷을 요구사항으로 못 박습니다.

3. 자막 스타일·전환·색을 **가게마다 다르게 배정**
4. 같은 배경이 여러 고객에게 몰리지 않게 **중복 방지**

반대로 **인스타는 우리 방향을 원본으로 인정**합니다 — Meta 2026-04: «고유한 텍스트, 창의적 편집, **보이스오버**를 더하면 원본 창작물».

# 3장. 스토리 페이지 디자인 → 이미지 규격

회장님 지시대로 **디자인을 먼저 정하고 그 기준으로 뱅크 사진 크기를 정합니다.**

```
┌─────────────────────────────────────────┐
│                                         │  본문 폭 720px (읽기 최적)
│  [대표 이미지  720 × 405  (16:9)]        │  ← 뱅크 배경 + 이야기 한 줄
│                                         │
│  광진구 24평, 벽 하나 트고               │  제목 Gowun Batang 28px

│  │          │  ← 영상 380 × 676 (9:16)  │  본문 왼쪽 정렬, 오른쪽에 여백

│                                         │

```

**모바일**: 본문 폭 100%, 영상은 전체 폭, 사진 3장은 가로 스크롤.

## 3-2. 이 디자인에서 나오는 이미지 규격 (확정)

| 자리 | 표시 크기 | **실제 파일 (레티나 2배)** | 형식 |
|---|---|---|---|
| **대표 이미지** | 720 × 405 | **1440 × 810** (16:9) | WebP q80 |
| 목록 썸네일 | 200 × 113 | 400 × 226 (16:9) | WebP q75 |
| 인스타 정사각 | — | **1080 × 1080** (1:1) | JPEG q85 (인스타는 JPEG만) |
| 인스타 세로 | — | **1080 × 1350** (4:5) | JPEG q85 |
| 영상 표지 | — | **1080 × 1920** (9:16) | JPEG q85 |
| 사장님 사진 | 232 × 232 | 원본 보관 + 464 × 464 크롭 | WebP |

## 3-3. 그래서 뱅크 원본은 이 크기 (확정)

**뱅크에는 «배경 소재»만 넣고, 위 여섯 가지는 전부 크롭·합성으로 뽑습니다.**

| 원본 종류 | 생성 크기 | 용도 | 비중 |
|---|---|---|---|
| **가로 16:9** | **1K (약 1344 × 768)** | 대표 이미지·썸네일 | 60% |
| **정사각 1:1** | **1K (1024 × 1024)** | 인스타 정사각·4:5 크롭 | 30% |
| **세로 9:16** | **1K (약 768 × 1344)** | 영상 표지·인스타 스토리 | 10% |

**«고화질 큰 이미지»에 대한 답**: 대표 이미지의 레티나 실사용 크기가 **1440×810**인데 1K 16:9 원본이 약 1344×768이라 아슬아슬합니다. 그래서 **대표용 상위 1,000장만 2K로 뽑고 나머지는 1K**로 가는 하이브리드를 권합니다(§4-3 예산 배분).

**배경이 질감·색면이라 크롭해도 무너지지 않는다**는 게 이 설계의 전제입니다. 장면 사진이면 크롭이 문제가 되지만 질감은 아닙니다.

# 4장. 이미지 뱅크 자동화

## 4-1. ⚠ 가장 중요한 발견 — 크레딧을 쓰는 경로가 정해져 있습니다

회장님 40만 원은 **Google Cloud 무료 체험 크레딧 $300 (유효 90일)** 이 거의 확실합니다. 그런데 구글 공식 문서에 이렇게 적혀 있습니다.

> **«$300 크레딧은 AI Studio의 Gemini API 비용을 결제할 수 없습니다»**

**즉 지금 쓰시는 AI Studio API 키로 이미지를 뽑으면 크레딧이 안 깎이고 카드에서 나갑니다.** 개발자 포럼에 같은 사례가 여럿 보고돼 있습니다.

## 4-7. AI 자동 별점 + 키워드 추출

생성된 이미지를 다시 Gemini에 넣어 **평가와 태깅을 한 번에** 받습니다(배치, 장당 약 1.5원).

```json
{
  "score": 4,
  "usable": true,
  "reject_reason": null,
  "tags": ["나뭇결","원목","따뜻한","갈색","베이지","질감","클로즈업",
           "가로결","자연광","여백_왼쪽아래","가구","바닥재","인테리어",
           "차분한","무광","세로줄무늬","중간톤","실내"],
  "text_area": "left-bottom",
  "dominant_color": "#B08A5E"
}
```

**별점 기준(프롬프트에 명시)**
- ★5 — 글자를 얹을 여백이 넉넉하고, 질감이 선명하고, 색이 차분함
- ★4 — 쓸 만하나 여백이 좁거나 색이 조금 튐
- ★3 — 배경으로는 되지만 글자가 묻힐 수 있음
- ★2 이하 — 사람·글자·로고가 들어갔거나, 완성된 실내 전경이거나, 뭉개짐 → **자동 폐기**

**키워드는 12~20개**를 뽑게 합니다. 회장님 지시대로 «최대한 많이» — 많을수록 나중에 이야기와 겹칠 확률이 올라갑니다.

**`text_area`가 중요합니다.** 글자를 어디에 얹을지 이미지마다 다르므로, 이걸 저장해 두면 카드 합성 때 자동으로 안 겹치는 자리에 글자를 놓습니다.

## 4-8. 생성 프롬프트 뼈대

```
한국 소상공인 홈페이지의 이야기 카드 배경.
소재: {나뭇결}   톤: {따뜻한}   비율: {16:9}

반드시 지킬 것:
- 글자를 얹을 여백을 {왼쪽 아래}에 크게 비울 것
- 사진 같은 질감. 일러스트·3D 렌더링 아님
- 얕은 심도, 자연광

절대 넣지 말 것:
- 사람, 얼굴, 손
- 글자, 숫자, 로고, 상표
- 완성된 실내 전경 (거실·주방·매장 전체)
```

**«완성된 실내 전경 금지»가 핵심입니다.** 이게 있어야 «저 집이 내 작업물»이라는 오해가 생기지 않고, 표시광고법 문제도 피합니다.
