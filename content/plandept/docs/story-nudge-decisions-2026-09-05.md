# 스토리 넛지 — 확정 결정표 & 실행 카드 (v3, 2026-09-05)

> 상태: **회장님 확정.** 배경·근거·문구·비용 계산은 `story-nudge-plan-v2-2026-09-04.md` 에 그대로 있고,
> 이 문서는 그중 미정이던 6건을 못 박고 실행 단위를 다시 자른 것이다. 클코팀장은 이 문서 + v2 를 읽는다.

## 1. 확정된 6건

| # | 항목 | 확정 |
|---|---|---|
| ① | 카톡 음성 명시 | **둘 다 명시.** 넛지 메시지와 `/story` 페이지 양쪽에 ⓐ"녹음은 카톡 밖(Chrome·Safari)에서 돼요" ⓑ"이 채팅에 음성메시지를 보내셔도 글이 되지는 않아요" 를 넣는다. 안드로이드 카톡 인앱은 페이지가 감지해 "Chrome으로 열기" 버튼 + 글·사진 대안을 같은 크기로 보여준다 |
| ② | 이메일 로그인 | **막지 않는다.** `/story` 로그인 화면은 카카오 버튼을 크게, 이메일은 "다른 방법으로 로그인" 작은 링크. 신규 가입 화면도 같은 배치. 이메일 가입자가 카카오로 옮기고 싶으면 운영자 "소유자 변경" 버튼(고객관리 화면)으로 처리 — 자동 계정 연결은 카카오가 이메일을 주지 않아 불가(DECISIONS 2026-09-01) |
| ③ | 사진 | **상한 20장 · 첫 화면 노출 8장** + "사진 더보기". 장당 폰에서 1600px·WebP 축소 |
| ④ | 글 길이 | **보통 = 3~5문장 · 150~300자 · 제목 22자 이내**. 운영자 설정에서 짧게/길게 변경 가능, 사이트별 덮어쓰기 가능 |
| ⑤ | 검토 알림 | **회장님 폰 문자 + 운영자 화면 배지.** 심각도 '높음'은 즉시, 나머지는 하루 1회 묶음. 문자 채널은 이미 살아 있음(2026-09-04 `/api/admin/notify-check` = sms true·email true·salt true). 카톡 알림은 알림톡 개통 후 |
| ⑥ | 운영자 화면 순서 | **검토함을 앞당긴다.** 검토함(+알림 문자)은 넛지 가동과 같이 나가고, 설정·고객관리·실험실 3화면은 그 뒤 별도 세션(P5 뒤 가능) |

v2 에서 이미 확정돼 있던 것(재확인): 발송은 회장님 카톡 1:1 예약, **화요일 12:00**, 인증은 카카오 로그인(작성 키 폐기), AI 재수정 **1회** 뒤 직접 수정, 승인 없는 자동 게시 **없음**, 카톡 음성 컨시어지 **없음**, 20곳 넘으면 알림톡으로 전환.

## 2. 실행 단위 (수락 후 클코팀장 세션)

| 세션 | 내용 | 모델 | 스키마·마이그레이션 |
|---|---|---|---|
| **N1** | `/[slug]/story` 두 얼굴 페이지(손님=목록+견적 CTA / 사장님=작성 카드) · `/[slug]/story/[id]` 개별 페이지 · 카카오 우선 로그인 게이트(`?next=`, `/auth/callback` 이 next 를 받는지 먼저 확인) · 사이트맵 추가 · 홈 스토리 섹션에 "전체 보기" 링크 | Sonnet 5 | 없음 |
| **N2** | 입력·AI: 녹음 컴포넌트(인앱 감지·Chrome 열기·명시 문구·2~60초) · 글/사진 입력 · `/api/story/voice`·`/draft`·`/revise`(1회)·`/decide` · 사이트 프로필 캐시(`sites.inferred.storyProfile`) · 2차 검수(원문에 없는 사실 지목·삭제) · `PATCH /api/site/story`(게시 후 수정) | Sonnet 5 | 마이그레이션 1개(`story_drafts` + `story_entries` 2열 ALTER) |
| **N3** | 검토함 `/admin/review` (규칙 8개 · 문자 알림 · [문제없음][글 수정][숨김][전화]) | Sonnet 5 | 마이그레이션 1개(`review_queue`) |
| **N4** | 프로덕션 확인 — 회장님 폰 3경로(iOS 카톡 / 안드로이드 카톡→Chrome / Safari)에서 녹음→게시 1건씩 + 검토함 알림 문자 1건 실수신 | — | — |
| (뒤) | 운영자 3화면(설정 `app_settings` · 고객관리 · 실험실) | Sonnet 5 | 마이그레이션 1개(`app_settings`) |

시점: 스프린트 **6(플로팅 위젯) 뒤 · 7(R2-2) 앞**. N3 까지가 "넛지를 실제로 켤 수 있는" 최소 묶음이다.

## 3. 시작 전 남은 확인 2개 (클코팀장 N1 첫머리)

1. `/auth/callback` 이 `next` 파라미터를 받아 원래 주소로 돌려보내는지 — 안 되면 그 한 줄을 먼저 고친다(잠금 작업 때 `/admin` 쪽에 넣은 것과 같은 방식, `//` 로 시작하는 주소는 거부).
2. `config/industries.ts` 에 스토리 라벨(`story.label`)을 추가할 자리 — 시공 "최근 시공 내역", 카페·식당 "우리 가게 소식". 렌더러가 이 값을 읽게 하되 섹션 zod 스키마는 건드리지 않는다.

## 4. 4주 실험 (N4 직후 회장님)

대상 현재 고객 2곳 + 지인 5곳 · 화 12:00 발송 · 기록은 검토함/고객관리에서.
판정: **4주 안에 1회 이상 게시한 사장님 ≥ 40%** 이면 20곳으로 확대 + 알림톡 신청. 미만이면 문구·주기부터 다시.
