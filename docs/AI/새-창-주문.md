# 새 AI 창을 열 때 붙여 넣는 주문

**쓰는 법:** 아래 회색 칸 안을 **통째로 복사**해서 새 창 첫 메시지로 붙여 넣으세요.
그것 하나면 AI 가 「무엇부터 읽어야 하는지」를 스스로 찾아갑니다.

⚠ 이 주문은 **고치지 마세요.** 읽을 순서가 바뀌면 인수인계가 끊깁니다.
바꿔야 할 일이 생기면 이 파일을 고치고, 왜 고쳤는지 `docs/DECISIONS.md` 에 한 줄 남기세요.

---

## 📋 복사할 것 (여기부터)

```
시작하기 전에 이 순서로 읽어라. 건너뛰지 마라.

1. START-HERE.md
2. docs/WAITING.md      — 지금 사람의 손을 기다리는 일. 이것부터 봐야 한다
3. docs/PROGRESS.md     — 맨 위 마디 하나만. 어디까지 됐는지
4. CLAUDE.md            — 어기면 안 되는 규칙
5. docs/DECISIONS.md    — 맨 위 다섯 줄만. 최근에 무엇을 왜 정했는지

다른 팀 최신은 ../../fable51plandept/AI_Context/{KIM,PARK,SANGMU,TECH,VICE}/LATEST.md 에 있다.
읽기만 하고 고치지 마라.

다 읽었으면 나에게 이렇게만 답해라:
- 지금 막혀 있는 것 (사람이 해야 할 일) 몇 건, 무엇인지
- 마지막으로 끝난 마디가 무엇인지
- 오늘 이어서 할 일로 네가 추천하는 것 하나

⚠ 추측으로 말하지 마라. 못 본 것은 「못 봤다」고 말해라.
⚠ 코드를 고치기 전에 npm run 검사 를 한 번 돌려 지금이 초록인지 확인해라.
```

## 일이 끝났을 때 — AI 에게 이렇게 시키세요

```
오늘 한 일을 인수인계에 남겨라. 네 곳 전부다:

1. docs/PROGRESS.md 맨 위에 새 마디 (무엇을·왜·무엇이 막혔는지)
2. docs/WAITING.md 갱신 — 내 손을 떠난 일을 적고, 끝난 것은 「끝난 일」로 옮겨라 (지우지 마라)
3. docs/DECISIONS.md — 오늘 «정한» 것이 있으면 한 줄 (없으면 안 적어도 된다)
4. docs/AI/ 세 파일 (CLAUDE.md §3-2 대로)

그리고 이 네 개를 한 커밋에 같이 넣어 push 해라.
⚠ 「push 했습니다」로 끝내지 마라 — 운영에서 «읽어서» 반영됐는지 확인까지가 한 건이다.
```

## 왜 이런 주문이 필요한가

AI 창은 **닫히면 기억이 사라집니다.** 사람과 다릅니다.
그래서 「기억」을 사람 머리가 아니라 **저장소 안 파일**에 둡니다.
이 주문은 새 창에게 「네 기억은 저 파일들에 있다」고 알려 주는 역할입니다.

2026-09-13 에 실제로 이런 일이 있었습니다 — `CLAUDE.md` 에
「AI_Context 폴더는 아직 없다」고 적혀 있었는데 그 사이 생겼습니다.
새 창이 그 줄을 믿고 **팀장님들 기록을 아예 안 읽을 뻔했습니다.**
그래서 이 문서들은 **사실이 바뀌면 그날 고칩니다.**
