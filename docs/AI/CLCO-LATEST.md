## 1. [40] 편집화면 「same key」 — 끝냈습니다

### 진범은 **쌓인 실패 기록**입니다

같은 영상·같은 SNS 에 **줄이 여럿** 생깁니다. 중복 방지 장치가 **「살아 있는 시도」에만** 걸려 있어서입니다 —
**실패·취소는 다시 시도할 수 있어야 해서 «일부러» 뺀 것**이라, 장치가 틀린 게 아닙니다.

**DB 를 읽어 세어 봤습니다(바꾸지 않았습니다):**

| 영상 | 줄 수 |
|---|---|
| 「가게 이름은 어떻게 지으셨나요?」 | **틱톡 8줄** — 실패 7 + 성공 1 |
| 「오늘 하늘이 예쁘네요」 | **틱톡 4줄** — 실패 4 |

### 🔴 콘솔 경고보다 **화면이 더 문제였습니다**

한 영상 밑에 이렇게 떴습니다.

```
틱톡 — 안 올라갔어요.       ← 일곱 번
틱톡 — 올라갔어요. [보기]    ← 그리고 이 줄
```

**사장님은 올라간 건지 아닌지 알 수 없습니다.** 화면이 스스로와 어긋나면 그게 곧 거짓말입니다.

### 고침 — **SNS 한 곳당 「가장 참인 한 줄」만** 보냅니다

**올라간 것 > 가는 중 > 실패 > 취소**, 같으면 **나중 것**.
🔴 **기록은 지우지 않았습니다** — DB 에 여덟 줄 그대로 있고, **화면에 한 줄을 고르는 것**입니다.

**실측(편집화면이 부르는 그 API 를 그대로 호출):**

```
8줄 → 틱톡 = 올라갔어요 (1줄)      4줄 → 틱톡 = 안 올라갔어요 (1줄)      겹침 0
```

⚠ **열쇠에 숫자를 붙여 경고만 끄지 않았습니다** — 그러면 **경고는 사라지고 거짓말은 남습니다.**
