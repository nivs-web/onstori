## [23] 회원 등급 — 대표님이 잡아내신 구멍

> 「정회원으로 올려줬는데 **무료회원으로 다시 바꾸는 게 없어.**」

사이트 목록에서 **한 곳을 체크**하면 버튼 둘이 생깁니다.
**［⬆ 정회원으로 올리기］ ［⬇ 무료회원으로 내리기］**

### 🔴 눌러 보다 «버그»를 잡았습니다

［⬆ 정회원으로 올리기］를 누르니 이런 창이 떴습니다:

```
1곳을 «다시 열기» 합니다.
폐쇄해도 자료는 지워지지 않고, 손님에게만 안 보입니다.
```

**등급을 올리는데 「다시 열기」라고 묻습니다.** 지금은 이렇게 뜹니다:

```
「○○○」 을 정회원으로 올립니다.
결제 없이 올리는 것이라 매출로는 잡지 않습니다.
```

⚠ **타입 검사도 빌드도 이건 못 잡습니다.** 문법은 완벽했습니다.

### 🔴 매출이 흐려지지 않게

| | 결제로 된 정회원 | 손으로 올린 정회원 |
|---|---|---|
| 사장님 화면 | 똑같습니다 | 똑같습니다 |
| **돈 들어온 날** | **찍혀 있습니다** | 🔴 **비어 있습니다** |
| 어드민 표 | **유료회원**(초록) | **정회원(손으로)**(검정) |

★ **시키신 것보다 한 걸음 더 갔습니다** — 데이터에만 표시를 남기면 **표에서 둘이 똑같아 보여
소용이 없습니다.** 표에서도 갈랐습니다.

**실측 16건**: 열쇠 없이 401 · 두 곳 400 · 이유 없음 400 · 없는 곳 404 ·

## [20] 홈 화면에 바로가기 — **대표님 아이디어**

> 「폰 홈 화면에 바로가기로 60초 촬영이 박히는 거야. 그러면 **자주 영상 찍어 올려줄 거 같다.**」

```
[ 60초 영상 촬영하기 ]
[ 어떻게 찍나요? · 30초면 읽어요 ]
[ 📱 홈 화면에 바로가기 만들기 ]
   홈 화면에 추가해 두고 생각이 나면 바로 찍어요!
```

### 🔴🔴 만들기 «전»에 찾은 것 — 그대로 했으면 **2주 만에 죽습니다**

녹화 주소의 **열쇠는 그 주에만** 살아 있습니다. 아이콘에 그대로 박으면
**2주 뒤 누르실 때 「이 링크는 만료됐어요」만** 뜹니다.

> **매일 눈에 띄게 하려던 아이콘이, 매일 실망을 줍니다.** 정반대입니다.

⇒ 바로가기는 **열쇠 없이** 갑니다. 그 자리에서 **주인이신지 확인해 새 열쇠를 즉석에서** 만듭니다.
**아이콘은 영원히 삽니다.**

🔴 **문을 넓힌 것이 아닙니다.** 주인 확인은 **원래 쓰던 방식 그대로**입니다.
실측 — **남이 열쇠 없이 들어오면 「만료됐어요」 · 403 거절** 입니다.

### 기기 네 갈래를 전부 눌러 확인했습니다

| 기기 | 뜨는 것 |
|---|---|
| **안드로이드** | 크롬 **설치 창이 바로** 뜹니다 |
| **아이폰** | 「①맨 아래 **공유 단추** ②**［＋ 홈 화면에 추가］**」 — **그 두 모양을 그림으로** |
| **카카오톡 안** | 「**⋮ → ［다른 브라우저로 열기］** 뒤 한 번만 더」 |
| **이미 설치됨** | 🔴 **버튼을 아예 숨깁니다** |

⚠ 제가 가장 신경 쓴 것 — **「눌러도 아무 일이 안 나는 버튼」을 안 만들었습니다.**
자동 설치가 안 되면 **손으로 하는 길이 그대로 펼쳐집니다.**

### 🟢 가장 큰 물음표가 풀렸습니다

권반장님이 「**서비스워커는 만들지 마십시오**」라고 하셨는데, 예전 크롬은 그게 없으면
**설치 창을 아예 안 줬습니다.** 재 봤더니 — **첫 방문에 바로 줍니다.** 지시를 그대로 지켰습니다.

★ 아이콘 밑에는 「온스토리」가 아니라 **사장님 «상호»**가 박힙니다.
가게가 둘이면 **아이콘도 둘** 두실 수 있습니다.
