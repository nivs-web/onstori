## 1. 체크박스 방향 — 앞 배치에서 고쳤습니다

회장님 지적이 정확했습니다. 「댓글 **막기**」는 기본 꺼짐 = **막지 않음** = 댓글 **허용**이라
틱톡이 정한 「기본 전부 안 됨」과 **정반대**였습니다.

「댓글 **허용** / 듀엣 **허용** / 이어찍기 **허용**」으로 뒤집고 **기본 꺼짐**.
서버로 보낼 때만 `disableComment: !okComment` 로 되돌립니다 — 말씀대로 **서버 타입은 그대로**입니다.

★ 하나 더: 못 켜는 항목을 전에는 **아예 안 보여 줬는데**, 규격서 F 지적대로
**회색으로 보여 주고** 「이 계정에서 꺼 두셨어요」를 붙였습니다.
아예 없으면 심사관이 「비활성 처리를 했는지」 판단할 수 없습니다.

## 2. Music Usage Confirmation

**[이 내용으로 틱톡에 올리기] 버튼 바로 위**에 넣었습니다.

```
By posting, you agree to TikTok's Music Usage Confirmation
올리시면 틱톡의 음악 사용 확인에 동의하시는 것이 됩니다.   ← 작은 글씨
```

★ **번역하지 않았습니다.** 틱톡이 문장을 지정했고, 번역하면 심사관이 못 찾습니다.
★ **브랜디드를 켜면 문구가 바뀝니다** — 「Branded Content Policy and Music Usage Confirmation」.
  이것도 틱톡이 정한 것이라 화면이 상업용 토글과 **연동**됩니다.

## 3. 상업용 콘텐츠 토글

| 단계 | 화면 |
|---|---|
| 토글 (**기본 꺼짐**) | ☐ 이 영상이 나 자신·브랜드·상품·서비스를 홍보하나요? |
| 안내 | 가게나 상품을 소개하는 영상이면 켜 주세요. 틱톡 규칙입니다. |
| 켜면 (**둘 다 기본 꺼짐**) | ☐ 내 브랜드 — 내 사업을 홍보합니다 / ☐ 브랜디드 콘텐츠 — 다른 브랜드·제3자를 홍보합니다 |
| 내 브랜드만 | `Your photo/video will be labeled as 'Promotional content'` |
| 브랜디드(또는 둘 다) | `Your photo/video will be labeled as 'Paid partnership'` |
| 켰는데 아무것도 안 고름 | **올리기 버튼 비활성** + `You need to indicate if your content promotes yourself, a third party, or both.` |

### 🔴 브랜디드 + 「나만 보기」

틱톡이 「Either… OR」라 했고, **「나만 보기」를 비활성하는 쪽**을 골랐습니다(간단합니다).

- 브랜디드를 켜면 「나만 보기」 버튼이 **회색**이 되고, 마우스를 올리면
  `Branded content visibility cannot be set to private.`
- ★ **이미 「나만 보기」를 골라 둔 상태에서 브랜디드를 켜면 그 선택을 되돌립니다.**
  화면은 못 고르게 막는데 값만 남아 나가면 그게 거짓말입니다.
- ⚠ **서버도 마지막으로 막습니다.** 화면 값을 그대로 믿지 않습니다 —
  안 막으면 하루 한도 1개를 쓰고 틱톡 거절만 받습니다.

### ⚠ 토글만 두지 않았습니다

화면에 토글을 두고 값을 안 보내면 **화면이 거짓말**입니다.
`brand_organic_toggle`·`brand_content_toggle` 로 **실제로 실어 보냅니다**.
