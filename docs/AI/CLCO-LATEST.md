## 1. ★★ 1번에서 «더 큰 구멍»을 찾았습니다

김팀장님이 찾아 주신 것은 **「60일이면 만료된다」** 였습니다. 그런데 코드를 열어 보니
**우리는 60일짜리 토큰을 받은 적이 아예 없었습니다.**

| | 무슨 일이 벌어지고 있었나 |
|---|---|
| 인스타 로그인 직후 받는 첫 열쇠 | **1시간짜리** |
| 60일짜리로 바꾸는 절차 | **코드에 없었습니다** |
| 결과 | 사장님이 연결하고 **한 시간 뒤부터** 올리기가 실패 |

> 즉 「두 달 뒤에 끊긴다」가 아니라 **「한 시간 뒤에 끊긴다」** 였습니다.
> 오늘 회장님이 인스타 연결에 성공하셨으니, **그 연결도 한 시간이면 죽었을 것**입니다.

**고친 것 셋**

1. 연결하는 순간 **1시간짜리 → 60일짜리로 바꿉니다.**
2. **매일 한 번** 크론이 「만료 2주 안에 죽는 열쇠」를 미리 갱신합니다. 다시 60일이 됩니다.
3. 갱신이 **확실히 끝난 것**일 때만 「다시 연결해 주세요」로 내립니다.
   잠깐 안 되는 것(인스타가 잠시 죽은 것 등)은 **그냥 둡니다** — 멀쩡한 연결을 우리가 끊지 않습니다.

**화면 거짓말도 하나 고쳤습니다.** 연결이 풀리면 화면이 「[연결하기]를 눌러 주세요」라고 하는데
**그 버튼이 화면에 없었습니다.** [연결 끊기]만 있었습니다. 이제 [다시 연결하기]가 나옵니다. (규칙 12)

**새 크론을 만들지 않았습니다.** `vercel.json` 의 크론 한 줄이 어제 배포 전체를 막았고,
무료 요금제는 크론 개수에도 제한이 있습니다. 그래서 **이미 매일 도는 크론에 얹었습니다.**

**검사 16건을 만들었습니다** — `npx tsx scripts/sns-refresh-test.ts`. 60일을 기다려 볼 수는 없으니까요.

## 2. 2번 — 가입 동의 ⚠ 회장님 손이 필요합니다

손님은 체크박스로 보호받는데 **사장님 가입에는 하나도 없었습니다.** 넣었습니다.

- 가입 **마지막 단계**(분위기 고르기 아래)에 체크박스 셋
  - **[필수]** 이용약관 · **[필수]** 개인정보 수집·이용 — 각각 **새 창 링크**로 열립니다
  - **[선택]** 촬영 알림 문자 — 안 눌러도 가입됩니다
- 필수 둘을 안 누르면 [홈페이지 만들기] 버튼이 **안 눌립니다**
- **동의 시각을 새 표(`consents`)에 남깁니다.** 상무님 경고대로 `settings` 에 넣지 않았습니다
  — 거기 넣으면 사장님이 홈페이지를 저장할 때마다 **증거가 조용히 덮입니다**

> ⚠ **`npx supabase db push` 를 해 주셔야 합니다.** (새 표 `consents`)
> 하기 전까지는 동의 화면은 뜨지만 **기록이 안 남습니다**(가입 자체는 정상).

## 3. 10번 — 전제가 코드와 달랐습니다

상무님 보고는 **「지금은 완성도 60점이면 색인된다」** 였습니다. 저장소를 뒤졌는데
**그런 규칙이 어디에도 없습니다.** 지금 실제 규칙은 이렇습니다:

| 지금 실제 | |
|---|---|
| 무료(trial) 사이트 | **검색에서 아예 뺍니다**(noindex) |
| 결제한(active) 사이트 | 사이트맵에 넣습니다 |

즉 **이미 60점 규칙보다 엄합니다.** 고칠 「60점」이 없었습니다.

그래서 **권고의 «뜻»을 살렸습니다** — 「빈 사이트가 색인되면 다 같이 손해다」.
**결제한 사이트라도 속이 비어 있으면 우리가 먼저 검색엔진에 알리지 않습니다.**
문턱: **75점 + 전화번호가 유효 + 한 번 이상 편집.**

★ 다만 **noindex 를 걸지는 않았습니다.** 둘은 다릅니다:
- 사이트맵에서 빼기 = 「우리가 먼저 알리지 않는다」 (채우면 다음 갱신에 저절로 들어갑니다)
- noindex = 「검색에서 지워라」

**돈을 낸 사장님의 홈페이지를 우리가 검색에서 지우는 일은 하지 않습니다.**

★★ **함정 하나를 잡았습니다.** 점수표(`site_progress`)는 «주인만» 읽을 수 있는 표입니다.
사이트맵은 로그인이 없어서, 그대로 뒀으면 점수가 전부 「없음」이 되어
**모든 사이트가 사이트맵에서 조용히 사라질 뻔했습니다.** 운영자 열쇠로 읽게 고쳤습니다.

★ **실측**: 지금 결제·발행된 손님 사이트는 **샘플 하나(`sample-interior`, 55점)** 뿐이라
새 문턱에 걸려 빠집니다. 그건 우리 시연용 가짜 가게라 **검색에 안 나오는 편이 맞습니다.**
진짜 사장님이 생기면 75점을 넘기는 순간 들어갑니다.
