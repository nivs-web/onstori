| **⬇ 무료회원으로 내리기** | **어디로** 내릴지 고릅니다 — **무료회원(체험)** 또는 **폐쇄** |

## 🔴🔴 눌러 보다 «버그»를 잡았습니다 — 안 해 봤으면 그냥 나갔습니다

[⬆ 정회원으로 올리기] 를 눌렀더니 **엉뚱한 확인창**이 떴습니다:

```
1곳을 «다시 열기» 합니다.
폐쇄해도 자료는 지워지지 않고, 손님에게만 안 보입니다.
```

**등급을 올리는데 「다시 열기」라고 묻습니다.** 예전 코드의 확인창 조건이 한 줄뿐이라
새로 만든 기능이 **자동으로 그 그물에 걸린** 것입니다.

**고친 뒤 실제로 뜨는 말:**

```
「zz-gate-test-a」 을 정회원으로 올립니다.
결제 없이 올리는 것이라 매출로는 잡지 않습니다.
```

⚠ **타입 검사도 빌드도 이건 하나도 못 잡습니다.** 문법은 완벽했습니다.

## 🔴 왜 «정회원으로 올려도» 매출이 안 흐려지나

| | 결제로 된 정회원 | 손으로 올린 정회원 |
|---|---|---|
| 손님·사장님 화면 | 똑같습니다 | 똑같습니다 |
| **돈 들어온 날(`paid_at`)** | **찍혀 있습니다** | 🔴 **비어 있습니다** |
| 어드민 표 | **유료회원**(초록) | **정회원(손으로)**(검정) |

⇒ 「이번 달 매출」을 셀 때 **돈 들어온 날이 있는 것만 세면** 섞이지 않습니다.
⇒ ★ **시키신 것보다 한 걸음 더 갔습니다** — 데이터에만 표시를 남기면 **표에서 둘이
   똑같아 보여 소용이 없습니다.** 그래서 회원 칸을 갈랐습니다.

🔴 **손님 사이트는 하나도 안 건드렸습니다.** 제가 전에 만든 시험용 사이트에서만 하고
**원래대로 돌려놨습니다.** 결제 표에 시험용 한 줄을 넣었다 지웠고(**돈은 1원도 안 움직였습니다**),
끝나고 **0건**을 다시 셌습니다.
