## 1. A — 화질: **폰 탓이 아니라 우리가 낮게 요청**하고 있었습니다

회장님 영상을 ffprobe 로 직접 쟀습니다.

| 항목 | 잰 값 | 원인 |
|---|---|---|
| 해상도 | **720×1280** | 우리가 720p 를 «요청» |
| 프레임 | **59fps** | 요청을 안 해 브라우저가 60을 고름. **안 떨어졌습니다** |
| 영상 비트 | 4.97Mbps | 안 정해 줌 |
| 소리 | **opus 35kbps** | 코덱을 안 적음 |

**고침:** 1080×1920 · 30fps · 6Mbps · AAC 128k. **60초 ≈ 45MB**(전 38MB, 화면 넓이는 2.25배).

★ **30fps 로 내리는 것이 화질을 올립니다** — 같은 비트를 절반의 장수에 씁니다.
★ **버벅임은 프레임 탓이 아니었습니다.** 60fps 에 비트를 나눠 쓴 것 + 720p 를 인스타가 늘린 것입니다.
★ **[갤러리에서 고르기]** 추가 — 브라우저 녹화는 카메라 앱을 못 이깁니다(센서를 다 안 열어 줍니다).
  아이폰 mov 는 **막지 않고** 미리 알린 뒤 고른 다음 판정합니다(갤러리에 mp4 도 있습니다).
