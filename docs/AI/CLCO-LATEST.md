## [19]⓪ 「여러 편 걸었는데 한 편만」 — **범인이 짐작과 달랐습니다**

권반장님은 「거는 길이 없다」고 보셨는데, **거는 길은 있었고 일곱 편이 실제로 걸려 있었습니다.**

진짜 범인은 **손님 권한 규칙 한 줄**입니다. 그 규칙은 「**보이기로 표시된 것만**」 읽게 하는데,
**영상은 일부러 그 표시를 안 켭니다**(켜면 이야기 목록에 **내용이 텅 빈 항목**이 뜨고
완성도 점수가 저절로 올라갑니다).

> ⇒ **사장님은 「걸었다」고 보고, 손님은 못 봅니다.**

```
같은 사이트, 열쇠만 바꿔서
  손님 열쇠  : 0편
  운영자 열쇠 : 7편
```

⚠ **운영자 미리보기(`/x/…`)에서는 일곱 편이 다 보였습니다.** 그래서 늦게 드러났습니다 —
「내 화면에서는 되는데」의 교과서 사례입니다.

**고친 뒤 실측: `<video>` 1개 → 7개.** 정지된 사이트는 여전히 **0편**입니다(안 샙니다).

🔴 **더 깨끗한 길은 DB 규칙 한 줄을 고치는 것**인데 **제가 못 합니다.** 승인해 주시면 하겠습니다.

## [19]① 숏폼 무대 — **화면이 다 까맣게 변합니다**

히어로 아래로 내려가면 화면이 **검게 덮이고**, 영상 일곱 편이면 **8화면**을 굴려야 나갑니다.
「히어로의 2배 이상」이 **저절로** 됩니다.

🔴 **스크롤을 훔치지 않았습니다.** 가두는 느낌은 **CSS 두 줄**로 만듭니다 —
JS 로 가로채면 **뒤로 가기·검색·스크롤바가 전부 망가집니다.**

**시키신 여섯 — 전부 눌러서 확인:**

```
굴리면 1/7 → 2/7 → 3/7 → 4/7 → 6/7      스와이프 위 2/7 · 아래 1/7
[건너뛰기 ↓] → 무대 밖으로 ✅            소리는 꺼진 채 시작 ✅
PC 에서도 9:16 (506×900) ✅              같은 영상을 두 번 안 그림 ✅
「움직임 줄이기」 : 가두지 않고 목록으로 · 자동재생 안 함 · 재생바 줌 ✅
```

### 🔴 눌러 보고 잡은 것 셋 — 안 눌렀으면 다 나갔습니다

| 무엇이 | |
|---|---|
| **편이 영원히 「1 / 7」** | 몇 번째인지 재는 «자»의 두께가 0 이라 아무것도 안 걸렸습니다 |
| **［건너뛰기 ↓］가 안 보임** | 아래 **［문의하기］ 바에 완전히 가려** 있었습니다. **탈출구가 안 보이면 「항상 띄운다」가 거짓말**입니다 |
| **검은 화면 위 «흰 띠» 한 줄** | 위 상호 바가 그대로 떠 「다 까맣게」가 깨졌습니다 |

## [19]③ 디자인 — **글은 한 글자도 안 바꿨습니다**

🔴 「손님 글은 먼저 여쭙는다」 규칙 때문입니다. 바꾼 것은 **여백·배경·전환** 셋뿐입니다.

### 🔴 「평범한 회사 홈페이지」의 가장 큰 이유를 찾았습니다

**같은 바탕색 섹션이 넷씩 이어지고 있었습니다.**

```
전 : 소개(흰) → 진행 과정(흰) → 시공 갤러리(흰) → 견적(연) → 오시는 길(흰)
후 : 무대(검정) → 소개(연) → 진행 과정(흰) → 시공 갤러리(연) → 견적(연) → 오시는 길(흰)
```

우리 디자인 문서가 「**같은 배경 연속 금지 — 경계가 사라져 한 덩어리로 보인다**」고 못 박아 뒀는데,
**그 규칙이 손님 사이트에는 적용된 적이 없었습니다.**

### 🔴 PC 에서 **폰과 똑같은 여백**을 쓰고 있었습니다

```
전 : 폰 64/20 · PC 64/20   ← 1440 화면에서도 폰 여백
후 : 폰 64/20 · PC 120/32  ← 원래 정해져 있던 값
```

큰 화면에서 **「폰 화면을 늘려 놓은 것」**처럼 보였습니다.
★ **새 값을 만든 게 아닙니다** — 원래 있던 값을 **안 쓰고** 있었습니다.
⚠ **본사 화면(첫 페이지·에디터·어드민)은 한 픽셀도 안 바뀝니다** — 실측으로 확인했습니다.

### 그리고 **검게 들어갔다 다시 밝게 나옵니다**

히어로의 마지막 한 뼘이 **검게 잠기고**, 무대가 끝나면 검정이 **다음 섹션 색으로 풀립니다.**

★ 바꾼 규칙은 `docs/DESIGN.md` 에 **§10 「고객 사이트 뼈대 규칙」**으로 새로 적었습니다.
전에는 「손님 사이트는 별개다」 한 줄뿐이라 **여백·띠·전환에 규칙이 아예 없었습니다.** 그게 뿌리였습니다.
