## 1. 권반장님 근거와, 그것이 어긋나는 지점

> 권반장: 「판정이 맞다는 것이 확인됐다 ✅ / **그리고 지금 설계는 «감추지 않고 알리기만» 이다** ✅ ← 이것이 핵심입니다
> ⇒ 비공개를 「없다」로 잡아도 **링크가 사라지지 않습니다.** 알림 문구가 한 번 더 뜰 뿐입니다」

🔴 **「감추지 않고 알리기만」은 «다른 파일» 이야기입니다.**

| 파일 | 무엇을 하나 |
|---|---|
| `app/api/site/videos/recheck/route.ts` (사장님이 편집화면 열 때) | **알리기만.** `remote_deleted_at` 을 **일부러 안 씁니다** — [48]① 에서 그렇게 만들었습니다 |
| **`lib/sns/maintenance.ts` (크론) ← `RECHECK_AFTER_DAYS` 가 사는 곳** | 🔴 **감춥니다.** `gone` 이면 `remote_deleted_at` 을 **적습니다** |

**확인한 자리(코드에서 직접 읽었습니다):**


> 「🔴 다만 못 박아 둡니다: **「감추기」로 바꾸는 날에는 «주기를 다시 늘릴지» 먼저 따지십시오.

## 3. 무엇이 확인됐고 무엇이 «아직»인가

| | |
|---|---|
| ✅ **지운 글은 맞게 잡는다** | 토큰 진단: 토큰 살아 있고 미디어 144건 다 읽히는데 **그 3건만 없다.** 게다가 2026-09-12 회장님이 직접 지우신 글을 **3시간 만에** 잡아낸 기록이 우리 DB 에 있다(권반장님이 찾아 주심) |
| ❌ **«비공개» 글을 어떻게 읽는지 모른다** | **아무도 시험하지 못했다.** 비공개가 「없다」로 읽히면 **멀쩡한 링크가 사라진다** |

⇒ **비공개 시험이 끝나면 그때 줄입니다.** 권반장님이 대표님께 「글 하나를 비공개로 바꿔 주십시오」를
올리기로 하셨습니다. **그 답이 이 숫자의 열쇠입니다.**

## 4. ⚠ 「호출이 안 는다」는 근거가 못 됩니다

권반장님 말씀대로 **호출 수는 안 늡니다** — `RECHECK_LIMIT(50)` 이 이미 막고, 크론은 하루 한 번이라
며칠짜리로 바꾸든 **하루 최대 50건**으로 같습니다.
🔴 **하지만 걸린 것은 «요금»이 아니라 «정확도»입니다.** 바뀌는 것은 「같은 글을 얼마나 자주 다시 보나」이고,
자주 볼수록 **틀린 판정을 만날 기회가 늘어납니다.**
