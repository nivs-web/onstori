# 「영상을 한 벌만 저장하기」 — **못 했습니다. 사본이 낭비가 아니었습니다**

날짜: 2026-09-17 · 지시: 대표님 「앞으로 올라오는 것부터 한 벌만」 · 상태: **안 함 · 이유 아래**

---

## 0. 🔴 먼저 제 말을 바로잡습니다

오늘 낮에 제가 이렇게 말씀드렸습니다:

> 「"원본을 따로 둔다"는 원래 **변환(자막·압축) 원재료** 자리인데, **변환이 안 일어나서**
>  똑같은 파일이 두 벌 남습니다」

**이 말은 불완전했습니다.** 만들기 전에 코드를 끝까지 읽었더니 **사본에는 «진짜 할 일»이 둘 있었습니다.**
대표님은 제 설명을 믿고 「한 벌만」을 고르셨는데, **전제가 틀렸으니 먼저 말씀드리는 것이 맞습니다.**

## 1. 사본이 왜 있나 — 이유 둘 (코드에서 확인)

### ① 공개 자리에는 «바로 못 올린다» — 올리면 캐시가 안 붙는다

`lib/storage.ts` 에 이전 세션이 적어 둔 실측입니다:

```
(브라우저가 쓰는 서명 PUT URL 에는 Cache-Control 을 못 넣는다 — 넣으면 403 이다.
 처음부터 공개에 올리는 길을 못 쓰는 이유가 이것이다.)
```

⇒ 폰에서 바로 공개 자리로 올리면 **「1년 보관」 딱지를 못 붙입니다.**
  복사(`CopyObject` + `MetadataDirective:"REPLACE"`)를 **거쳐야만** 그 딱지가 붙습니다.
  🔴 그 딱지가 없으면 **손님이 영상을 볼 때마다 새로 내려받습니다** — 느려지고, 통신량이 늡니다.

### ② 비공개 원본을 «발행 뒤에도» 세 곳이 읽고 있다

| 읽는 곳 | 무엇에 |
|---|---|
| `api/site/videos` | 사장님 편집화면의 **영상 목록**(`video_key` 로 고른다) + **미리보기 서명 주소(10분)** |
| `api/sns/publish` · `publish/poll` | **인스타·유튜브에 올릴 때** 이 주소를 쓴다 |
| (앞으로) 자막 워커 STEP 4 | 아직 안 만들었지만 원본이 필요하다 |

🔴 **그래서 발행 뒤에 비공개 원본을 지우면 — 편집화면 목록이 비고, SNS 올리기가 깨집니다.**

## 2. 그래서 「한 벌만」은 «한 줄»이 아닙니다

| 길 | 되나 | 값 |
|---|---|---|
| **A. 처음부터 공개 자리에 올린다** | ❌ | 캐시 딱지를 못 붙인다(위 ①). 게다가 **안 쓰기로 한 녹화까지 공개 주소**가 된다 |
| **B. 비공개만 두고 서명 주소로 보여 준다** | ❌ | 서명 주소는 **시간이 지나면 죽는다.** 손님 홈페이지의 영상이 나중에 안 나온다 |
| **C. 걸 때 «옮기고»(복사 후 원본 삭제) 읽는 곳을 공개 주소로 돌린다** | ⭕ | 🔴 **네 파일 이상** — 그중 하나가 **인스타에 실제로 글을 올리는 길**이다 |

## 3. 🔴 그래서 오늘은 «안 만들었습니다»

`CLAUDE.md` §2-0 의 「안 만들어도 되는 셋」 중 **③ 있으면 해가 되는 것** 에 해당합니다.

- 긴 작업의 끝에서 **SNS 발행 길을 검증 없이 건드리면** 사장님 글이 안 올라가는 사고가 납니다
- **급하지 않습니다** — 지금은 0원 구간이고, 사장님이 적습니다
- **C 를 하려면 한 마디를 통째로** 잡아야 합니다(검증 포함)

## 4. ⚠ 다만 — **숫자는 그대로 사실입니다**

| | |
|---|---|
| 겹쳐 쓰는 양 | **58.55MB / 전체 127.16MB = 46%** |
| 60초 영상 한 편의 실제 저장량 | **약 90MB**(45MB × 2) |

**요금을 셀 때는 여전히 «두 배»로 계산해야 합니다.** 그건 안 바뀌었습니다.
바뀐 것은 **「그 두 배가 낭비다」가 아니라 「그 두 배에 이유가 있다」**는 것입니다.

## 5. 다음에 할 일 (C 를 할 때)

1. 편집화면 미리보기를 **공개 주소**로 돌린다(걸린 영상만 — 안 걸린 것은 여전히 서명 주소)
2. SNS 발행이 읽는 주소를 **공개 주소**로 돌린다 ← **여기가 제일 위험하다. 실제로 올려 봐야 한다**
3. `publicVideoKeyOf` / `parseStoryKey` 가 **공개 키도 알아보게** 고친다
   (지금은 비공개 키 모양만 읽는다 — 그대로 두면 **목록에서 영상이 사라진다**)
4. 그다음에야 걸 때 원본을 지운다
