# 지시 [49]② — ⌃⌄ 와 점 표시기의 5px 겹침

날짜: 2026-09-17 · 요청: 권반장 · 상태: 처리함

---

## 1. 원인 (확정)

```
.world-rail   (점 표시기)  right: 24px · top: 50%
.world-arrow  (⌃⌄)        right: 24px · top: 50%
```

**둘이 같은 자리였습니다.** 막대 폭이 **5px** 라 **단추(40px) 안에 통째로 들어가** 있었습니다.
그것이 그 「5px 겹침」입니다. 세로로도 30px 겹쳤습니다.

## 2. 어떻게 풀었나 — **없애지 않고 «자리»로 갈랐다**

🔴 **점 표시기를 없애지 않았습니다.** 대표님이 기획서에 **두 번** 명시하셨습니다(권반장 재확인).

대표님 캡처④(인스타 PC)대로 나눴습니다:

| | 어디 | 값 |
|---|---|---|
| ⌃⌄ | 영상 **바깥** · 화면 가장자리 | `right: 16px` (화면 기준) |
| 점 표시기 | 영상 **안** 오른쪽 가운데 | `right: 16px` (프레임 기준) |

## 3. ⚠ ⌃⌄ 를 «프레임 밖»으로 옮겨야 했습니다 — 그냥 밀면 안 됩니다

`.world-frame` 에 **`overflow: hidden`** 이 걸려 있습니다.
🔴 **프레임 «안»에 둔 채 바깥으로 밀면 «잘려서 안 보입니다».**
⇒ 단추를 `.world`(화면 전체)의 **직계 자식**으로 옮겼습니다.

- `position:absolute` 라 **grid 흐름에서 빠집니다** — `.world` 의 가운데 정렬이 안 흔들립니다
- **바깥을 눌러 닫는 길도 안 막힙니다** — 단추를 누르면 `target` 이 단추라 닫기가 안 걸립니다

## 4. 🔴 «자리가 없으면 아예 안 그린다» — 조건 둘

```css
.world-arrow { display: none; }
@media (min-width: 768px) and (min-aspect-ratio: 7/10) { .world-arrow { display: grid; } }
```

**① 폰에서 숨기는 이유** (권반장님이 「근거를 코드에 적어 두라」 하신 것):
- 인스타도 **폰에는 ⌃⌄ 가 없습니다** — 손가락으로 쓸면 됩니다(우리도 쓸기가 됩니다)
- 폰은 영상이 화면을 꽉 채워 **「영상 바깥」이라는 자리 자체가 없습니다**
- 억지로 안에 넣으면 **점 표시기와 다시 겹칩니다**

**② 세로로 긴 창에서 숨기는 이유** (제가 더한 것):
영상 프레임은 `aspect-ratio: 9/16` · `height: 100svh` 라 **창이 세로로 길수록 넓어집니다.**
너무 길면 프레임이 **화면 폭을 꽉 채워** 「바깥」이 사라지고 단추가 **영상 위로 다시 올라탑니다.**
7/10 인 이유는 CSS 주석에 계산과 함께 적었습니다.

## 5. 실측 (브라우저에서 직접 쟀습니다)

| 창 | 비율 | 결과 |
|---|---|---|
| PC 1280×800 | 1.60 | 프레임 `[415..865]` · ⌃ `[1224..1264]` → **완전히 바깥** · 겹침 **0** ✅ |
| 폰 390×844 | 0.46 | ⌃⌄ `none` · 점 표시기 `flex` ✅ |
| 세로로 긴 800×1250 | 0.64 | 프레임이 폭 800 중 **703** 을 먹음 → ⌃⌄ `none` ✅ (막이 없었으면 겹쳤습니다) |

점 표시기도 프레임 안 **16px**(865−849)로 정확히 들어갔습니다.

## 6. ⚠ 걱정되는 점 — **영상에서 359px 이나 떨어져 있습니다**

1280 화면에서 영상은 `[415..865]`, ⌃⌄ 는 `[1224..1264]` 입니다 — **사이가 359px.**
규격서 문구(「화면 맨 오른쪽 가장자리 · `right: 8~16px`」)는 **그대로 지켰습니다만**,
손님 눈은 영상에 있는데 단추가 **화면 끝**에 있습니다. 넓은 모니터일수록 더 멀어집니다.

🔴 **대안이 있습니다 — 「영상 바로 옆」에 붙이기.** CSS 한 줄입니다:

```css
right: max(16px, calc(50vw - min(50vw, 28.125svh) - 56px));
```

**영상 오른쪽 가장자리에서 56px** 자리에 붙고, 좁아지면 저절로 화면 끝(16px)으로 물러납니다.
**어느 쪽이 대표님 캡처와 같은지는 캡처를 본 사람만 압니다** — 권반장님께 여쭸습니다.
