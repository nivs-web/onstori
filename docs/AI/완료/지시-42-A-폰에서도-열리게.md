# 지시 [42] (A) — **폰에서 눌러도 큰 화면이 열립니다**

**날짜:** 2026-09-17 (밤) · **권반장 §3 의 ①②③ 까지만 했습니다. ④(「전부 보기」 빼기)는 «안 했습니다».**
**한 줄:** 폰 손님이 **10편 너머를 못 보던 것**이 풀렸습니다.

---

## 1. 무엇이 막혀 있었나

```
폰에서 영상을 누르면 → 「소리만 켜짐」. 큰 화면이 «안 열림»
⇒ 폰 손님은 무대에 선 앞 10편만 보고 끝났습니다. 우리 손님 대부분이 폰입니다
```

**[33] 의 「폰은 이대로 좋아」**가 그대로 살아 있었습니다.
🔴 **대표님이 이번 기획에서 그것을 덮으셨습니다**(권반장 전달 · 기획서 원문):

> 「**전부 보기가, 즉 몰입모드야, 몰입모드는 스피커 소리를 틀기 위해서라도 «무조건 열리게 만들어야 함».**
>  그리고 몰입모드 들어가면 모든 영상 다 볼 수 있어야 함」
> 「**어떤 상황에서든 클릭을 1번이라도 하게 되면 … 들어감**」

## 2. ① 먼저 잰 것 — **소리 끄는 길이 사라지지 않는가**

권반장님이 「그것부터 보라」 하신 항목입니다. 폰 탭이 **소리 토글**이었으니, 그걸 빼앗으면
**사무실·지하철에서 소리를 못 끄는** 사고가 납니다([36] 에서 잡았던 바로 그것).

**잰 값(폰 375×812):**
```
.stage-sound  →  있음 · display:grid · opacity 1 · 크기 56×56 · 「🔇」
```
⇒ **폰에서도 스피커 단추가 또렷이 보입니다. 소리는 그 단추가 맡습니다.**
★ 찾아보니 `display:none` 규칙은 **「움직임 줄이기」 안에만** 있었습니다 —
  거기서는 영상에 **진짜 재생바**가 붙으므로 숨기는 것이 맞습니다.

⇒ **스피커 단추를 새로 만들 필요가 없었습니다.** 그대로 ②로 갔습니다.

## 3. ② 고친 것

```
전 : 마우스 기기면 → 큰 화면 열기 / 폰이면 → 소리 토글
후 : 🔴 «어느 기기에서든» 누르면 큰 화면이 열린다 (소리는 스피커 단추가 맡는다)
```
⚠ **「움직임 줄이기」를 켠 손님에게는 여전히 안 엽니다** — 그분들은 큰 움직임을 싫어하십니다.

## 4. ③ 폰에서 **실제로** 확인했습니다

```
기기            hover:false · pointer:coarse   (폰)
누르기 전        세상 없음
🔴 영상을 누르니  ✅ 열렸다 · 「1 / 8」
소리 단추        🔊 (몰입 화면 안)
나가는 길        우상 ✕ ✅ · 우하 ✕ ✅
나가기 누르니     ✅ 닫힘
무대 스피커       ✅ 그대로 있음 (소리 끄는 길이 남아 있다)
```

**PC 도 다시 쟀습니다:** `hover:true` · 누르니 **✅ 열림 · 1 / 8** — **전과 같습니다.**

## 5. 🔴 ④ 「전부 보기」 빼기 — **안 했습니다**

권반장님 순서 그대로입니다. ③ 을 보고드린 **뒤에** 뺍니다.
⚠ 그리고 그건 **권반장님 판단**이지 대표님이 빼라고 하신 적은 없습니다 — 그 점도 그대로 적어 둡니다.

## 6. ⚠ 못 한 것

| 무엇 | 왜 |
|---|---|
| **진짜 폰이 아닙니다** | PC 크롬에 폰 탈을 씌운 것입니다. **탭은 «코드로 만든 클릭»**입니다 |
| **진짜 소리를 못 들었습니다** | 시험용 브라우저는 소리를 내지 않습니다 |
| 🔴 **「소리 들으려고 눌렀는데 큰 화면이 열린다」가 손님에게 어떻게 느껴질지** | 기획대로입니다만, **놀라실 수도** 있습니다. 대표님이 폰으로 한 번 눌러 보셔야 합니다 |
