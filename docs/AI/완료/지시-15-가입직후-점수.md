# 지시 [15] · 가입 직후 완성도 점수 — 숫자로 확인

| | |
|---|---|
| 상태 | **처리함** · 2026-09-16 · 클코 |
| 성격 | **«만들지 말라»는 지시.** 코드를 **한 줄도 안 고쳤습니다** |
| 확인 방법 | 진짜 가입을 **네 번** 끝까지 통과시키고 DB 를 직접 읽었습니다 |
| 🔴 결론 | **70점이 아닙니다. 사장님에 따라 «50·60·70» 셋으로 갈립니다.** 다만 **셋 다 75점을 못 넘습니다** — 대표님이 원하신 「뭔가 수정을 해야만」은 지켜집니다 |

---

## 1. 실측 — 가입을 네 번 끝까지 통과시켰습니다

| # | 「시작한 이유」 | 영상 | **점수** | 붙은 규칙 |
|---|---|---|---|---|
| A | 안 씀 | 안 찍음 | **50** | hero_text · contact · cta_form · logo · published |
| B | 안 씀 | **찍음** | **60** | 위 + **first_video** |
| C | **씀** | 안 찍음 | **60** | 위(A) + **story_1** |
| D | **씀** | **찍음** | **70** | 위 전부 |

⇒ **[13] 의 관문을 통과한 사장님은 「시작한 이유」를 쓰셨으면 70점, 안 쓰셨으면 60점입니다.**

---

## 2. 🔴 권반장 점수표에서 **두 군데가 어긋나 있었습니다**

두 오차가 **서로 상쇄돼** 「70점」이라는 답이 우연히 맞았습니다.

| 항목 | 권반장 표 | **실측** |
|---|---|---|
| **연결 버튼 (10점)** | ✅ 가입에서 자동 | 🔴 **안 붙습니다.** 네 번 다 `위젯 수 0` 이었습니다 |
| **첫 스토리 (10점)** | ❌ 안 붙음 | 🔴 **「시작한 이유」를 쓰면 붙습니다** |

### ① 연결 버튼(`widget_1`) — **가입은 위젯을 하나도 안 만듭니다**

판정은 `doc.widgets.length > 0` 인데(`lib/score.ts:45`), 저장소 전체에서 `widgets` 를
**만드는 코드는 편집화면의 「연결」 메뉴(`WidgetsPanel`) 하나뿐**입니다.
`app/api/generate` 도 `lib/generate.ts` 도 그 칸을 만들지 않습니다.

> 근거: 먼저 가입한 `peliz`·`bareunjeongi` 도 **50점**이고 규칙에 `widget_1` 이 없습니다.
> `sample-interior` 만 `widget_1` 이 있는데, 그건 **사람이 편집화면에서 켠 것**입니다.

⚠ 문의 채널(CTA) 단계를 고르셔도 안 붙습니다 — CTA 는 `settings.ctaChannels` 와
  `quoteForm` 섹션으로 가고 `widgets` 와는 **다른 칸**입니다.

### ② 첫 스토리(`story_1`) — **AI 가 지어 준 첫 이야기가 «보임»으로 들어갑니다**

가입 3단계의 **「시작한 이유」(선택 칸)** 를 채우면, AI 가 그것을 1인칭 이야기로 다듬어
`story_entries` 에 한 줄 넣습니다(`app/api/generate/route.ts:246`).
그때 **`visible` 을 안 적어서 DB 기본값 `true`** 로 들어갑니다
(`supabase/migrations/20260831120000_core.sql` — `visible boolean not null default true`).

⇒ `storyCount >= 1` → **`story_1`(10점)이 가입에서 저절로 붙습니다.**

**실측(C):** 스토리 1개 · **보임 1** · 규칙에 `story_1` **있음**.

---

## 3. ✅ 권반장이 물으신 핵심 — **영상은 `story_1` 을 «안» 붙입니다**

> 「영상을 찍으면 `story_1` 이 같이 붙는지 **눈으로** 확인해 주십시오. 붙으면 80점이 되어
> 관문이 사라집니다. **이게 이 지시의 핵심입니다.**」

**안 붙습니다. 권반장 예측이 맞았습니다.** 실측(B):

```
zz-gate-test-b | 점수 60 | ["hero_text","first_video","contact","cta_form","logo","published"]
   스토리 1개 · 보임 0    ← visible=false 라 story_1 조건(보이는 스토리 ≥1)에 안 걸린다
```

- 녹화 제출(`api/story/submit`)은 `visible: false` 로 넣습니다.
- 「홈페이지에 걸기」도 `visible` 을 **안 건드립니다**(그 파일 주석이 같은 이유를 적어 두었습니다).
- `first_video` 만 붙습니다 — 그쪽은 `visible` 과 무관하게 `video_key` 로 셉니다.

⇒ **80점이 되는 길은 없습니다. 관문은 사라지지 않습니다.**

---

## 4. 시키신 대로 «안» 한 것

| 시키신 것 | 지켰나 |
|---|---|
| 가입 스텝에 **영업시간을 넣지 않는다** | ✅ 안 넣었습니다 |
| **점수 규칙을 고치지 않는다** | ✅ `config/completeness.ts` 무수정 |
| 아무것도 더 만들지 않는다 | ✅ 이 지시로는 코드 **0줄** |

## 5. 🔴 그래서 대표님께 — 정해 주셔야 할 것 하나

대표님 결정은 「**가입 하자마자 75점 되는 건 반대. 뭔가 수정을 해야만 하는 걸로 가자.**」였습니다.
**그 결정은 지금 지켜집니다** — 최고가 70점이라 어떤 사장님도 가입만으로 75를 못 넘습니다.

**다만 사장님마다 출발점이 다릅니다:**

| 사장님 | 출발 | 75점까지 |
|---|---|---|
| 「시작한 이유」를 쓰신 분 | **70점** | 영업시간(5) **하나만** 채우면 넘습니다 |
| 안 쓰신 분 | **60점** | 연결 버튼(10) + 영업시간(5), 또는 첫 스토리(10) + 영업시간(5) |

> **이대로 두실까요?** 저는 **두셔도 된다**고 봅니다 — 「시작한 이유」를 적어 주신 분은
> 실제로 홈페이지가 더 채워져 있으니 점수가 높은 것이 **사실과 맞습니다.**
>
> 🔴 다만 **「연결 버튼 10점은 가입에서 절대 안 붙는다」**는 것은 알고 계셔야 합니다.
> 권반장 표가 그걸 「자동」으로 보고 계산했기 때문에, 앞으로 점수를 셈하실 때
> **그 10점을 빼고** 보셔야 맞습니다.

## 6. 못 한 것 · 걱정거리

1. **업종을 하나(인테리어)로만 봤습니다.** 템플릿이 다르면(`visit`·`book` 등)
   `quoteForm` 섹션이 없어 `cta_form`(10점)이 안 붙을 수 있습니다 — **그러면 더 낮아집니다.**
   75를 넘길 위험은 없으니 급하지 않다고 보아 안 쟀습니다.
2. ✅ **사진 15장을 올려도 점수는 안 오릅니다 — 코드로 확인했습니다.**
   제 테스트는 사진 단계를 「건너뛰기」로 지났기에 **따로 읽어서 확인**했습니다.
   `app/api/site/photos` 는 올린 사진을 **갤러리 섹션**에 넣고 `story_entries.photos` 는
   건드리지 않습니다. 그 파일 머리말이 같은 말을 적어 두었습니다 —
   「완성도 점수 규칙(`lib/score.ts` `photo_real`)은 손대지 않는다. 그 규칙은 `story_entries.photos`」.
   ⇒ `photo_real`(15점)은 가입에서 **안 붙습니다.** 최고는 여전히 **70점**입니다.
   ⚠ 다만 **직접 올려서 재 보지는 않았습니다.** 코드 근거만입니다.
3. **테스트 홈페이지 넷**(`zz-gate-test-a`·`-b`·`-c`·`-off`)이 운영 DB 에 생겼습니다.
   지우지 않고 **`status='suspended'`** 로 돌려 두었습니다(불변 규칙 10). 원본은 백업했습니다.
   🔴 지울지는 권반장이 정해 주십시오.
