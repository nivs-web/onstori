# 지시 [49]① — 이모지를 SVG 아이콘 아홉 개로

날짜: 2026-09-17 · 요청: 권반장(규격서 `15-인스타릴스-UI정밀해부.md` §3) · 상태: 처리함

> 권반장님: 「보고서의 SVG 를 **그대로** 쓰십시오. 24×24 · `stroke` · `currentColor`.
> ⚠ **기존 원형 배지의 크기·자리는 바꾸지 마십시오** — 좌상 🔊 와 우상 ✕ 의 **완벽한 대칭이 이미
> 맞아 있습니다.** **안에 든 그림만** 갈아 끼우십시오」

---

## 1. 무엇을 했나

**글자로 찍던 것 일곱 자리를 «우리가 그린 그림»으로 바꿨습니다.**

| 옛것 | 새것 | 들어간 자리 |
|---|---|---|
| 🔊 🔇 | ① 소리 켜짐 · ② 꺼짐(사선) | 무대 우상 · 몰입 좌상 · 카드 우상 |
| ✕ | ⑦ 닫기 | 몰입 우상 · 우하 「숏폼에서 나가기」 |
| ⌃ ⌄ | ③ 위 · ④ 아래 | 몰입 오른쪽 가운데 |
| ‹ › | ⑧ 왼쪽 · ⑨ 오른쪽 | 카드형태 좌우 |
| — | ⑤ 하트 · ⑥ 말풍선 | **아직 안 붙임**(아래 §3) |

**왜 바꾸나:** 글자는 **기기가 제 마음대로 그립니다.** 🔊 는 기기에 따라 **색깔 이모지**로 나와
검은 배지 위에서 혼자 튀고, `⌃⌄` 는 이모지도 아닌 기호라 글꼴이 없으면 **네모(□)로 깨집니다.**
그림으로 바꾸면 어느 기기에서나 **같은 모양·같은 색**입니다.

## 2. 🔴 크기를 «두 곳»에 적지 않았습니다 — `1em` 입니다

각 단추의 크기는 **이미 CSS 에 `font-size` 로 적혀 있습니다.** 그래서 그림을 **`1em`** 으로 그렸습니다
— **그 `font-size` 가 그대로 그림 크기가 됩니다.**
숫자를 SVG 에도 박으면 크기가 적힌 자리가 둘이 되고, CSS 만 고친 사람이 「왜 안 바뀌지」 하게 됩니다.

**실측(브라우저에서 직접 쟀습니다):**

| 자리 | 배지 | 아이콘 | 규격서 값 | |
|---|---|---|---|---|
| `.stage-sound` | 56px | **26px** | 56 / 26 | ✅ 일치 |
| `.world-sound` · `.world-x` | 48px | **22px** | 48 / 22 | ✅ 일치 |
| `.world-arrow` ⌃⌄ | 40px | **20px** | (②에서 48/22 로 갈 자리) | 그대로 둠 |
| `.world-exit-x` | — | **26px** | (표에 없음) | 그대로 둠 |

**좌상 소리 ↔ 우상 ✕ 대칭도 실측했습니다 — 왼쪽 여백 17px · 오른쪽 여백 17px · ✅ 안 깨졌습니다.**

## 3. 🔴 못 한 것 · 일부러 안 한 것

| | |
|---|---|
| **⑤ 하트 · ⑥ 말풍선을 화면에 «안 붙였다»** | 들어갈 자리(리액션 막대)가 **[49]③** 이고, 숫자는 **[46]** 뒤입니다. 대표님이 「아홉 개를 각각 그리라」 하셔서 **그리기는 아홉 개 다 했고**, 붙이는 것만 남겼습니다 |
| **⌃⌄ 와 리액션 막대의 5px 겹침은 «그대로»** | 그건 **[49]②** 입니다. 권반장님이 **「① 만 하고 보고하라」** 하셔서 손대지 않았습니다 |
| **로고(인스타·유튜브 마크)는 안 그렸다** | 상표라 따라 그리면 안 됩니다(권반장 §2) |
| **화면 캡처를 못 남겼다** | 내장 브라우저 창이 숨어 있으면 캡처가 **빈 화면**으로 나옵니다. 대신 **크기·SVG 유무·대칭을 숫자로 쟀고**, 보시라고 `지시-49-1-아이콘-미리보기.html` 을 따로 만들었습니다 |

## 4. ⚠ 한 가지, 「바꾸지 말라」의 «경계»에 있는 것을 먼저 말씀드립니다

**카드형태 좌우 화살표(`.shorts-arrow`)의 «아이콘 크기»만 26px → 22px 로 줄였습니다.**

- **배지(44px)와 자리는 안 건드렸습니다.** 줄인 것은 **안에 든 그림**입니다.
- **왜:** 옛 `‹` 는 **글자**라 26px 로 적어도 **실제 먹은 그보다 훨씬 작습니다**(글자 둘레의 여백).
  그 자리에 26px 짜리 **그림**을 그대로 넣으면 **갑자기 커 보입니다** — 같은 숫자인데 결과가 다릅니다.
- **근거:** 권반장님 규격서 §3 배지 표에 **「카드형태 좌우 ‹› : 44px 배지 · 22px 아이콘」** 이라고
  적혀 있습니다. 코드가 26px 이라 **규격서와 코드가 어긋나 있던 자리**입니다. 규격서를 따랐습니다.
- 🔴 **아니라고 하시면 한 줄 되돌립니다**(`app/globals.css` 의 `.shorts-arrow`).
