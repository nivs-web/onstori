## 1. 🔴 막힌 것 — **공식 로고 파일이 없습니다. 그리고 그것 없이는 «옮기기»도 안 됩니다**

권반장님 배치는 이것입니다:

```
[인스타 로고] ♡128  💬14
[쇼츠 로고]   ♡47   💬3
```

**이 줄은 «작은 로고 마크»를 전제합니다.** 그런데 —

### ① 저장소에 인스타·유튜브 로고가 없습니다

`public/brand/` 에는 **온스토리 로고만** 있습니다. 인스타·유튜브 마크는 한 장도 없습니다.

### ② 그리고 «직접 그리면 안 됩니다» — 권반장님 조사가 그렇게 정했습니다

> 규격서 §2-5: **인스타/유튜브 로고**(브랜드 마크) — ❌ 직접 그리면 안 됨 ·
> **Meta·구글 공식 브랜드 파일을 내려받아 그대로 사용**

### ③ 게다가 지금 코드에는 «로고를 안 쓴다»는 반대 결정이 박혀 있습니다

`components/sections/sns-brand.ts`:

```
⚠ 로고 그림을 쓰지 않는다 — 상표 문제가 생긴다. 색 점 하나와 글자로만 구분한다
  (channel-widget.tsx 가 같은 이유로 직접 그린 도형을 쓴다).
```

### ⇒ 그래서 «옮기기»도 못 했습니다

로고가 없으니 그 자리에 쓸 수 있는 것은 지금의 **「● 인스타에서 보기」** 뿐입니다.
**그 글자는 알약 하나가 120px 가까이 됩니다** — 우측 세로줄에 넣으면 **영상을 가립니다.**
로고 마크(20px 남짓)를 전제한 배치라서, **로고가 와야 옮길 수 있습니다.**

🔴 **그리고 옮기는 것은 «손님 화면의 글 자리»를 바꾸는 일**이고, 지금 자리는
**대표님이 [42] §2 에서 직접 정하신 것**입니다(「좌측 아래는 [인스타에서 보기] …」).
**로고 없이 임의로 옮기지 않았습니다.**

## 2. ✅ 한 것 — ♡·💬 의 «자리와 모양»

### 데이터 칸을 만들었습니다 (`lib/shorts.ts`)

```ts
likes?: number;      // [46] 이 채운다
comments?: number;   // [46] 이 채운다
```

🔴 **`0` 과 `undefined` 를 갈라 뒀습니다.**
`0` = 「세어 봤더니 0」 · `undefined` = 「아직 안 세어 봤다」.
**둘 다 안 그리지만 뜻이 다릅니다** — 다음 사람이 헷갈리지 않게 주석에 적었습니다.

### 화면 (`shorts-world.tsx` 의 `Reactions`)

- **둘 다 없으면 칸 자체를 안 만듭니다** — 빈 칸이 남으면 알약 옆이 어색하게 벌어집니다
- **0 이면 안 그립니다** — 「♡ 0」은 「아무도 안 좋아했다」로 읽힙니다(권반장 지시)
- ⑤하트·⑥말풍선은 **[49]① 에서 그려 둔 것을 씁니다**(새로 안 그렸습니다)

### 🔴 원형 배지를 «안» 줬습니다 — 이유

**우리 ♡ 는 누르는 단추가 아니라 «보여주는 표시»입니다.**
둥근 단추 모양을 주면 손님이 **누르면 좋아요가 되는 줄** 압니다. 그래서 글자+아이콘만입니다.
