## 1. 🔴 먼저 정정 — 「해지 버튼이 없다」는 사실과 다릅니다

> 권반장님: 「우리 약관 제5조가 이미 「해지는 마이페이지 버튼 한 번」이라고 써 있습니다.
> **그 버튼이 없어서 지금 약관이 거짓말을 하고 있습니다.**」

**버튼은 있습니다.** `app/my/ui.tsx:76` 의 `CancelSubscription` 이고, 정회원이면
마이페이지에 **1뎁스로** 떠 있습니다(`ui.tsx:37`). 약관 파일 주석에도 그렇게 적혀 있습니다
(`⑤ 해지 버튼 → app/my/ui.tsx CancelSubscription → api/billing/cancel`).

**실측 — 시험용 사장님으로 진짜 로그인해서 본 화면:**

```
② 로그인해서 간 곳 : /my
③ 마이페이지에 보이는 버튼 : ['수정하기', '보러가기', '결제 관리', '구독 해지']
```

⇒ 대표님이 말씀하신 **세 걸음 중 ①과 ③은 이미 있었습니다.**
**빠진 것은 가운데 ② — 「해지 안내 페이지」**였습니다. 전에는 **한 줄**이 전부였습니다:

> 「다음 달부터 청구되지 않습니다. 이미 결제하신 **달**은 그대로 쓰실 수 있어요.」

권반장님이 적어 주신 **다섯 가지 중 «넷»이 없었습니다** — 홈페이지는 어떻게 되는지,
자료는 어떻게 되는지, 환불은 되는지, 다시 오려면 어떻게 하는지.

## 2. ② 해지 안내 화면 — **약관 제5조에서 그대로 옮겼습니다**

**실제로 뜨는 화면 그대로:**

```
해지하면 이렇게 됩니다

언제까지 쓰나요 — 이미 결제하신 회차는 3월 15일까지 그대로 쓰십니다.
                 다음 회차부터 청구되지 않고, 위약금·해지 수수료는 없습니다.
홈페이지는요   — 그 회차가 끝나면 비공개로 바뀝니다. 지워지지 않습니다.
제 자료는요    — 그대로 보관됩니다.
다시 오시려면  — 결제 한 번이면 바로 다시 공개됩니다.
환불되나요     — 결제하신 날부터 7일 이내면 그 회차 금액을 전액 돌려드립니다.
                 그 뒤에는 남은 기간을 그대로 쓰시는 것입니다. [환불 규정 보기]

               [ 그대로 두기 ]  [ 해지하기 ]
```

🔴 **새로 쓰지 않았습니다.** 다섯 줄 모두 **약관 제5조 ③④⑤**의 문장을 옮긴 것입니다.
그리고 **［환불 규정 보기］**를 달아 **제5조를 바로 열 수 있게** 했습니다 —
사장님이 두 글을 **맞대 볼 수 있어야** 합니다. (약관 제5조에 `#refund` 표만 붙였습니다.
🔴 **법률 문구는 한 글자도 안 건드렸습니다.**)

### 🔴 「○월 ○일까지」가 진짜 날짜로 뜹니다

전에는 **해지한 «뒤»에야** 날짜를 알 수 있어, 안내가 「이미 결제하신 **달**」로 뭉뚱그려졌습니다.
⇒ **누르기 «전»에** 읽어 오는 길(`GET /api/billing/cancel`)을 만들었습니다.

```
② 누르기 전에 날짜를 읽나 : 200 {"active":true,"paidUntil":"2099-03-15T00:00:00+00:00"}
⑤ 해지한 뒤 화면이 한 말   : 해지됐습니다. 3월 15일까지는 그대로 쓰실 수 있어요.
```

⚠ 날짜를 **못 읽어도 화면은 열립니다.** 날짜 하나 때문에 해지를 막으면 그게 더 나쁩니다.

## 3. 🔴 「절대 하지 마라」 다섯 — **실측으로 확인했습니다**

| 금지 | 실측 |
|---|---|
| **가입보다 어려우면 안 된다** | ✅ 마이페이지에서 **［구독 해지］ → ［해지하기］ 두 번**이면 끝납니다 |
| **「정말요?」를 여러 번 묻지 마라** | ✅ 확인 버튼은 **둘뿐** — `['그대로 두기', '해지하기']`. 한 번입니다 |
| **숨기거나 흐리게 하지 마라** | ✅ 두 버튼이 **같은 높이 34px · 같은 글자 13px · 같은 투명도 1** |
| **전화·메일로만 되게 하지 마라** | ✅ **화면에서 끝납니다** |
| **쿠폰으로 붙잡지 마라** | ✅ 붙잡는 안내가 **없습니다**(그런 것이 있지도 않습니다) |

## 4. 어드민 쪽 — **막은 자리에서 바로 풀립니다**

[23] 에서 자동결제가 살아 있으면 등급 내리기를 **409 로 막았는데**, 막힌 뒤
**어디서 푸는지**를 안 알려 줬습니다. 그 자리에 **［먼저 자동결제 해지하기］**를 띄웁니다.

**실측 — 「첫 유료 고객」 상황을 만들어 끝까지 돌렸습니다:**

```
③ 🔴 등급을 내리려 하면 : 409 「이 사장님은 자동결제가 걸려 있습니다. 먼저 해지해야 합니다.」
④ 그 자리에서 해지      : 200 {"ok":true,"paidUntil":"2099-03-15…"}
⑤ 🔴 이제 내려가나       : 200 {"from":"active","to":"trial"}
⑥ 결제 줄이 바뀌었나     : {"status":"canceled","canceled_at":"2026-09-17T02:55:58Z"}
   주간 문자도 꺼졌나     : {"on":false,…}   ← 그만두신 분께 문자가 계속 가면 안 됩니다
⑦ 해지된 뒤 다시 읽으면  : {"active":false,…}
```

⚠ **해지만 하고 등급은 안 내립니다.** 둘을 한 번에 해 버리면 「무엇을 눌렀는지」가 흐려집니다 —
해지한 뒤 ⬇ 를 다시 누르시면 그때는 막히지 않습니다.
⚠ **돈이 얽힌 자리라 확인창은 필수**로 뒀고, **한 번만** 묻습니다.

## 5. 🔴 「다음 결제가 정말 안 걸리는지」 — 권반장님이 제일 중요하다 하신 것

```
billing 의 그 줄 : status = "canceled" · canceled_at 찍힘 ✅
```

크론이 카드를 긁는 조회는 **`billing.status = 'active'` 인 줄**만 봅니다
(`api/cron/expire` 의 청구 블록 — 제가 [23] 때 읽고 확인한 자리입니다).
⇒ **`canceled` 로 바뀐 줄은 그 조회에 걸리지 않습니다.**

⚠ **다만 이것은 «코드를 읽어» 확인한 것이지 «크론을 돌려» 본 것이 아닙니다.**
크론을 실제로 쏘면 **진짜 문자가 나가고 진짜 카드를 긁습니다.** 그래서 안 돌렸습니다.

## 6. 🔴 못 한 것 · 걱정거리

### ① **진짜 결제·진짜 해지는 못 해 봤습니다**

시험용 결제 줄은 **가짜 빌링키**입니다(상태 `failed`·청구일 **2099년** — 크론이 긁는 것은
`active` 뿐이라 **돈이 움직일 길이 없습니다**). 끝나고 **지웠고 `billing` 행 0건**을 다시 셌습니다.
⇒ **토스에 실제로 해지 요청이 가는지**는 첫 유료 고객이 생겨야 압니다.
⚠ 지금 `api/billing/cancel` 은 **우리 장부의 줄을 `canceled` 로 바꿀 뿐**,
   **토스 쪽에 「빌링키를 폐기해 달라」고 보내지는 않습니다.** 우리가 안 긁으면 안 긁히는 구조라
   돈은 안 나갑니다만, **토스에 카드 정보가 남습니다.** 첫 유료 고객 전에 볼 만한 지점입니다.

### ② **환불은 여전히 «사람이 처리»합니다**

약관 제5조 ④는 「남은 기간만큼 지금 바로 돌려받고 그만두기를 원하시면 **메일·전화로 말씀해 주세요**」입니다.
**이 화면도 그대로입니다** — 화면에서 자동으로 일할 환불을 해 주지 않습니다.
🔴 **약관이 그렇게 써 있어서 그대로 뒀습니다.** 자동화하기 전에 그 문장을 바꾸면 안 됩니다.

### ③ ⚠ **7일·환불 조건 숫자는 화면에 «직접» 적혀 있습니다**

`lib/trial.ts` 에 그 값이 없어서입니다(요금·무료기간만 있습니다).
약관과 화면이 갈라질 위험이 **아주 조금** 있습니다. 🔴 **약관 파일을 못 고치므로**
제가 단일 출처로 묶지 못했습니다. **［환불 규정 보기］로 맞대 볼 수 있게** 한 것이 지금의 대비입니다.

### ④ **「해지 안내 화면」의 글은 손님이 보는 글입니다**

약관에서 옮긴 것이라 **새로 지어낸 문장은 없습니다**만, **읽는 말투로 다듬은 것**은 사실입니다.
(예: 약관 「이미 결제하신 회차는 마지막 날까지 그대로 쓰시고」 → 화면 「이미 결제하신 회차는
**3월 15일까지** 그대로 쓰십니다」) 🔴 **대표님이 한 번 봐 주십시오** — `docs/WAITING.md` 에 올렸습니다.

### ⑤ **한 사람이 홈페이지를 둘 가지면** 해지도 **각각**입니다

결제가 홈페이지 단위라 그렇습니다. 지금은 그런 분이 없어 문제가 안 됩니다.
