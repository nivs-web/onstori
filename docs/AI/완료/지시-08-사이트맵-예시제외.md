## 1. 실제로 위험했습니다 — 운영 DB 로 재 봤습니다

권반장 말씀이 **맞았습니다.** 지금 발행된 사이트는 셋이고, 그중 `sample-interior` 는 이렇습니다.

| 슬러그 | 상태 | 완성도 | 전화 | 첫 편집 |
|---|---|---|---|---|
| `peliz` | trial | 50 | 있음 | 없음 |
| **`sample-interior`** | **active** | **65** | **있음** | **2026-09-11** |
| `bareunjeongi` | trial | 50 | 있음 | 없음 |

`sample-interior` 는 **`active`(결제한 곳) 로 들어가 있고, 전화도 첫 편집도 있습니다.**
⇒ **완성도 문턱(75점) 하나만이 그것을 막고 있었습니다.** 지금 65점이라 우연히 걸렸을 뿐입니다.
유튜브 심사용으로 사진·글을 채우면 **75점을 넘어 그대로 사이트맵에 들어갑니다.**

### 눈으로 본 증거

문턱을 잠깐 60 으로 낮춰(=채워서 점수가 오른 상황을 흉내 내어) 사이트맵을 실제로 뽑아 봤습니다.

**고치기 «전»** — 없는 업체가 구글에 제출됩니다:
```
{"evt":"sitemap_skipped","skipped":{"low-score":2},"min":60}
엔트리 9개 … https://onstori.com/sample-interior   ← 🔴 실렸습니다
```

**고친 «뒤»** — 빠집니다:
```
{"evt":"sitemap_skipped","skipped":{"low-score":2,"sample":1},"min":60}
엔트리 8개 (sample-interior 없음)
```

문턱은 **75 로 원복해 두었습니다**(`lib/indexable.ts:24` 그대로).

## 2. 🔴 지시대로 «못» 한 것 하나 — `sites` 표에는 `sample` 칸이 없습니다

권반장 지시는 「`sites` 조회 `select` 에 `sample` 을 더하라」였습니다. **그대로 하면 안 됩니다.**

- `supabase/migrations/20260831120000_core.sql` 의 `create table sites` 에 **`sample` 칸이 없습니다.**
  그 뒤 어떤 마이그레이션도 그 칸을 더하지 않았습니다.
- `select` 에 없는 칸을 적으면 PostgREST 가 **400** 을 냅니다. 그 오류는 `app/sitemap.ts` 의
  `catch` 가 **조용히 삼킵니다**(그 자리는 「DB 불가 시 기본 엔트리만」이라 일부러 삼킵니다).
- ⇒ 결과는 **「예시 하나가 빠진다」가 아니라 「사이트맵이 통째로 빈다」** 였을 것입니다.
  손님 사이트 전부가 구글에서 사라집니다. **지시 [8] 을 글자대로 했으면 더 큰 사고였습니다.**

**대신 이렇게 했습니다.** 예시 여부의 **단일 출처는 `lib/sites.ts` 의 `SAMPLE_SLUGS`** 입니다
(2026-09-13 지시 13 이 그렇게 정해 두었고, `lib/jsonld.ts:37` 도 이 값에서 온 `site.sample` 을 씁니다).
그 집합을 그대로 가져다 `slug` 로 거릅니다 — **칸을 읽는 대신 목록으로 거릅니다.**

```ts
import { SAMPLE_SLUGS } from "@/lib/sites";
...
if (SAMPLE_SLUGS.has(s.slug as string)) { skipped.sample = (skipped.sample ?? 0) + 1; continue; }
if (gated && !v.ok) { skipped[v.why] = (skipped[v.why] ?? 0) + 1; continue; }
```

⚠ **`SAMPLE_SLUGS` 에 진짜 사장님 주소가 들어가면 그 홈페이지가 사이트맵에서 사라집니다.**
   그 파일의 경고문(「여기에 진짜 사장님 주소를 적지 마라」)이 이제 **색인까지** 책임집니다.
   지금 값은 `["sample-interior"]` 하나뿐입니다.

## 3. 지시에서 시키신 세 가지 — 다 지켰습니다

| 시키신 것 | 어떻게 |
|---|---|
| `v.ok` 검사 **앞**에서 `continue` | 예. `v` 계산 바로 뒤, `if (gated && !v.ok)` 바로 앞 |
| `skipped` 에 **`"sample"` 한 낱말** | 예. 위 로그에 `"sample":1` 로 남습니다 |
| `lib/indexable.ts` 를 **안 건드림** | 예. 「돈 낸 사장님 판정」과 「우리 견본」을 섞지 않았습니다 |
| `app/[slug]/page.tsx` 의 `noindex` 를 **안 건드림** | 예. 심사관은 예시를 열어 봐야 합니다 |

**한 가지 더 정했습니다 (권반장께 알려 드립니다).**
`gated` 와 **상관없이** 뺐습니다. 원래 문턱 검사는 `if (gated && !v.ok)` 라서
**운영자 열쇠가 없으면 통째로 꺼집니다.** 예시 제외까지 그 안에 넣었으면
열쇠 빠진 배포에서 없는 가게가 그대로 나갔을 것입니다. **없는 가게를 미는 것은 그때도 안 됩니다.**
