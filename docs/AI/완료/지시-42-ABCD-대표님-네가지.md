# [42] 사이 지시 — 대표님 네 가지 (A·B·C·D)

**날짜:** 2026-09-17 (밤) · **5단계(재생 순서)는 «멈췄고 지우지 않았습니다».**
**한 줄:** 넷 다 했고, **⌃⌄ 를 되살리니 리액션 막대와 «정말로» 겹치는 것**을 숫자로 재 뒀습니다.

---

## 【A】 「몰입모드 나가기」 → **「숏폼에서 나가기」** ✅

> 대표님: 「**몰입모드 나가기 라는 이름을 그냥 «숏폼에서 나가기» 라는 명칭으로 바꿔**」

우하 단추 글자와 **읽어 주는 이름(aria-label) 둘 다** 바꿨습니다.
**실측:** 우하 글자 「숏폼에서 나가기」 · 우상 ✕ 이름 「숏폼에서 나가기」 ✅

★ 제가 「대표님 문장이라 손대지 않겠다」고 남겨 뒀던 자리입니다 — **대표님이 직접 바꾸셨으니 이제 맞습니다.**

## 【B】 가두는 편수를 **5~10 에서 고르게** ✅

> 대표님: 「**최소 5개에서 최대 10개 중에 고를 수 있음.** 숏폼형태 10개면 너무 많이 영상이 가려서 사장님들이 답답해 할 수 있으니까」

- 편집화면 「숏폼 스타일 선택」 안, **숏폼형태일 때만** 뜨는 칸 (5·6·7·8·9·10)
- **기본 10** · 범위 밖 값은 **조용히 끌어당깁니다**
- ⚠ **카드형태 20 은 그대로** 뒀습니다(대표님 지시)

**실측 — 5로 두고 진짜 홈페이지:**
```
--stage-n 5 · 칸 5 · 눈금 5 · 무대높이 «6화면»(5+1) · 「1 / 5 · 전체 8」 · 「전부 보기 (8편) →」
```
⇒ **높이가 11화면에서 6화면으로 줄었습니다.** 대표님이 걱정하신 「답답함」이 그 숫자입니다.

## 【C】 ⌃⌄ **되살렸습니다** — 🔴 **모양은 아직 옛날 것입니다**

> 대표님: 「오른쪽 중간 ⌃⌄ 버튼은 인스타 릴스 보니까 **다시 살리는 게 좋겠다**」

**되살리기만** 했습니다(권반장 지시). **인스타 릴스 규격은 안 맞췄습니다** — 규격이 오면 그때.

### 🔴 겹칩니다 — 재 뒀습니다 (규격 정하실 때 쓰십시오)

```
폰 375×812 · 오른쪽 기준

막대(.world-rail)   x 346~351   y 362~450
⌃ (arrow up)        x 311~351   y 352~392     ⇒ 🔴 겹침
⌄ (arrow down)      x 311~351   y 420~460     ⇒ 🔴 겹침

겹치는 가로 띠 : x 346~351 (5px) — 막대가 화살표 오른쪽 끝에 «올라타 있습니다»
```
⇒ **둘 다 오른쪽 한가운데**라 지금은 **막대가 화살표 위에 겹쳐 보입니다.**
🔴 **혼자 옮기지 않았습니다** — 권반장님이 규격과 함께 배치를 주시기로 했습니다.

## 【D】 문의하기 플로팅을 **히어로·숏폼 구역에서 숨김** ✅

> 대표님: 「**히어로 섹션이랑, 숏폼 구역에선 안 뜨게 하고, 숏폼 구역 아래로 벗어나면 그때 나오게** …
>  안 그래도 폰 화면 작은데 너무 공간을 많이 차지한다」

### 🔴 먼저 확인한 것 — **문의 길을 막지 않는가**

권반장님이 「없으면 숨기지 말라」 하신 항목입니다.
```
히어로 안에 [문의하기] 버튼 : ✅ 있다
```
⇒ **첫 화면에서도 문의로 가는 길이 남습니다.** 그래서 숨겨도 됩니다.

### 실측 (폰 375×812)

```
① 맨 위(히어로)        ✅ 안 보임      ⑤ 숏폼을 지나면   ✅ 보임
② 히어로 끝자락        ✅ 안 보임      ⑥ 맨 아래        ✅ 보임
③ 숏폼 구역 안         ✅ 안 보임      ⑦ 다시 맨 위      ✅ 안 보임
④ 숏폼 끝 직전         ✅ 안 보임
```

⚠ **기준은 「숏폼 구역의 아래」**입니다. 무대가 없는 사이트는 **첫 섹션(히어로)** 아래가 기준입니다.
🔴 **기준을 «못 찾으면 보여 줍니다»** — 못 찾았다고 문의 길을 막으면 그게 더 큰 손해입니다.

---

## ⚠ 이 확인에서 알게 된 것 — **숨은 창에서는 `scroll` 이벤트도 안 옵니다**

```
① 굴린 직후 (브라우저 scroll 만 믿고)   → 안 보임   🔴
② scroll 을 «직접» 쏘니                → ✅ 보임
```
`IntersectionObserver` 에 이어 **`scroll` 도 멈춰 있었습니다.** ⇒ 이후 실측은 **직접 쏴서** 했습니다.
★ **「계산과 화면을 나란히 놓기」에 이어 「이벤트를 직접 쏘기」도 쓸 수 있는 방법입니다.**
