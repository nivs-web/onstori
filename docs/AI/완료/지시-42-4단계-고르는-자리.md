# 지시 [42] **4단계** — 「숏폼 스타일 선택」 고르는 자리 (사장님 화면)

**날짜:** 2026-09-17 (밤) · **①(사장님 화면)만 했습니다. ②(어드민 표)와 5단계는 안 했습니다.**
**한 줄:** 사장님이 **그림과 대표님 문장으로** 모양을 고르고, **눌러서 바뀌는 것까지** 확인했습니다.

---

## 1. 자리 — **사장님 편집화면 「영상」 맨 위**

권반장님 판단대로 **①을 «주»로** 먼저 만들었습니다(대표님 원문의 「홈페이지 관리자」가 갈려 여쭙는 중).

```
편집화면 → 영상 → 맨 위 「숏폼 스타일 선택」
  ● 숏폼형태   최근 10편   ↓ 세로로   (대표님 문장)
  ○ 카드형태   최근 20편   → 옆으로   (대표님 문장)
```

- **그림으로 한눈에** — 세로로 쌓인 그림(숏폼형태) · 좌우 카드 그림(카드형태)
- **설명글은 대표님이 쓰신 문장 «그대로»**입니다(기획서 §1-1). 줄이거나 다듬지 않았습니다
- **기본은 숏폼형태** — 아무것도 안 고른 사장님은 지금까지와 똑같습니다
- 🔴 **「몰입모드」·「숏폼시네마」라는 낱말을 한 번도 안 썼습니다**(권반장이 정한 규칙)

## 2. 저장 — `settings.shorts.style` · **db push 없음**

🆕 `app/api/site/shorts-style/route.ts`

- **주인만** 바꿀 수 있습니다(`loadOwnedSite`)
- 🔴 **모르는 값은 거절**합니다 — 화면이 고장 나도 손님 홈페이지가 깨지면 안 됩니다
- 🔴 **있던 것 «위에» 얹습니다**(두 겹 다) — 통째로 덮으면 채널·주간알림이 날아갑니다
- ⚠ **`revalidatePath`** 한 줄 — 손님 화면이 ISR(60초)이라 없으면 **바꿔 놓고 1분 동안 옛 모양**이 보입니다

## 3. 🔴 실제로 눌러서 확인했습니다

시험은 **버리는 계정**이 `zz-gate-test-a`(정지된 시험용 사이트)의 주인이 되게 **잠깐** 바꿔서 했고, **전부 되돌렸습니다.**

```
① 처음                 숏폼형태=true · 카드형태=false      (기본값)
② 카드형태를 누르니      숏폼형태=false · 카드형태=true
③ 화면 알림             「바꿨어요. 홈페이지를 열어 보시면 바로 보입니다.」
④ 서버가 기억하나        shortsStyle = "cards"              ✅
```

**대표님 문장이 화면에 그대로 나오는 것**도 확인했습니다(두 칸 모두 전문).

### 🔴 가장 중요한 확인 — **다른 설정이 안 날아갔습니다**

권반장님이 세 번 강조하신 것입니다.

```
바꾸기 전 : 9칸  logo,phone,notify,weekly,address,aiUsage,oneLiner,manual_grant,industryLabel
바꾼 뒤   : 10칸 (위 9칸 그대로 + shorts)
되돌린 뒤 : 9칸  (원래대로)
⇒ 날아간 칸 0개
```

⚠ **되돌리기까지 확인했습니다** — 주인·`anon_id`·`settings` 셋 다 원래 값. **시험 계정도 지웠습니다**(남은 것 0개).

## 5. 🔴 여쭐 것 — **「몰입모드 나가기」는 대표님 확정 문구입니다**

권반장님이 **「손님 눈에 닿는 곳에 «몰입모드» 를 쓰지 마라」**고 정하셨는데,
**우하 단추의 글자가 「몰입모드 나가기」**이고 그건 **대표님이 직접 쓰신 문장**입니다:

> 「오른쪽 아래에는 큰 X가 위에 있고 그 아래 작은 글씨로 **「몰입모드 나가기」**」

⇒ **손대지 않았습니다.** 규칙과 대표님 확정이 부딪치는 자리라 **제가 고를 일이 아닙니다.**
   (카드형태 안내문은 대표님 확정 문구가 아니라서 규칙대로 고쳤습니다)
