# 지시 [49]④ — 카드형태 좌우 단추 + 3초 안내

날짜: 2026-09-18 · 요청: 권반장 · 상태: 처리함

---

## 1. 한 것

| | |
|---|---|
| **좌우 원형 단추 `‹ ›` 를 «폰에서도» 켰다** | 전에는 `@media (min-width: 768px)` 안에만 있어 **폰에서 아예 안 떴다** |
| **3초 안내** 「← → 좌우로 밀어서 영상을 변경하세요」 | 떴다 사라진다. **대표님 원문 그대로** |
| **안내가 «둘» 동시에 안 뜨게** | 떠 있는 동안 윗줄(「옆으로 넘겨 보세요…」)을 **비운다** |

## 2. ★ 「손가락으로 밀기」는 **이미 되고 있었다**

> 대표님: 「폰 버전에서도 좌우 플로팅 동그란 버튼이 있고, **손으로 좌우 밀어서 스크롤도 가능한 거야**」

**코드를 더할 것이 없었습니다.** `.shorts-rail` 이 이미 이렇습니다:

```
overflow-x: auto  ·  scroll-snap-type: x mandatory  ·  -webkit-overflow-scrolling: touch
실측: 넘치는 폭 2887 > 보이는 폭 390  ✅
```

**단추를 켠다고 밀기가 막히지도 않습니다** — 단추는 레일 «위»에 뜨는 별개 요소입니다.

## 3. 🔴 권반장님이 재 달라 하신 것 — **단추가 영상을 얼마나 가리나**

| 화면 | 카드 폭 | 두 단추가 가리는 폭 | 비율 |
|---|---|---|---|
| **폰 390×844** | 342px | **60px** | **17.5%** |
| PC 1280×800 | 324px | 28px | 8.6% |

단추는 **지름 44px · 아이콘 22px**([49]① 에서 맞춰 둔 값) · 배경 `rgb(0 0 0 / 0.45)` + 흐림.

⚠ **폰에서 17.5% 는 적지 않습니다.** 다만 ①반투명이고 ②세로 한가운데라 얼굴·자막이 있는
위아래를 피하며 ③대표님이 **「폰에도 있어야 한다」**고 명시하셨습니다. **판단은 대표님 몫으로 남깁니다.**

## 4. 🔴 재다가 잡은 것 둘

### ① 안내가 **화면 오른쪽 끝에 붙어** 있었다 (고쳤습니다)

처음에 `.world-help`(몰입모드 안내)의 모양을 그대로 베끼면서 `animation: world-in` 도 같이 가져왔습니다.
그런데 —

```
@keyframes world-in { from { transform: scale(1.04); } to { transform: none; } }
```

🔴 **`transform: none` 으로 «끝납니다».** `both` 라 끝값이 그대로 남아,
가운데 정렬용 `translateX(-50%)` 를 **영구히 지웁니다.**
⇒ 실측: **왼쪽여백 190 · 오른쪽여백 0** — 안내가 화면 끝에 붙었습니다.
⇒ **투명도만 바꾸는 애니메이션**(`shorts-help-in`)을 따로 만들어 고쳤습니다.
⇒ 고친 뒤: **왼쪽 81 · 오른쪽 81 ✅**

★ **교훈을 CSS 주석에 적었습니다** — 「자리를 `transform` 으로 잡는 요소에는
  `transform` 을 건드리는 애니메이션을 쓰지 않는다」.

### ② 안내가 **영영 안 뜰 수 있는** 조건이었다 (고쳤습니다)

처음엔 「레일이 **절반 이상 보이면**」(`intersectionRatio >= 0.5`)으로 썼습니다.
🔴 **레일이 화면보다 두 배 넘게 크면 그 비율에 «영영» 못 닿습니다** — 안내가 평생 안 뜹니다.
⇒ **「화면 한가운데에 닿았나」**로 바꿨습니다(`rootMargin: "-25% 0px -25% 0px"`).
  레일이 크든 작든 똑같이 동작합니다.

## 5. 왜 «윗줄»을 감추나

> 권반장: 「**두 개가 동시에 뜨지 않게 하십시오. 손님이 어느 것을 읽어야 할지 모릅니다**」

윗줄이 이미 **「옆으로 넘겨 보세요」**라고 말합니다 — 거의 같은 말입니다.
⇒ 안내가 떠 있는 동안만 윗줄을 **`visibility: hidden`** 으로 둡니다.
⚠ **`display: none` 이 아닙니다** — 줄이 사라지면 **아래가 위로 튑니다.** 자리는 두고 글자만 감춥니다.
실측: 안내 뜨기 «전» `visible` → «후» `hidden` ✅

⚠ **윗줄의 글자는 한 자도 안 바꿨습니다.** 이름표(`shorts-say`)만 달았습니다.

## 6. 시간은 `HINT_MS`(2800ms) 를 그대로 씁니다

대표님은 「3초」라 하셨고 권반장님은 재량을 주셨습니다.
**눈에 안 띄는 차이**라 **「값이 적힌 자리를 하나로」** 두는 쪽을 골랐습니다 — 무대·몰입모드와 같은 값입니다.

## 7. ⚠ 못 한 것 · 한계

| | |
|---|---|
| **안내가 «실제로» 뜨는 것은 못 봤다** | 내장 브라우저 창이 숨으면 **IntersectionObserver 가 업니다.** 같은 조건의 관찰기를 따로 만들어 **한 번도 안 터지는 것**을 확인했습니다(레일은 100% 보이는데도). ⇒ **모양·자리·윗줄 감추기는 표시를 직접 켜서 쟀고**, «터지는 순간»만 못 봤습니다 |
| **카드형태를 쓰는 사장님이 «아직 없다»** | 여덟 사이트 전부 기본(숏폼형태)입니다. 시험은 **로컬 코드에서만 잠깐 강제**하고 되돌렸습니다(`git diff` 변화 0 확인) — DB 는 안 건드렸습니다 |
