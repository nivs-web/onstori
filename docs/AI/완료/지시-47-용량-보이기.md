# 지시 [47] — 영상 용량을 **막지 말고 보이게**

**날짜:** 2026-09-17 (밤) · **한 줄:** 어드민 표에 **사장님별 실제 저장량**을 띄웠습니다. **아무것도 막지 않았습니다.**

---

## 1. ① 사장님별 «실제 저장량» ✅

4-② 에서 만든 「걸린 영상 N편」 **바로 옆**에 붙였습니다.

```
다산 리모델링 (샘플사이트)  /sample-interior  active  걸린 영상 8편  · 127.6MB
펠리즈                    /peliz           trial   걸린 영상 없음  · 0
```

⚠ **세는 자리는 «지울 때 지우는 자리»와 같습니다**(`site-delete` 의 `PREFIXES`) —
그래야 **「보이는 용량」과 「지우면 사라지는 용량」이 같습니다.**
```
media:uploads/{상호}/ · private:private/stories/{상호}/ · media:shots/{상호}/ · private:inquiries/{id}/
```

🔴 **못 세면 «0» 이 아니라 「용량 못 쟀어요」**라고 씁니다. 0 이라고 적으면 **「없다」는 거짓말**이 됩니다.
⚠ 0 바이트도 **「1KB」로 반올림하지 않습니다** — 처음엔 그렇게 나와서 고쳤습니다(아무것도 없는데 1KB 라고 쓰면 그것도 거짓말입니다).

**실측 — 직접 세어 화면 값과 맞춰 봤습니다:**
```
sample-interior  uploads 25개/58.8MB · stories 18개/68.4MB · shots 12개/0.4MB ⇒ 127.6MB
peliz            0개 ⇒ 0
화면에 나온 값과 «같습니다» ✅
```

## 2. ② 편수가 많은 곳은 **눈에 띄게** ✅

`VIDEOS_WARN_AT = 300` — 넘으면 그 줄의 용량이 **굵은 빨강 + 「🔴 300편 넘음」**.

⚠⚠ **막는 값이 아닙니다.** 넘어도 **아무것도 막지 않습니다.**
★ **왜 300인가:** 주 1회 찍으면 약 6년치입니다. 그 이상은 **평범한 쓰임이 아니라 «봐야 할 신호»**입니다.
🔴 **근거 있는 정답이 아니라 눈에 띄게 하려고 고른 값**입니다 — 대표님이 다른 수를 주시면 바꿉니다.

**화면 맨 위에도 적었습니다:**
> 🔴 **영상 편수에 제한이 없습니다.** 저장한 용량이 그대로 요금이 되므로 여기서 **눈으로 지켜봅니다** —
> **300편**이 넘는 곳은 눈에 띄게 표시합니다(**막지는 않습니다**).

## 3. ③ Cloudflare 요금 알림 — **순서를 `WAITING.md` 에 적었습니다** ✅

코드가 아니라 **사람이 콘솔에서** 할 일이라 대기표에 넣었습니다(5분).
```
① dash.cloudflare.com ② [Manage Account] → [Billing] ③ [Budgets]/[Notifications]
④ [Create] → Billing/Usage ⑤ 미화 $10 쯤 + 받을 메일 ⑥ 저장
⚠ R2 를 쓰는 «그 계정»에서
```
★ **왜 화면만으로는 부족한가:** 어드민 용량은 **우리가 «보러 가는» 것**이고,
알림은 **«찾아오는» 것**입니다. 성격이 다릅니다.

## 4. 🔴🔴 **올리는 것은 «막지 않았습니다»**

권반장님 지시대로입니다. **사장님이 영상을 못 올리게 막는 것은 «사업 정책»이고 «돈»과 얽혀 대표님 결정 사항**입니다.
⇒ **지금은 보이게만.** 보이면 대표님이 정하실 수 있고, **안 보이면 아무도 모릅니다.**

## 5. ⚠ 못 한 것 · 알아 두실 것

| 무엇 | 왜 |
|---|---|
| **Cloudflare 캐시 규칙이 켜져 있는지** | 🔴 **코드로는 확인할 수 없습니다.** 조사원도 저도 **못 봤습니다** — 「켜져 있다」고 말하지 않겠습니다. `WAITING.md` 에 올렸습니다 |
| **사이트가 아주 많아지면** | 표를 열 때마다 **사이트 수만큼 용량을 셉니다.** 지금 8곳이라 괜찮습니다 — 수백 곳이 되면 **미리 세어 두는 방식**이 필요합니다 |
| **5,000개에서 멈춥니다** | 한 사장님이 그보다 많으면 **「최소값」**입니다(`listPrefix` 와 같은 안전장치) |
| **진짜 해법은 압축입니다** | 45MB → 11MB 면 요금이 **1/4**([45]). 이 지시는 «그때까지 눈을 뜨고 있는 것»입니다 |
