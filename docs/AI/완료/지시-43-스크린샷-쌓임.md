# 지시 [43] ①② — 미리보기 스크린샷이 영원히 쌓이던 것 · 그리고 「아래로 쓸어 닫기」 제거

**날짜:** 2026-09-17 (밤) · **한 줄:** 새는 곳 둘을 막았습니다. **③(이미 쌓인 것 치우기)은 안 했습니다 — 세어서 아래에 보고드립니다.**

---

## 1. 🔴 먼저 — **「아래로 쓸어내려 닫기」를 없앴습니다** (대표님 확정 · 권반장 전달)

> 대표님: 「나가는길, X 버튼 우측상단, 좌측 하단, ESC, 폰 뒤로가기,
> **아래로 쓸어내리는건 못나가게해, 위아래 스크롤은 영상 넘기기야**」

⚠ 제가 앞서 **「[42] 에서 걷어내겠다」**고 미뤄 뒀던 것인데, 권반장님 말씀이 맞습니다 —
**문구만 지우고 동작을 남기면 「말은 안 하는데 여전히 그렇게 되는」 상태**라 오히려 나쁩니다.

🔴 **그냥 막지 않았습니다.** 아래로 쓸면 **이전 편**으로 갑니다 —
아무 일도 안 일어나면 손님은 「멈췄나?」 합니다.

**실측 (폰 375×812 · 무대 상한을 잠깐 3으로 낮춰 8편짜리로 재현):**

| 몸짓 | 전 | 지금 |
|---|---|---|
| 위로 크게 쓸기 | 다음 편 | **다음 편** (1/8 → 2/8 → 3/8) |
| 🔴 **아래로 «400px» 쓸기** | **닫혔다**(140 넘으면) | ✅ **안 닫히고 이전 편** (3/8 → 2/8 → 1/8) |

**나가는 길은 그대로 넷입니다 — 전부 눌러 확인했습니다:**

```
① ✕(우상)      ✅ 닫힘      ② ESC          ✅ 닫힘
③ 바깥 클릭     ✅ 닫힘      ④ 폰 뒤로가기   ✅ 닫힘 (그리고 홈페이지를 떠나지 않음)
```

⚠ **그 밖의 몰입모드 화면은 한 줄도 안 건드렸습니다** — [42] 「숏폼시네마」에서 통째로 바뀐다고 하셔서입니다.

---

## 2. [43]① — **새 사진을 올리면 옛 사진을 치웁니다**

**권반장님 진단이 맞았습니다**(제가 직접 훑어 확인).
`shots/` 를 **쓰는 곳은 한 군데**(`lib/site-shot.ts:192`)이고 **지우는 코드는 어디에도 없었습니다.**

⚠ 파일명에 시각을 넣는 것 자체는 **맞습니다** — R2 가 영구 캐시라 같은 이름으로 덮으면 옛 사진이 계속 보입니다.
문제는 **이름만 바꾸고 옛것을 안 치운 것**입니다.

### 🔴 순서가 곧 안전장치입니다 — **«적은 뒤에» 치웁니다**

찍는 것과 「그 주소를 `settings.shots` 에 적는 것」은 **두 걸음**입니다.
찍은 자리에서 옛것을 지웠는데 **적는 데서 실패하면**, 표에는 옛 주소가 남고 그 파일은 없어져
**카드가 깨진 사진**이 됩니다.

⇒ 치우는 일(`pruneOldShots`)을 **부르는 쪽**(`lib/publish-site.ts` · `app/api/admin/site-shot`)에서
**적기에 성공한 뒤에만** 부르게 했습니다.

⚠ **「최신 1장」을 «시각 비교»로 고르지 않습니다.** **방금 올린 이름(`stamp`)**이 든 것만 남깁니다 —
시각으로 고르면 **시계가 어긋난 기계에서 살아 있는 사진을 지웁니다.**

**실측 (버리는 폴더 `shots/__prune-test__/` 하나에만):**

```
넣은 것 : 6장 (세 쌍)      →   지운 것 : 4장 · 남은 것 2장 (pc·phone 최신 한 쌍)  ✅
다시 불렀을 때 지운 것 : 0장  ← 살아 있는 것은 안 건드린다                          ✅
시험 폴더 치움 : 2장 · 남은 것 0장
```

## 3. [43]② — **사이트를 지울 때 `shots/` 도 함께**

| 파일 | 전 | 지금 |
|---|---|---|
| `app/api/admin/site-delete/route.ts` | `uploads/` · `inquiries/` · `private/stories/` | **+ `shots/{slug}/`** |
| `app/api/cron/expire/route.ts` | 같음 | **+ `shots/{slug}/`** |

★ `site-delete` 의 그 목록은 **「세는 곳」과 「지우는 곳」이 함께 쓰는 한 줄**이라,
한 줄을 넣으면 **「몇 장이 사라지는지」 세는 화면도 같이** 고쳐집니다.

## 4. 🔴 [43]③ — **안 했습니다. 먼저 세어서 보고드립니다**

⚠ **되돌릴 수 없는 일**이라 대표님 확인 전에는 손대지 않았습니다. **읽기만 했습니다.**

```
shots/ 전체 : 119장 · 4.4MB (평균 37KB)
그중 «지금 쓰는 것» : 4장          ⇒ 🔴 안 쓰는 것 115장
```

| 폴더 | 장수 | 지금 쓰는 것 | 사이트가 아직 있나 |
|---|---|---|---|
| `barun` | 34 | 0 | 🔴 **없음** |
| `bls` · `herotest1` · `interior2` · `moksu` | 각 12 | 0 | 🔴 **없음** |
| `herotest2` · `herotest3` | 각 10 | 0 | 🔴 **없음** |
| `skaldjflk` | 2 | 0 | 🔴 **없음** |
| `sample-interior` | 12 | 2 | ✅ 있음 |
| `zz-gate-test-b` | 2 | 2 | ✅ 있음 |
| `zz-gate-test-c` | 1 | 0 | ✅ 있음 |

**지금 사이트는 8곳뿐인데 `shots/` 폴더는 11개**입니다 — **8개가 이미 지워진 사이트의 것**입니다.
권반장님이 말씀하신 **「사이트를 지워도 남는다」가 눈으로 확인**됐습니다.

### ⚠ 그런데 **「돈이 새고 있다」는 말은 과장입니다** — 사실대로 적습니다

**4.4MB 입니다.** R2 요금으로는 **사실상 0원**입니다.
🔴 문제는 **금액이 아니라 «멈추지 않는 구조»**였습니다 — 발행할 때마다 한 쌍씩, 영원히.
①② 로 **그 구조는 막혔습니다.** ③은 **급하지 않습니다.**

**여쭙습니다:** 안 쓰는 115장을 한 번 치울까요? (되돌릴 수 없습니다 · 「치워」 한 마디면 합니다)

## 5. ⚠ 못 한 것
