# 지시 [42] **5단계** — 재생 순서

**날짜:** 2026-09-17 (밤) · **5단계만 했습니다. 어드민 표(4-②)는 안 했습니다.**
**한 줄:** 세 가지를 고를 수 있게 했고, **「올 때마다 다르되 그 손님에겐 끝까지 같다」를 실제로 확인**했습니다.

---

## 1. 고르는 것 셋 (대표님 기획서 §1-2 그대로)

```
● 최근에 등록한 순으로 재생          ← 기본
○ 첫 영상만 최근, 2번째부터 랜덤
○ 전체 랜덤 재생
```

⚠ **목록을 화면에 박지 않았습니다** — `config/shorts.ts` 의 `SHORTS_ORDERS` 를 **돌려 그립니다.**
대표님이 「옵션이 더 늘어난다」고 하셔서, 늘 때 **그 배열에 한 줄만** 더하면 화면도 서버도 따라옵니다.
🔴 **모르는 값은 조용히 기본값**으로 떨어뜨립니다.

## 2. 🔴 가장 중요한 것 — **「1 / N」이 거짓말이 되지 않게**

권반장님이 잡아 주신 것입니다. **그릴 때마다 새로 섞으면** 손님이 3번째 편을 보다가 새로고침했을 때
**전혀 다른 영상**이 3번째가 됩니다 — 「몇 번째인지」가 아무 뜻이 없어집니다.

⇒ **손님 한 분의 «방문 한 번»에 씨앗 하나.** 들어올 때 뽑아 `sessionStorage` 에 두고 그 방문 내내 그 씨앗으로만 섞습니다.

### ⚠ 그리고 **서버에서 섞으면 안 됩니다**

손님 화면은 **ISR(캐시)** 이라 서버에서 섞으면 **모든 손님이 같은 순서**를 받습니다 —
「올 때마다 다르게」가 **아예 성립하지 않습니다.** ⇒ **브라우저에서** 섞습니다.

## 3. 잰 것 — **함수부터**

`npx tsx` 로 8편을 놓고 열네 가지를 쟀습니다. **전부 통과:**

```
같은 씨앗이면 항상 같은 순서   newest / first-fixed / random 셋 다 ✅
씨앗이 다르면 다른 순서        ✅
newest 는 손대지 않는다        ✅
first-fixed 는 첫 편 고정      ✅ (AEGCDFHB — A 가 그대로)
빠짐·중복 없음                 셋 다 8편 그대로 ✅
원본 배열을 안 건드린다         ✅
0편 · 1편                      ✅
```

## 4. 잰 것 — **진짜 홈페이지로** (샘플 사이트 설정을 잠깐 바꿔 확인 후 되돌림)

**DB 순서(= 최근 등록순):** `39aeee44 · 13a4a04c · a828f4e4 · bd94307c · 14b7af28 · 66081b2b · 0e8d7e19 · 641cb4f5`

| 잰 것 | 결과 |
|---|---|
| **전체 랜덤** — 순서가 바뀌나 | 첫 영상이 **`641cb4f5`**(DB 8번째) ✅ **섞였습니다** |
| 🔴 **같은 손님이 새로고침** | 씨앗 `1278093110` 그대로 · 첫 영상 **`641cb4f5` 그대로** ✅ |
| 🔴 **새 손님**(씨앗 지움) | 씨앗 `1683239169` · 첫 영상 **`a828f4e4`** ✅ **다릅니다** |
| **첫 영상만 고정** | 첫 영상이 **`39aeee44`**(DB 1번째) ✅ **고정됐습니다** |

⇒ **「올 때마다 다르되, 그 손님에게는 끝까지 같다」가 실제로 그렇게 됩니다.**

⚠ 설정 변경은 **백업(9칸) → 검증 → 변경 → 되돌림(글자까지 같음)** 했습니다.

## 5. 화면 — 사장님 편집화면 「영상」

모양 고르는 칸 **바로 아래**에 「재생 순서」를 붙였습니다.
⚠ 랜덤을 고르면 **「손님 한 분에게는 보시는 동안 순서가 바뀌지 않습니다」**를 함께 적습니다 —
안 적으면 사장님이 새로고침해 보고 **「고장났나?」** 합니다.
🔴 **「몰입모드」·「숏폼시네마」라는 낱말을 한 번도 안 썼습니다.**

## 6. 저장 — **창구 하나로**

`/api/site/shorts-style` 이 **모양과 순서를 함께** 받습니다(둘 다 `settings.shorts` 안에 살고 저장 규칙이 같습니다).
🔴 **보낸 것만 바꿉니다** — 순서만 보냈는데 모양이 기본값으로 덮이면 안 됩니다.
🔴 **있던 것 «위에» 얹습니다**(두 겹). ⚠ 모르는 값은 **거절**합니다.
