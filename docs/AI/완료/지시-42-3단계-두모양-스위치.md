# 지시 [42] **3단계** — 두 모양 스위치

**날짜:** 2026-09-17 (밤) · **3단계만 했습니다. 4~5단계는 손대지 않았습니다.**
**한 줄:** 잠들어 있던 **카드형태를 깨워서 실제로 그려지는 것을 봤고**, 그 과정에서 **화면이 거짓말을 하게 된 문장 하나를 잡았습니다.**

---

## 1. 판정을 「편수」에서 「사장님이 고른 모양」으로

```
바꾼 곳 ①  app/[slug]/page.tsx        const stageOn = shortsStyle === "shorts" && stageItems.length > 0;
바꾼 곳 ②  components/sections/index.tsx  (그대로 — stageOn 이 false 면 카드형태가 그려진다)
```

⚠ **아무것도 안 고른 사장님은 지금까지와 똑같습니다**(기본 = 숏폼형태).
🔴 **모르는 값이 들어 있으면 조용히 기본값**으로 떨어뜨립니다(`shortsStyleOf`) — 옛 사이트 화면이 깨지면 안 됩니다.

**저장 자리:** `sites.settings.shorts.style` · **db push 필요 없습니다**(jsonb).

## 2. 🔴 **카드형태가 «실제로» 그려지는 것을 봤습니다**

권반장님이 「반드시 눈으로(또는 숫자로) 보십시오」 하신 항목입니다.
샘플 사이트의 설정을 **잠깐** `cards` 로 바꿔 확인했습니다(백업 → 확인 → **되돌림**).

```
무대(.stage)  : 없음        카드(.shorts) : 있음
카드 8장 · <video> 8 · 좌우 화살표 2 · 점 8
```

**되살아났습니다.** 2026-09-16 에 만들어 놓고 **한 번도 안 그려지던 화면**입니다.

### 🔴 그런데 — **그 화면의 안내 문장이 «거짓말»이 됐습니다**

```
지금까지 : 「8편 · 옆으로 넘겨 보세요. 소리는 «영상을 누르면» 켜집니다.」
```

대표님 확정으로 **카드형태는 누르면 «몰입모드»가 열립니다.** 소리는 **스피커 단추**가 맡습니다.
⇒ 그대로 두면 화면이 **안 하는 일을 한다고 말합니다**(불변 규칙 12).

| 무엇을 | 「… 소리는 **영상을 누르면 켜집니다**」 → 「… **영상을 누르면 몰입모드로 열립니다**」 |
|---|---|
| **어디** | `components/sections/index.tsx` 의 카드형태 안내 한 줄 |
| **왜** | 동작이 바뀌었는데 문장이 안 바뀌면 **그 자체가 거짓말**입니다 |

🔴 **손님이 보는 글이라 「일단 고치고」 여쭙습니다** — 되돌리라 하시면 한 줄입니다.

## 3. 카드형태에 **몰입모드**를 붙였습니다

**§1 에서 몰입모드를 파일로 떼어낸 것이 바로 이걸 위해서였습니다.** 실측:

```
영상 누름 → 몰입모드 열림 ✅ · 「1 / 8」 · 막대 7칸 · 우하 나가기 있음
↓ 로 넘김 → 2 / 8 ✅        우하 ✕ → 닫힘 ✅
스피커 단추 → 🔊 ⇄ 🔇 (몰입모드는 «안» 열림) ✅
```

🔴 **몰입모드에는 «가져온 전부»를 넘깁니다** — 화면의 카드는 20장까지지만 열고 들어가면 전부 봅니다
(대표님: 「10·20편은 홈페이지만, 몰입모드는 전부」).
⚠ 「움직임 줄이기」를 켠 손님에게는 **안 열고 전처럼 소리만** 켭니다.

## 4. 편수 — 모양별 상수로

```
숏폼형태 10편 · 카드형태 20편   (config/shorts.ts 의 SHORTS_SHAPE_N)
```
⚠ **`SHORTS_MAX`(200)는 안 건드렸습니다** — 그건 «DB 에서 몇 편 가져오나»라 별개입니다.
⚠ `STAGE_MAX` 는 이제 이 표에서 가져옵니다. **[39] 의 12 → [42] 의 10** 으로 바뀌었습니다.

## 5. ⚠ 못 잰 것 · 걱정되는 것

| 무엇 | 왜 |
|---|---|
| 🔴 **「더 많은 영상을 보시려면 영상 클릭하세요」가 뜨는 것을 못 봤습니다** | 그 안내는 **마지막 편에 닿았을 때** 뜨는데, 「몇 번째 편인가」는 `IntersectionObserver` 가 정합니다. **숨은 창에서는 그것이 안 돕니다**(2단계에서 밝힌 그 문제) — 굴려도 「1 / 3」에서 안 움직였습니다. **코드로만 확인했습니다** |
| ⚠ **「전부 보기」와 «두 개»가 됐습니다** | 위 안내와 「전부 보기 (N편) →」가 **같은 곳으로 갑니다.** 「전부 보기」는 늘 떠 있는 문이고 새 안내는 끝에서의 권유입니다 — 🔴 **둘 다 둘까요?** |
| **20편 넘는 사이트가 없습니다** | 가장 많은 곳이 8편이라 **카드형태 20편 자르기를 못 봤습니다**(코드로만) |
| **진짜 폰 아님 · 화면 그림 못 찍음** | 창이 숨어 있습니다 |

⚠ **시험하느라 샘플 사이트 설정을 잠깐 바꿨습니다** — 백업(9칸) → 검증 → 변경 → **되돌림(글자까지 같음)** 확인.
  🔴 바꿀 때 **반드시 스프레드**했습니다(채널·주간알림 그대로. 9칸 → 10칸 → 9칸).
