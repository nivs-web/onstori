## ① 무엇을 했나

### B-17 — 카드형태 편수를 **10 / 15 / 20 / 25 / 30 / 40** 중에 고른다

```
전 : 카드형태는 «20편 고정»
후 : 사장님이 고른다. 아무것도 안 고르면 «20편» — 지금까지와 똑같다
```

| 어디 | 무엇 |
|---|---|
| `config/shorts.ts` | `CARDS_N_CHOICES`·`CARDS_N_DEFAULT`·`cardsNOf()` 신설 — **목록은 여기 한 곳** |
| `app/[slug]/edit/videos-panel.tsx` | **카드형태를 고르셨을 때만** 「보여 드릴 영상 수」 칸이 뜬다 |
| `app/admin/videos/` | 어드민 표에도 「늘어놓는 편수」 칸 — 전화로 부탁하셨을 때 대신 눌러 드린다 |
| `app/api/site/shorts-style` | 목록 밖 숫자는 **받지 않는다**(400) |
| `app/[slug]/page.tsx` · `components/sections/index.tsx` | 손님 화면이 그 값만큼 그린다 |

⚠ **숏폼형태의 `stageN`(5~10)과 다른 숫자다.** 한쪽은 «가두는» 편수, 한쪽은 «늘어놓는» 편수다.
⚠ **`SHORTS_MAX`(200)와도 다르다** — 몰입모드는 여전히 **가져온 전부**를 본다.
🔴 **모양 카드의 「최근 N편」 라벨을 «고른 값»으로 바꿨다.** 고정 숫자(10·20)를 적어 두면
  5편으로 바꾸신 사장님 화면이 **거짓말**을 한다(불변 규칙 12).

### B-16 — 「숏폼 스타일 선택」 아래 안내 한 줄 (대표님 문장 그대로)

> 「어떤 영상이든 영상을 클릭하면 몰입모드로 바뀌고, 몰입모드에서는 모든 영상이 재생됩니다」

⚠ **「몰입모드」라는 낱말을 여기에 쓴 것은 B-18 때문**입니다 —
  「사장님은 몰입모드·숏폼시네마를 알아도 됨. **홈페이지 방문 «손님»에게만** 굳이 안 알려도 된다」.
  🔴 **손님 화면에는 여전히 안 씁니다.**

## ② 무엇을 «못» 했나

1. 🔴 **편집화면을 눈으로 못 봤습니다.** `/{상호}/edit` 는 **주인만** 들어가는 곳이라
   시험용 브라우저로 열 수 없습니다. ⇒ **배포 뒤 대표님이 한 번 눌러 보셔야** 합니다.
   （확인한 것: 손님 화면이 **전과 똑같이 9장**을 그린다 — 기본값 20 이 그대로 도는 것）
2. **B-14(영상 메뉴 3분할) 뒤에 이 칸들의 «자리»가 바뀔 수 있습니다.** 지금은 한 칸에 모여 있습니다.
3. 🔴 **B-21(랜덤)은 손대지 않았습니다** — 「몰입모드는 최신순」과 「첫 화면 순서를 이어받음」이
   서로 어긋나 **대표님 한 마디가 먼저**입니다.
4. 🔴 **B-2(스크린샷 115장 지우기)도 손대지 않았습니다** — **되돌릴 수 없는 일**이라
   대표님이 계실 때 직접 확인받고 하겠습니다.
