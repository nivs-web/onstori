## 1. ① 스피커가 둘로 보인 «진짜» 이유

> 대표님: 「방금 폰으로 테스트 했는데 **스피커 2개 나오네????** 아무튼 **스피커 1개**」
> 권반장님 짐작: 「무대와 **옛 레일이 둘 다 그리는** 것으로 보입니다」

### 🔴 옛 레일은 하나도 안 그려지고 있었습니다

```
③ 옛 레일도 같이 그려지나 : { 무대: 1, 레일: 0 }
```

**진짜 원인은 「🔇 탭하면 소리가 나요」 안내 알약**이었습니다. 그 안내가 **🔇 를 하나 더** 달고
**큰 스피커 바로 아래**에 떠서 **둘로 보였습니다.**

**고치기 «전» 실측:**

```
[ {글:"🔇",              클래스:"stage-sound", 자리:"318,88",  크기:"56×56" },
  {글:"🔇 탭하면 소리가 나요", 클래스:"stage-hint",  자리:"232,152", 크기:"142×38" } ]
```

⇒ 큰 스피커(318,88) **바로 아래**(232,152)에 작은 🔇 가 하나 더. **대표님이 보신 그대로입니다.**

**고친 «뒤»:**

```
① 폰 — 힌트가 떠 있는 동안 스피커 모양 : [{"글":"🔇","클래스":"stage-sound"}]
   힌트 글 : 탭하면 소리가 나요
```

🔴 **스피커는 이제 «하나»뿐입니다.** 안내는 글자만 남았습니다.

⚠ **화면 가운데로 옮기는 것은 권반장님 조사 결과를 기다립니다.**

## 3. ③ 위아래로 넘기기 — **대표님 말씀이 맞습니다**

> 대표님: 「**좌우 화살표로 영상 돌리는 게 익숙하지 않을 듯. 모든 숏폼은 위아래 아닌가?**
> 마우스 휠로 돌려서 위아래 영상 바꾸기가 좋을까?」

**릴스·쇼츠·틱톡 전부 위아래입니다.** 바꿨습니다.

```
시작 : 2 / 7
아래로 굴리면 : 3/7 → 4/7 → 5/7        위로 굴리면 : 4 / 7
↓ 키 : 5/7    ↑ 키 : 4/7    → 키(함께 살아 있나) : 5/7
소리는 계속 나나 : 🔊
```

**화면의 화살표도 위아래로 옮겼습니다:**

```
⌃ (692, 32)   ← 위        ⌄ (692, 812)   ← 아래
```

**도움말도 바꿨습니다:** 「**↑ ↓ 또는 마우스 휠로 넘기고, ESC 로 나가요**」

### ⚠ 휠이 «한 번에 다섯 편»을 넘기던 문제

마우스 휠은 한 번 굴려도 **여러 번** 들어옵니다(관성). 그대로 두면 **한 번에 대여섯 편**이 지나갑니다.
⇒ **한 번 넘기면 잠깐 잠급니다.** 실측:

```
④ 한 번 세게 굴려도(deltaY 900) : 5 / 7 → 6 / 7    ← 한 편만 넘어갑니다
```

## 4. 🔴 손대지 «않은» 것 — 권반장님 연구를 기다립니다

권반장님이 **여섯 갈래 조사**를 돌리고 계십니다(속도·릴스 UI 해부·좋아요 수·역링크·해지 정책·이름 후보).

> 대표님이 가장 걱정하시는 것: 「**영상을 100개 걸면 홈페이지 엄청 느려지는 거 아냐?**
> **무조건 속도는 빨라야 해. 속도 느려지면 끝장이다**」

⇒ **속도 구조(가상화·미리 받기 등)는 한 줄도 안 건드렸습니다.** 지금 손대면 **곧 다시 뜯어야** 합니다.

### ⚠ 다만 제가 지금 아는 것을 미리 적어 둡니다

지금 무대는 **영상 20편까지만** 싣습니다(`SHORTS_MAX = 20`). 그리고 **지금 편과 그 다음 편만**
미리 받습니다(`preload`). 그래서 **100편을 걸어도 손님이 받는 것은 두 편치**입니다.
⚠ 다만 **`<video>` 태그 자체는 20개가 한꺼번에 만들어집니다** — 그것이 느려지는 지점인지는
**재 봐야** 압니다. 권반장님 조사에 이 숫자를 넘깁니다.

## 5. 🔴 못 한 것 · 걱정거리

### ① **진짜 소리는 여전히 못 들었습니다**

시험용 브라우저는 소리를 내지 않습니다. 확인한 것은 「**음소거가 풀렸고 재생 중**」까지입니다.

### ② **나가기 단추 위치는 그대로**입니다

대표님이 「화면 가운데」를 원하셨는데 **오른쪽 위에 그대로** 있습니다.
권반장님 조사 결과가 나오면 옮기겠습니다.

### ③ **폰에서 휠은 없습니다**

폰은 원래 스와이프입니다. 대표님 「폰은 이대로 좋아」 그대로입니다.

### ④ **안내 글자에서 🔇 를 뺀 것도 «손님 글» 변경**입니다

「🔇 탭하면 소리가 나요」 → 「탭하면 소리가 나요」.
**대표님이 「스피커 1개」라고 지시하셔서 그대로 한 것**입니다만, 적어 둡니다.
