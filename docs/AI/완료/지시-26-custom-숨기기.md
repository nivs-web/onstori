## 5. 만들다 걸린 것 — **검사기가 제 주석을 잡았습니다**

설명을 적다가 대표님 원문(구독 금액이 들어 있는 인용)을 코드 주석에 옮겼더니
`npm run check` 가 **빨간불**이 났습니다 — 규칙 9(「요금 숫자를 코드에 적지 마라」)입니다.

⇒ **검사기가 옳습니다.** 인용은 **문서로 옮기고**(`docs/AI/보류/…`) 코드 주석에는 **뜻만** 남겼습니다.
   ⚠ 검사기를 끄는 예외 표시(`금액 출처: lib/trial.ts`)를 붙일 수도 있었지만 **일부러 안 썼습니다** —
   그것을 붙이면 그 파일 전체가 검사에서 빠져, 나중에 진짜 실수가 들어와도 안 걸립니다.

## 6. 못 한 것 · 걱정거리

1. **어드민 아이디어 뱅크(`/admin/ideas`)에는 안 넣었습니다.** 문서로 남겼습니다.
   넣기를 원하시면 말씀해 주십시오 — **DB 에 글을 쓰는 일**이라 여쭙고 하겠습니다.
2. **이미 색인됐을 가능성.** `/custom` 은 어제 만들어 **사이트맵에도 메뉴에도 없었고** 배포도 안 됐으니
   구글이 알 길이 없었다고 봅니다. 다만 **확인은 못 했습니다** — 서치콘솔에 못 들어갑니다.
   🔴 걱정되시면 `site:onstori.com/custom` 을 한 번 검색해 봐 주십시오.
3. **배포해야 404 가 됩니다.** 지금은 `main` 커밋까지입니다. ⚠ 다만 `/custom` 은 **아직 배포된 적이
   없을 가능성이 높습니다**(어제 만들었습니다) — 그렇다면 운영에는 처음부터 없었습니다.
4. **되살릴 때 약관이 먼저입니다.** `/terms` 에 「단건 맞춤 제작」 조항이 없어 환불 링크가
   월 구독 이야기로 갑니다. **약관은 제가 못 고칩니다.**
