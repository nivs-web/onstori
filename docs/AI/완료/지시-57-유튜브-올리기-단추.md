# [유튜브 감사] 「유튜브에 올리기」 단추 — 처리함 · 2026-09-19

지시: 대표님 · 2026-09-19 — **유튜브 API 감사 신청의 「업로드 인터페이스 스크린샷」 증빙**이 막혀 있었다.

## ① 무엇을 했나 — **화면 한 파일만** 고쳤다

`app/[slug]/edit/videos-panel.tsx` 하나다. **뒷단은 새로 만든 것이 없다**(지시대로).

| # | 무엇 |
|---|---|
| 1 | `ytReady` 판정 하나 추가 — `igReady`·`ttReady` 와 **같은 `verdict()` 를 그대로 재사용** |
| 2 | 영상마다 **「유튜브에 올리기」 상자** — 인스타 상자를 본떴다(글칸 · `TextMeter providers={["youtube"]}` · `publish(id, ["youtube"])`) |
| 3 | 「한 방 등록」 안내문에서 **「유튜브 쇼츠」를 뺐다** |

**안내문 — 대표님이 주신 문장 그대로:**
> 지금은 준비 기간이라 **비공개**로 올라갑니다.
> 사장님 유튜브에서는 보이지만 손님에게는 아직 안 보입니다.

## ② 🔴 하지 말라신 것 — **지켰다**

「한 방 등록」의 채널 목록은 **`["instagram","tiktok"]` 그대로**다. 유튜브를 **안 넣었다.**
이유를 코드 주석에도 남겼다:
① 하루 1편뿐이라 한 방에 섞이면 **사장님이 모르는 새 그날 몫이 사라진다**
② 🔴 **감사 신청서에 「한 번의 명시적 클릭마다 한 번 호출」이라고 적었다** — 화면이 그 말과
   어긋나면 **그 자체가 반려 사유**가 된다

⚠ 대신 안내문에 **한 줄을 더했다**(제 판단입니다 — 빼라 하시면 바로 뺍니다):
> 유튜브 쇼츠는 **영상마다 있는 [유튜브에 올리기]** 로 한 편씩 올립니다(하루 1편).
**왜:** 「유튜브 쇼츠」를 준비 중 목록에서 빼기만 하면 **어디로 갔는지 알 수 없다.**
화면이 「없다」고도 「있다」고도 말하지 않는 상태가 된다.

## ③ 실측 — 단추가 «뜰 조건»을 DB 로 확인했다

```
유튜브 문(app_settings: sns:youtube)
  {"mode":"review", "allowSites":[sample-interior 의 id], "auditPassed":false}

sample-interior   허용목록 있음 · 연결 active · 「올려도 좋아요」 동의함   ⇒ 상자가 뜬다 ✅
sample-toss       허용목록 없음 · 연결 없음                              ⇒ 상자가 안 뜬다 ✅
```

🔴 **이 구조가 곧 안전장치다.** `ytReady` 는 `/api/sns/status` → `youtube.isAvailable()` 를 보는데,
그 안에 **문(`canUpload`)이 들어 있다**(`lib/sns/youtube.ts:137`).
⇒ **감사 전에 아무 사장님 화면에 이 단추가 뜨는 일은 «구조적으로» 생기지 않는다.**
（`youtube-gate-test.ts` 29건도 그대로 통과 — 열리는 조합은 «review+허용목록=비공개» 와 «on+감사통과=공개» 둘뿐）

## ④ 🔴 무엇을 «못» 했나 — 반드시 읽어 주십시오

1. **제 눈으로 단추를 못 봤습니다.** 이유가 «둘»입니다:
   · `/{상호}/edit` 는 **로그인한 주인**만 들어갑니다. 심사 계정 비밀번호는 **운영에만** 있습니다
   · 🔴 **로컬 `.env.local` 에 `GOOGLE_OAUTH_CLIENT_ID`·`SECRET` 이 «없습니다».**
     그러면 `isAvailable` 이 **열쇠 없음**으로 판정해, 로컬에서는 **어차피 상자가 안 뜹니다.**
   ⇒ **운영에서 대표님이 보셔야** 합니다(운영에는 열쇠가 있고 유튜브가 실제로 연결돼 있습니다).
2. **실제로 올려 보지 않았습니다.** 하루 1편뿐이고, 올리면 **되돌릴 수 없습니다**
   (감사 전 업로드는 **영구 비공개 · 항소 불가**). 🔴 **감사 스크린샷을 찍으신 뒤에** 올려 보십시오.

## ⑤ 확인 방법 (대표님)

```
onstori.com/login → 심사 계정 → 다산 리모델링(sample-interior) → [영상] → [내 영상]

```
