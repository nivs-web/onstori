# 지시 [45] 앞작업 — 「영상 한 편이 몇 MB인가」 실측

날짜: 2026-09-17 · 요청: 권반장 · 상태: 처리함

> 권반장님: 「① sample-interior 의 영상 파일 «각각»의 크기를 나열해 주십시오 ② 그중 «가장 큰 것»과
> «가장 작은 것» ③ 그 영상들의 «길이(초)» 도 ⇒ 「60초짜리가 몇 MB 인가」를 알아야 비교가 됩니다
> ④ uploads / stories 중 «어느 쪽이 영상»입니까?」
>
> 그리고: 「⚠ 다만 — **짧은 시험 영상만 있을 수도** 있습니다. **60초를 꽉 채운 영상이 있는지** 함께 보십시오.
> 없으면 「**지금 있는 것으로는 못 잰다**」고 적어 주십시오. 그것도 답입니다.」

## 0. 먼저 결론 — **45MB 는 맞았습니다**

권반장님이 걱정하신 것은 「내가 대표님께 **계산으로** 45MB 라고 말해 왔는데, 잰 적이 없다」는 점이었습니다.
**재 봤더니 맞습니다.** 오히려 **더 큽니다**(최대 54MB).

| | 값 |
|---|---|
| 그동안 말해 온 값 | 45MB (6Mbps × 60초 ÷ 8 — **계산**) |
| 실측 60초 환산 | **42.7 ~ 54.1MB** (최근 녹화 6편) |
| 판정 | ✅ **맞다.** 지금까지의 보고를 고칠 필요 없음 |

⚠ **다만 «60초를 꽉 채운 영상은 하나도 없습니다».** 가장 긴 것이 **17.0초**입니다.
그래서 위 값은 **잰 비트레이트로 60초를 환산한 것**이지, 60초 파일을 직접 본 것이 아닙니다.
환산의 근거는 튼튼합니다 — 길이가 제각각인 6편이 전부 42~54MB 로 모였습니다.

## 2. ④ uploads / stories — **둘 다 영상이고, «같은 영상»입니다**

| 자리 | 개수 | 합계 |
|---|---|---|
| `uploads/sample-interior/` (손님이 보는 것) | 25개(영상 9 + 사진 등) | 58.80MB |
| `private/stories/sample-interior/` (녹화 원본) | 18개(전부 영상) | 68.35MB |
| **합계** | | **127.16MB** |

🔴🔴 **영상 9편이 «두 벌» 저장돼 있습니다. 바이트까지 똑같습니다.**

```
0e8d7e19  11,049,790  =  11,049,790   ✅
66081b2b  12,993,310  =  12,993,310   ✅
a828f4e4   9,659,096  =   9,659,096   ✅   … 9쌍 전부 일치
```

⇒ **겹쳐서 더 쓰는 양 58.55MB — 전체 127.16MB 의 «46%»가 사본입니다.**
⇒ **60초 영상 한 편의 진짜 저장량은 45MB 가 아니라 «약 90MB»** 입니다(45 × 2).

★ 「원본을 따로 둔다」는 원래 **변환(자막·압축) 원재료**로 남기는 자리인데,
  **변환이 일어나지 않아** 똑같은 파일이 두 벌 남고 있습니다.

## 3. 재면서 함께 나온 것 (시키지 않았지만 보고합니다)

**① 「가로로 찍힘」 고침이 실제로 먹었습니다 — 실측으로 확인.**
09-16 15:15 까지는 `2052×1154`(**가로**), 15:28 부터 `1154×2052`(**세로**).
`aspectRatio` 를 더한 그 고침이 **진짜로 갈랐습니다.**

**② 화면크기가 우리가 부탁한 값이 아닙니다.** 1080×1920 을 부탁했는데 카메라가 **2052×1154**(2K급)를 줬습니다.
`ideal` 이라 카메라가 더 큰 모드를 고른 것입니다 — 막은 적이 없으니 정상 동작입니다만, **부탁한 것보다 큽니다.**

**③ 실제 비트가 부탁한 6Mbps 를 넘습니다** — 7.42 · 7.45Mbps. 그래서 54MB 까지 나옵니다.
`videoBitsPerSecond` 는 **부탁**이지 **상한**이 아닙니다.

## 4. 못 한 것 · 걱정되는 점

| | |
|---|---|
| **못 한 것** | **60초를 꽉 채운 영상을 못 구했다.** 사람이 한 번 60초로 찍어 주셔야 «직접 잰 값»이 된다 |
| **못 한 것** | 다른 사장님 사이트는 안 쟀다. sample-interior 한 곳만 |
| 걱정 | 두 벌 저장은 **지금 사장님이 적어서 안 보인다.** 100편이면 9GB가 아니라 **18GB** |
| 걱정 | 화면크기·비트가 **우리 손을 벗어나 있다.** 기기가 좋을수록 파일이 커진다 — 상한이 없다 |

🔴 **아무것도 고치지 않았습니다.** 재기만 했습니다.
  두 벌 저장을 한 벌로 줄이는 것은 **규칙 10(원본을 지우지 않는다)** 에 걸리고 요금과 직결돼
  **대표님 확인 없이는 손대지 않습니다.**
