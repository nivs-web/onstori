## [53] `/{상호}/edit` 영상 메뉴를 **셋으로** (B-14)

```
전 : (내 영상) (SNS 연결)
후 : (내 영상) (영상 설정) (SNS 연결)
```

- **「영상 설정」**으로 옮긴 것: 숏폼 스타일 · 가두는 편수 · **늘어놓는 편수** · 재생 순서
- **「내 영상」**에는 이제 **목록과 [⚡ 한 방에 올리기]가 맨 위**에 온다 — 대표님 뜻 그대로다
- ⚠ **내용은 한 줄도 안 바꿨다. 자리만 옮겼다** — 뭔가 어긋나면 «옮기기»가 잘못된 것으로 바로 좁혀진다
- ⚠ 목록을 불러오는 «동안»에도 「영상 설정」에 들어갈 수 있다(`items === null` 검사 «위»에 뒀다)
- ⚠ **「이름 바꾸기」(B-15)는 아직 없다.** 만들면 이 탭에 들어온다

## [54] 「⋯」 — **삭제로 가는 길** (B-20)

> 대표님: 「**온스토리에 영상 삭제 버튼이 어디 있는지 못 찾겠다**」

**① 몰입모드 우측에 `⋯`** → 누르면 편집화면 **[내 영상]**(`#video-list`)으로 간다.
**② 삭제 확인 문구를 대표님 문장으로 바꿨다** (`lib/sns/copy.ts` 한 곳):

```
온스토리 홈페이지에서 삭제하시겠습니까?
(각각 연결된 SNS에서는 자동으로 삭제되지 않습니다. 각 SNS에 접속해 개별 삭제해 주세요)
```

⚠ 전 문장(「온스토리(홈페이지·영상 목록)에서 지웁니다 …」)은 **우리가 지은 말**이었다. 뜻은 같지만
  **지우는 일**이라 대표님 말씀 그대로 쓴다. 버튼 글자(「온스토리에서만 지우기」)는 그대로 뒀다.
⚠ 지우기는 지금대로 **`deleted_at` 표시만** 찍는다(`CLAUDE.md:246`). **파일은 안 지운다.**

### 🔴 「⋯」를 «누구에게» 보여 주나 — 이것은 권한 검사가 아니다

손님 홈페이지는 **캐시(ISR)** 라 서버가 「지금 보는 사람이 주인인가」를 모른다.
물어보러 가면 **손님 모두의 몰입모드가 느려진다.**
⇒ **브라우저 안의 흔적 둘**로만 짐작한다(네트워크 0): ①`onstori:anonId` ②`sb-…auth-token` 쿠키.
🔴 **틀려도 안전하다 — 실측으로 확인했다:** 흔적을 심어 두고 남의 사이트에서 눌러 보니
**편집화면이 서버에서 막고 `/login` 으로 보냈다.**

### ⚠ 실측으로 잡은 사고 하나 — `close()` 를 부르면 «이동이 안 된다»

`close()` 안에는 **`history.back()`** 이 있다(폰 뒤로가기로 닫히게 하려고 기록을 밀어 넣기 때문).
그 되돌아가기와 페이지 이동이 **경주를 해서 되돌아가기가 이긴다** — 눌러도 주소가 그대로였다.
⇒ **덮개만 접고(`onClose`) 곧바로 간다.** 되돌리지 마라.

## [55] 하루 5건 — **못 올리게 막는다** (B-5)

> 대표님: 「하루 영상 제한 5개라고 **여러 번** 말했는데 **못 올리게 막아**」

### 🔴 먼저 — 권반장 조사가 맞았다. **녹화·올리기에는 제한이 하나도 없었다**

```
있었음 : lib/sns/limits.ts  ← «SNS 에 내보내기»에만
없었음 : /api/story/upload-url · /api/story/submit  ← «찍어 올리는» 길
```

### 막는 자리 **둘** — 둘 다 있어야 한다

| 자리 | 무엇 | 왜 |
|---|---|---|
| `upload-url` | 올리기 **전**에 거절 | 여기서 안 막으면 **60초를 찍고 40MB 를 올린 «뒤»** 거절당한다 |
| `submit` | **마지막 관문** | 파일은 다른 길로도 올 수 있다. **줄을 만드는 자리**가 진짜 관문이다 |

### ⚠⚠ 「하루」가 **둘**이다 — 주석에 남겼다(`lib/story-quota.ts`)

| 어디 | 기준 | 왜 |
|---|---|---|
| **우리 녹화** | 🔴 **한국 시간 자정** | 사장님이 한국에 사신다. 「내일 다시」가 말이 되려면 한국 날짜여야 한다 |
| `lib/sns/limits.ts` | **UTC 자정**(한국 오전 9시) | 인스타·틱톡이 그렇게 센다. 우리가 못 바꾼다 |

⇒ **둘이 다른 것이 «맞다».** 오전 9시 전에는 「우리 한도는 남았는데 SNS 한도는 찼다」가 있을 수 있다.

### 화면 — **찍기 «전»에 알려 드린다** (권반장 부탁)

녹화 첫 화면에 **「오늘 1 / 5편」**, 다 쓰셨으면 **「오늘 몫을 다 쓰셨어요 — 내일 다시 찍어 주세요」**.

### ⚠ 못 세면 «막지 않는다»

옛 DB(마이그레이션 전)나 장애로 셀 수 없으면 `-1` 이고, 그때는 **막지도 않고 아무 말도 안 한다.**
셀 수 없는 것을 근거로 사장님을 멈춰 세우지 않는다.

| 「⋯」 | 흔적 있는 브라우저에만 보였고, 누르니 편집화면으로 갔고, **주인이 아니라 `/login` 으로 막혔다** ✅ |

## 무엇을 «못» 했나

1. 🔴 **편집화면을 눈으로 못 봤다** — `/{상호}/edit` 는 **로그인한 주인**만 들어간다.
   ⇒ **[53] 세 탭과 [54] 삭제 확인 문구는 배포 뒤 대표님이 한 번 보셔야** 한다.
   （운영자 열쇠로 들어가는 길이 있지만, **열쇠를 화면·기록에 적지 않는다**는 규칙을 지켰다）
2. **진짜로 5편을 찍어 6번째에서 막히는 것**은 못 해 봤다 — 한도를 1로 낮춰 **같은 길**을 확인했다.
3. **B-15(숏폼시네마 이름 바꾸기)** 는 아직 없다. [53] 의 「영상 설정」에 들어갈 자리만 생겼다.
