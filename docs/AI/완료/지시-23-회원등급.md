## 1. 대표님이 말씀하신 두 가지 — 둘 다 생겼습니다

> 「정회원으로 내가 누군가를 올려줬어. 근데 **무료회원으로 다시 바꾸는 게 없어.**
> 그리고 **정회원으로 올려주는 버튼도 만들어.** 내가 내 것을 유료로 할 수 없으니까
> **나는 설정 가능한 권한이 있어야지.**」

사이트 목록에서 **한 곳을 체크**하면 막대에 버튼 둘이 생깁니다.

| 누르면 | 무슨 일이 |
|---|---|
| **⬆ 정회원으로 올리기** | 이유를 한 줄 적고 누르면 **결제하신 분과 똑같이** 쓰실 수 있게 됩니다 |
| **⬇ 무료회원으로 내리기** | **어디로** 내릴지 고릅니다 — **무료회원(체험)** 또는 **폐쇄(손님에게 안 보임)** |

---

## 2. 🔴 시키신 여섯 가지 — 전부 «눌러서» 확인했습니다

| # | 시키신 것 | 한 것 | 실제 응답 |
|---|---|---|---|
| 1 | **이유를 반드시 받아라** | 두 글자 미만이면 **버튼이 잠깁니다**. 서버도 또 막습니다 | `400 왜 바꾸는지 한 줄만 적어 주세요 …` |
| 2 | **결제 정회원과 손으로 올린 정회원을 구분** | `settings.manual_grant` 를 남기고 🔴 **`paid_at` 은 비워 둡니다** | `{"by":"admin","at":"…","reason":"…","prev":"suspended"}` · `paid_at: null` |
| 3 | **내릴 때 어디로 내릴지 물어라** | **무료회원(체험)** / **폐쇄** 중에 고릅니다. 기본은 체험 | 화면 실측: `무료회원(체험) / 폐쇄(손님에게 안 보임)` |
| 4 | 🔴 **자동결제 걸린 분은 못 내리게** | `billing` 에 살아 있는 키가 있으면 **409 로 막습니다** | `409 이 사장님은 자동결제가 걸려 있습니다. 먼저 해지해야 합니다. (그냥 내리면 다음 달에 또 결제됩니다)` |
| 5 | **기록을 남겨라** | 서버 로그에 `grade_changed` | `{"evt":"grade_changed","who":"admin","when":"…","what":{"slug":…,"from":…,"to":…},"why":"…"}` |
| 6 | **한 번에 하나씩만** | 화면이 먼저 막고 서버가 또 막습니다 | `400 등급은 한 번에 한 곳만 바꿀 수 있어요.` |

### 🔴 2번을 «표»에서도 갈라 보이게 했습니다

시키신 것은 데이터에 표시를 남기는 것이었지만, **표에서 둘이 똑같아 보이면 소용이 없습니다.**
그래서 회원 칸을 이렇게 나눴습니다:

| 표에 뜨는 말 | 뜻 |
|---|---|
| **유료회원** (초록) | **돈이 실제로 들어왔습니다** (`paid_at` 이 찍혀 있음) |
| **정회원(손으로)** (검정) | 어드민에서 올린 것입니다. **매출로 잡히지 않습니다** |

⇒ 대표님이 표만 보셔도 **어느 쪽이 진짜 매출인지** 한눈에 보입니다.

## 3. 🔴🔴 테스트하다 잡은 버그 — **안 해 봤으면 그냥 나갔습니다**

대표님이 「작동되는지 테스트까지 꼭 해보라」고 하셔서 **진짜 크롬으로** 눌러 봤습니다.
[⬆ 정회원으로 올리기] 를 누르니 **엉뚱한 확인창**이 떴습니다:

```
1곳을 «다시 열기» 합니다.

폐쇄해도 자료는 지워지지 않고, 손님에게만 안 보입니다.
계속할까요?
```

**등급을 올리는데 「다시 열기」라고 묻고, 「폐쇄해도 자료는…」이라고 합니다.**
원인은 기존 코드의 확인창 조건이 `mode !== "event"` 한 줄이었던 것입니다 —
새로 만든 `grade` 가 **자동으로 그 그물에 걸렸습니다.**

**고친 뒤 실제로 뜨는 말(실측):**

```
「zz-gate-test-a」 을 정회원으로 올립니다.

결제 없이 올리는 것이라 매출로는 잡지 않습니다.
계속할까요?
```

```
「zz-gate-test-a」 을 무료회원(체험) 으로 내립니다.

계속할까요?
```

⚠ **이것이 「만들었습니다」와 「눌러 봤습니다」의 차이입니다.** 타입 검사·빌드는 이 버그를
   **하나도 못 잡습니다.** 문법은 완벽했습니다.

## 4. 실제로 돌린 시험 — **열여섯 가지**

🔴 **손님 사이트는 하나도 건드리지 않았습니다.** 제가 전에 만든 시험용 사이트
(`zz-gate-test-a` · 주인 없음 · 폐쇄 상태)에서만 했고, **끝나고 원래대로 돌려놨습니다.**

### 서버 쪽 (10건)

```
① 열쇠 없이 (로그인 안 한 사람)  → 401 unauthorized
② 두 곳을 한 번에                → 400 등급은 한 번에 한 곳만 바꿀 수 있어요
③ 이유를 안 적음                 → 400 왜 바꾸는지 한 줄만 적어 주세요
④ 엉뚱한 등급(vip)               → 400 어디로 바꿀지가 잘못됐어요
⑤ 없는 홈페이지                  → 404 그 홈페이지를 찾지 못했어요
⑥ 이미 그 등급                   → 400 이미 그 등급이에요 (suspended)
   → 여기까지 DB 가 바뀌었나 : 안 바뀜 ✅

⑦ 진짜로 정회원으로 올리기        → 200 {"from":"suspended","to":"active"}
   정회원이 됐나                 : 예
   🔴 돈 받은 것으로 안 잡혔나    : 예 (paid_at 비어 있음)
   왜 올렸는지 남았나            : {"by":"admin","at":…,"reason":"우리 회사 시험용 사이트","prev":"suspended"}

⑧ 🔴 자동결제가 살아 있는데 내리려 할 때
                                 → 409 이 사장님은 자동결제가 걸려 있습니다. 먼저 해지해야 합니다.
   막힌 뒤 DB                    : 그대로 active (안 내려감) ✅

⑨ 다시 무료회원으로 내리기        → 200 {"from":"active","to":"trial"}
   올렸던 기록이 지워졌나        : 아니오 — «언제 왜 내렸는지»가 덧붙었습니다 ✅
⑩ 폐쇄로 내리기                  → 200 {"from":"trial","to":"suspended"}  (원래 상태로 복구)
```

### 화면 쪽 (6건, 진짜 크롬)

```
① 한 곳을 체크하니 나온 버튼 : ⬆ 정회원으로 올리기 / ⬇ 무료회원으로 내리기
② 이유가 비면 버튼이 잠겨 있나 : 예
③ 이유를 적으니 잠금이 풀렸나  : 예
④ 확인창이 물어본 말          : 「zz-gate-test-a」 을 정회원으로 올립니다 / 결제 없이 … / 계속할까요?
⑤ 누른 뒤 화면이 한 말        : 등급을 바꿨습니다 (suspended → active). 새로고침하면 표에 반영됩니다.
⑥ 🔴 표에 다시 나온 그 줄      : 운영중·유료 | **정회원(손으로)** | —
   내린 뒤                    : 운영중·무료 체험 | 무료회원 | D-30
```

⚠ **⑧번 시험을 위해** `billing` 표에 시험용 행을 **한 줄 넣었다가 바로 지웠습니다.**
   · 상태를 `failed` 로 넣었습니다 — **크론이 카드를 긁는 것은 `active` 뿐**이라 긁힐 길이 없습니다
   · 청구 예정일도 **2099년**으로 두었습니다
   · 끝나고 지웠고 **`billing` 행 수 0건**을 다시 세어 확인했습니다
   🔴 **진짜 카드는 쓰지 않았고, 돈은 1원도 움직이지 않았습니다.**

## 5. 🔴 왜 «정회원으로 올려도» 매출이 안 흐려지나 — 쉬운 말로

| | 결제로 된 정회원 | 손으로 올린 정회원 |
|---|---|---|
| 손님·사장님 화면 | 똑같습니다 | 똑같습니다 |
| **`paid_at`(돈 들어온 날)** | **찍혀 있습니다** | 🔴 **비어 있습니다** |
| 어드민 표 | **유료회원**(초록) | **정회원(손으로)**(검정) |
| 왜 그렇게 됐는지 | 결제 기록 | `manual_grant` 에 **누가·언제·왜** |

⇒ 「이번 달 매출」을 셀 때 **`paid_at` 이 있는 것만 세면** 손으로 올린 분은 안 섞입니다.
⇒ 나중에 「이분 왜 정회원이죠?」에 **이유 한 줄로 답할 수 있습니다.**

## 6. 🔴 못 한 것 · 걱정거리

### ① `sample-interior` 가 이제 「정회원(손으로)」로 보입니다

우리 샘플 사이트는 예전부터 `active` 인데 **결제 기록이 없습니다.**
새 표시 규칙(「정회원인데 `paid_at` 이 비었다」)에 그대로 걸립니다.
**틀린 말은 아닙니다** — 돈을 받은 적이 없는 게 맞습니다. 다만 대표님이 보시고
「이게 왜 이러지?」 하실 수 있어 미리 적어 둡니다. ⚠ **동작은 아무것도 안 바뀝니다.**

### ② 「내려놓고 자동결제는 그대로」인 경우를 **사람이 못 만듭니다**

자동결제가 살아 있으면 막기는 하는데, **막힌 다음에 어디서 해지하는지**는
화면이 알려 주지 않습니다. 지금은 유료 고객이 0명이라 만날 일이 없어 두었습니다.
⚠ 첫 유료 고객이 생기기 전에 **해지 버튼으로 가는 길**을 붙이는 게 좋겠습니다.

### ③ 어드민 로그인은 **여전히 열쇠(ADMIN_KEY) 방식**입니다

「누가 올렸나」를 `who: "admin"` 으로만 적습니다. **사람 이름이 안 남습니다.**
열쇠를 아는 사람이 하나뿐이라 지금은 문제가 없지만, 사람이 늘면 못 가립니다.
(원래 `P7 운영자 인증 교체` 로 이월돼 있는 일입니다 — 이번 지시 범위 밖이라 안 건드렸습니다.)

### ④ **배포된 화면에서는 아직 안 눌러 봤습니다**

전부 **로컬**에서 확인했습니다. 어드민 열쇠가 로컬과 운영이 달라 배포 뒤 확인이 필요합니다.
⚠ 다만 이 기능은 **어드민 전용**이라 손님에게는 아무 영향이 없습니다.

### ⑤ 원래 있던 잔소리 2건은 **안 고쳤습니다**

`app/admin/sites/page.tsx:83`(`<a>` 대신 `<Link>`) · `slug-ui.tsx:29`(효과 안에서 상태 바꾸기).
**제 변경 전부터 있던 것**이고(따로 확인했습니다), 지시 범위 밖이라 그대로 뒀습니다.
