## ⓪ 먼저 — «짐작이 틀렸던 것» 둘을 숫자로 잡았다

### 가. 랜덤이 안 섞이는 진짜 이유 — 씨앗(`sessionStorage`)이 아니었다

운영 DB 를 읽었다(읽기만):

```
sample-interior   {"order":"newest","style":"cards","stageN":5}
rombu             {"stageN":7}
```

🔴 **`order` 가 「최근순」이다. 랜덤은 «켜진 적이 없다».**
안 섞인 것이 아니라 **섞으라는 설정이 저장돼 있지 않다.**
⚠ 지난 기록의 「`visitSeed()` 가 1 로 고정되는 것이 원인일 수 있다」는 **원인이 아니다.**
저장 창구(`app/api/site/shorts-style/route.ts`)와 화면 배선은 열어 봤고 멀쩡하다.
`style:cards`·`stageN:5` 가 **기본값이 아닌 값으로 저장돼 있으니 저장 자체는 된다.**
⇒ 대표님이 누르셨을 때 **실패 문구가 떴거나, 누른 뒤 되돌려진 것**이다. 대표님 확인이 필요하다.

### 나. 카드형태 좌우 이동 — `scrollIntoView` 가 **1px 도 안 움직였다**

```
card.scrollIntoView({inline:"center"})  →  레일 scrollLeft 0 → 0
rail.scrollTo({left:900})               →  레일 scrollLeft 0 → 1028 (스냅까지 맞춰 정상)
```

⇒ 못 움직이는 것이 아니라 **그 함수가 이 자리에서 아무 일도 안 한다.**

## ② 무엇을 «못» 했나

1. 🔴 **「소리가 두 번 난다」를 실기기 소리로 못 쟀다.** 시험용 브라우저는 소리를 내지 않고
   `preload="none"` 영상의 `play()` 를 거절한다. 막은 것은 **누르는 순간 레일의 모든 영상을
   손으로 음소거·정지**시키는 길이다(상태 변화는 한 박자 늦어서 그것만으로는 샌다).
2. **한 칸 이동(부드러운 스크롤)은 «숨은 창»에서 진행되지 않는다** — 그 자리에서는 못 쟀다.
   대신 **가야 할 자리의 셈**이 맞는 것을 확인했다(가운데 오차 0px).
3. **C-2(랜덤)는 «고치지 않았다».** 위 ⓪-가 때문이다 — 고칠 버그가 아직 안 보인다.
   대표님이 다시 눌러 보셔야 한다.
4. **B-21(랜덤 순서 기억) · B-11~B-20 은 손대지 않았다.** 이 배치가 아니다.

## ③ 걱정되는 점

- **무한 회전이 한 바퀴 넘어갈 때는 «즉시» 옮긴다**(부드럽게 하지 않는다). 20편을 부드럽게
  되감으면 몇 초 동안 휙 지나가 멀미가 난다. 대표님이 보시고 어색하면 되돌릴 수 있다.
