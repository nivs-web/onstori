## 2. 🔴 만들다가 찾은 것 — **가장 큰 가격 글자 둘이 빠질 뻔했습니다**

`COPY.priceLine` 한 줄만 고치고 화면을 받아 보니, 첫 페이지에 **옛 문장이 남아 있었습니다.**

`app/page.tsx` 의 **요금제 카드 제목 둘**(`:311` · `:533`)이 `priceLine` 을 안 쓰고
괄호를 **손으로 적고** 있었습니다 — 숫자를 크게 보여 주려고 나눠 놓은 자리였습니다:

```tsx
정회원 <span>{COPY.priceOnly}</span>
<span> ({BILLING_INTERVAL} 구독 요금제)</span>   ← 🔴 손으로 적은 괄호
```

⇒ **우리 홈페이지에서 가장 큰 가격 글자 둘**이 나머지와 말이 달라질 뻔했습니다.
권반장이 경고하신 그대로입니다 — 「한 곳만 고치면 화면끼리 말이 달라집니다.」

**고친 법 — 괄호를 한 곳에 모았습니다:**

```ts
// lib/trial.ts
const PRICE_SUFFIX = `(${BILLING_INTERVAL} 구독 요금제 · 부가세 포함)`;
COPY.priceLine   = `49,900원 ${PRICE_SUFFIX}`
COPY.priceSuffix = PRICE_SUFFIX            // ← 요금제 카드가 이것을 읽는다
```

⇒ 이제 **두 자리가 같은 값을 읽습니다.** 다음에 괄호를 고칠 때 또 어긋날 일이 없습니다.
(2026-09-06 의 「182곳 중 175곳이 어긋난」 사고가 바로 이 «손으로 적기» 때문이었습니다.)

## 3. 🔴🔴 **돈 냄새 — 여기서 멈추고 여쭙습니다**

**만료 예고 문자가 `priceLine` 을 씁니다**(`app/api/cron/expire/route.ts:40`).
그 한 줄이 길어지면서 **문자 요금 등급이 바뀝니다.**

| | 문자 길이 | 요금 등급 |
|---|---|---|
| 지금 | 69자 · **EUC-KR 87바이트** | **SMS** (90바이트 이하) |
| 바뀐 뒤 | 78자 · **EUC-KR 102바이트** | 🔴 **LMS** (90바이트 초과) |

**LMS 는 SMS 보다 건당 요금이 비쌉니다.** 예고 문자는 **한 사장님에게 3번**(7일·3일·1일 전) 갑니다.

### ⚠ 다만 — **지금 당장 나가는 돈은 «0원»입니다**

- 만료 예고 문자는 **꺼져 있습니다**(`expiryAlertOn: false` — 2026-09-15 대표님 결정으로 기본 꺼짐)
- 솔라피 잔액이 **약 190원**이라 켜도 나갈 수 없습니다

⇒ **그래서 코드는 손대지 않고 그대로 뒀습니다.** 문자 문구를 제가 마음대로 줄이면
   ①손님이 보는 글을 허락 없이 바꾸는 것이고 ②「금액만 쓰면 1회 결제로 읽힌다」는
   기존 경고(`lib/trial.ts` 주석)를 어기게 됩니다.

🔴 **대표님께 — 문자를 «켜시기 전에» 정해 주십시오** (`docs/WAITING.md` 에 올렸습니다):

| | 길 | 결과 |
|---|---|---|
| **가** | 그대로 둔다 | 예고 문자가 **LMS 요금**이 됩니다 (건당 더 비쌈) |
| **나** | 예고 문자에서만 괄호를 짧게 | SMS 요금 유지. 다만 **문자 문구가 바뀝니다**(대표님 허락 필요) |

⚠ **화면은 이미 바꿨습니다**(승인받은 부분). 문자만 남은 판단입니다.

## 4. 못 한 것 · 걱정거리

1. **약관(`/terms`)은 안 건드렸습니다.** 거기에 가격 표기가 있는지 확인은 했습니다 —
   `COPY.priceLine` 을 import 해 쓰고 있어 **저절로 함께 바뀌었습니다.** 약관 문장 자체는 무수정입니다.
2. **문자·알림톡 문구는 눈으로 못 봤습니다.** 지금 꺼져 있어 실제로 보낼 수 없습니다.
   길이는 위에서 **글자로 쟀습니다**(EUC-KR 기준 — 국내 문자 길이 계산 방식).
3. **간이과세자 관련 판단은 제가 하지 않았습니다.** 대표님이 토스에 물어 **「간이과세자도 상관없다」**는
   답을 받으셨다는 권반장 기록을 그대로 따랐습니다.
4. **배포는 안 했습니다.** `main` 커밋까지입니다.
