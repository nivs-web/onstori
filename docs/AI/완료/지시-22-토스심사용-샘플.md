## 1. 🔴 목적 달성 — **결제창이 열리는 것을 실측했습니다**

`/api/billing/checkout` 을 두 사이트에 각각 불러 봤습니다(실제 결제는 하지 않았습니다):

| 사이트 | 상태 | 응답 |
|---|---|---|
| **`sample-toss`** | `trial` | **`{ready: true, clientKey: 있음, orderId: "os-sample-toss-…", amount: 49900}`** ✅ |
| `sample-interior` | `active` | `{ready: false, alreadyPaid: true}` ← 「이미 정회원이에요」 **그대로** |

⇒ **심사관이 `sample-toss` 에서 [결제하기] 를 누르면 토스 결제창이 뜹니다.**
⇒ `sample-interior` 는 **전과 똑같이** 「이미 정회원」입니다 — 건드리지 않았습니다.

⚠ **로컬에는 토스 열쇠가 없어**, 이 확인은 **가짜 열쇠를 잠깐 넣고** 했습니다
(`checkout` 라우트는 그 값을 **토스로 보내지 않고 화면에 돌려주기만** 합니다 — 안전합니다).
확인 뒤 **즉시 지웠습니다**(확인함). 🔴 **운영에서는 대표님이 넣으신 진짜 열쇠로 돕니다.**

## 3. 검색·표시 — 실제 화면에서 확인한 값

```
① robots 태그      : noindex, nofollow        ← 🔴 검색에서 뺐습니다
② 「샘플 예시 사이트」 : 화면에 있습니다
③ 상호             : 하남 종합인테리어 (토스 심사용 예시)
④ 구조화 데이터     : 없음 (예시라 안 나갑니다)
⑤ 사이트맵         : sample-toss 없음 ✅ (sample-interior 도 없음 — 지시 [8] 대로)
⑥ sample-interior  : robots 태그 없음 = 색인 허용 «그대로» ✅
```

**목록을 둘로 나눴습니다** — 합치면 안 되는 것이라 `lib/sites.ts` 에 이유를 적어 뒀습니다:

| 목록 | 무엇을 정하나 | 들어 있는 것 |
|---|---|---|
| `SAMPLE_SLUGS` | 「예시인가」 → 예시 표시 · 사이트맵 제외 · 구조화 데이터 제외 | `sample-interior` · **`sample-toss`** |
| **`NOINDEX_SLUGS`**(새로 만듦) | 「검색에서 **지울** 것인가」 → `noindex` | **`sample-toss` 뿐** |

🔴 **`sample-interior` 를 `NOINDEX_SLUGS` 에 넣지 마십시오.** 그 화면은 유튜브·인스타 심사관이
검색으로도 찾아 볼 수 있어야 합니다(지시 [8] — 「사이트맵에서 빼기」와 「검색에서 지우기」는 다릅니다).

## 4. 만들다가 고친 것 — **한 화면에서 두 지역이 싸웠습니다**

처음에는 상호만 「다산 리모델링」 → 「하남 종합인테리어」로 바꿨는데, 화면을 찍어 보니 본문이
**「남양주에서 아파트 올수리만 합니다」** 였습니다. 상호는 하남인데 본문은 남양주 —
**심사관이 보면 지어낸 티가 납니다.** 지명까지 함께 바꿨습니다.

지금 히어로: 「20년 된 아파트, 다시 살고 싶은 집으로 — **하남에서** 아파트 올수리만 합니다.」
**「다산」·「남양주」는 화면에 한 글자도 안 남았습니다**(확인함).

## 6. 🔴 못 한 것 · 걱정거리

1. **진짜 토스 결제창을 눈으로 못 봤습니다.** 로컬에 토스 열쇠가 없어 «관문이 열리는 것»까지만
   확인했습니다(`ready: true` + 주문번호 발급). 🔴 **배포 뒤 심사 계정으로 한 번 눌러
   결제창이 실제로 뜨는지 봐 주셔야** 권반장이 캡처하실 수 있습니다.
2. 🔴 **30일 뒤에 이 사이트는 «정지»됩니다.** 무료 기간을 정상값으로 두라고 하셔서 그렇습니다.
   심사가 30일 안에 안 끝나면 **결제창이 다시 안 열립니다**(만료된 사이트는 `trial` 이 아닙니다).
   ⇒ 그때는 위 스크립트를 `--force` 로 한 번 더 돌리면 기간이 새로 30일이 됩니다. **적어 두십시오.**
3. **영상 섹션이 `sample-interior` 의 영상을 가리킵니다.** 파일을 복사하지 않고 주소만 같이
   왔습니다 — 같은 회사 파일이라 문제는 없지만, **두 사이트가 같은 영상을 보여 줍니다.**
   토스 심사는 결제만 보므로 그냥 뒀습니다. 걸리시면 말씀해 주십시오.
4. **이야기(스토리) 행은 복사하지 않았습니다.** 영상 13건이 딸려 오면 무거워지고,
   토스 심사에 필요 없습니다. 그래서 완성도가 **55점**입니다(원본은 65점).
5. **심사 계정으로 실제 로그인해 「사이트가 두 개 보이는지」 확인하지 못했습니다.**
   `owner_id` 가 같은 것은 DB 로 확인했습니다만, `/my` 화면이 여러 개를 어떻게 그리는지는
   **눈으로 안 봤습니다.** 🔴 한 개만 보이면 그 화면을 고쳐야 합니다 — 확인이 필요합니다.
6. **배포는 안 했습니다.** `main` 커밋까지입니다. **사이트 자체는 운영 DB 에 이미 있습니다** —
   배포 전에도 `onstori.com/sample-toss` 가 열립니다(운영이 같은 DB 를 봅니다).
   ⚠ 다만 **`noindex` 는 배포돼야 붙습니다.** 그 전까지는 검색에 열려 있습니다 —
   🔴 **되도록 빨리 배포해 주십시오.**
