## 1. 무엇을 했나

### ① `ShortsWorld` 를 `components/sections/shorts-world.tsx` 로

```
전 : components/sections/shorts-stage.tsx   621줄  (무대 + 몰입모드 한 파일)
후 : components/sections/shorts-stage.tsx   412줄  (무대)
     components/sections/shorts-world.tsx   233줄  (몰입모드) 🆕
```

**코드는 «옮기기만» 했습니다.** 한 줄도 다시 쓰지 않았습니다 — 잘라서 붙였습니다.
⚠ `default export` 로 바꾼 것 하나만 다릅니다(파일 밖에서 부르려면 필요합니다).

### ② 공유 상수는 `config/shorts.ts` 로 — **지시서와 다르게 했습니다. 이유를 적습니다**

지시서에는 **「딸려 갈 것: `SWIPE_PX`·`HINT_MS`」**라고 돼 있었습니다.
그런데 **그 둘을 «무대도» 씁니다**(`shorts-stage.tsx` 의 스와이프·힌트).

| | 무대 | 몰입모드 |
|---|---|---|
| `SWIPE_PX` | 쓴다(스와이프) | 쓴다(스와이프) |
| `HINT_MS` | 쓴다(「탭하면 소리」) | 쓴다(「↑↓로 넘길 수 있어요」) |

⇒ 몰입모드로 **딸려 보내면 무대가 몰입모드를 import** 하게 되어 **방향이 거꾸로** 됩니다.
⇒ 그래서 **`config/shorts.ts` 한 곳**에 뒀습니다. **두 파일에 각각 적으면 한쪽만 고쳐집니다** —
  🔴 `SHORTS_MAX` 가 **실제로 그렇게 두 곳에 박혀 있었습니다**([38]①).

### ③ 빌려 쓰던 CSS 이름을 갈랐습니다 (지시서 §1)

`.stage-pill`·`.stage-dot` → **`.world-pill`·`.world-dot`**
**값은 «글자까지 같은 사본»**입니다. 2단계에서 무대와 몰입모드가 **서로 다른 모양**이 될 때
`.stage-pill` 을 고쳐도 **몰입모드가 같이 안 바뀝니다.**

### ④ 덤 — **낡은 주석 한 줄을 바로잡았습니다**

`shorts-stage.tsx` 의 「⑤ … **`"use client"` 를 이 파일에만 둔다**」가 **이제 사실이 아닙니다**
(새 파일에도 필요합니다). 그대로 두면 **다음 창이 그 문장을 믿고 되돌립니다.**

## 2. 🔴 「화면 변화 0」을 **어떻게 쟀나**

### ① CSS 사본이 정말 같은가 — **속성 705개를 하나씩 비교**

브라우저에서 `.stage-pill` 과 `.world-pill` 을 각각 만들어 **계산된 값 전부**를 맞대 봤습니다.

```
알약 — 다른 속성 : 0 개          점 — 다른 속성 : 0 개          (검사한 속성 705개)
```

⇒ **글자 하나 다르지 않습니다.**

### ② 몰입모드가 전과 똑같이 도는가 (PC)

```
① 세상 열림              true              ⑥ ↓ 로 넘김        2 / 8
② 카운트                 1 / 8             ⑦ ↑ 로 되돌림      1 / 8
③ 도움말                 「↑ ↓ 또는 마우스 휠로 넘길 수 있어요」
④ 부품                   소리 ✅ · 나가기 「✕나가기」 · 화살표 2개 · 영상 1개 · 포털이 body 에 ✅
⑤ 초점                   열자마자 world-x 에 (키보드 손님)
⑧ 소리 끄기              🔇 · 영상 음소거 true
⑨ ESC 로 닫힘            ✅
```

### ③ 폰(375×812)에서도 (무대 상한을 잠깐 3으로 낮춰 8편짜리로 재현)

```
① 「전부 보기」 뜸 ✅       ② 열림 1 / 8       ③ 위로 쓸기 → 2 / 8
④ 아래로 400px → 1 / 8 · «안 닫힘» ✅   ← [42] 전에 없앤 규칙이 그대로 산다
나가는 길 넷 : ✕ ✅ · ESC ✅ · 바깥 클릭 ✅ · 폰 뒤로가기 ✅ (홈페이지도 안 떠남)
무대도 멀쩡 : 칸 3 · <video> 2 · 「1 / 3 · 전체 8」   ← 가상화가 안 깨졌다
```

⇒ **떼어내기 전에 재 뒀던 값과 «전부 같습니다».**

## 3. ⚠ 못 한 것 · 안 한 것

| 무엇 | 왜 |
|---|---|
| **2~5단계** | 🔴 **일부러 안 했습니다.** 권반장 지시 — 1단계를 따로 끝내고 보고 |
| **「영상 없는 사이트엔 JS 가 한 바이트도 안 간다」를 «운영에서» 못 쟀습니다** | 개발 서버는 청크 이름이 달라 **믿을 수 없습니다.** 확인한 것은 **영상 0편 사이트(`sample-toss`)에 무대·몰입모드가 «안 그려진다»**까지입니다 |
| **몰입모드를 «필요할 때만» 내려받게 하지 않았습니다** | `next/dynamic` 으로 미루면 **첫 화면이 가벼워집니다.** 다만 그건 **동작이 바뀌는 일**이라 「화면 변화 0」인 이번 단계에 넣지 않았습니다. **2단계 때 같이 볼 값어치가 있습니다** |
| **진짜 폰이 아닙니다** | 쓸어넘기기는 **코드로 만든 손가락**입니다 |
