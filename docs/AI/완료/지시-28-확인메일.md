## 1. 🔴🔴 실측 — **손님 주소로는 가입이 «막힙니다»**

조직 «밖» 주소(= 진짜 사장님 주소와 같은 처지)로 가입을 걸어 봤습니다:

```
응답: 500 {"code":500,"error_code":"unexpected_failure",
           "msg":"Error sending confirmation email"}
DB 에 계정이 생겼나: 아니오
```

⇒ **메일이 안 가는 정도가 아닙니다. 계정이 아예 안 만들어집니다.**
⇒ **오픈하면 이메일로 가입하시는 사장님은 «한 분도» 못 들어옵니다.**

### 왜 그런가 — Supabase 공식 문서 (2026-09-17 조회)

| | 기본 제공 메일 |
|---|---|
| 보낼 수 있는 양 | 🔴 **시간당 2통** |
| 받을 수 있는 사람 | 🔴 **우리 조직(팀) 구성원 주소만.** 그 밖은 「Email address not authorized」 |
| 보장 | **없음** — 「delivery·uptime SLA 없음, best-effort」 |
| 문서의 말 | 「**운영에는 자체 SMTP 를 쓰라**」 (탐색·시험용이라고 못 박음) |

⚠ 권반장이 걱정하신 「시간당 한도」보다 **훨씬 나쁩니다.** 한도 이전에 **받는 사람이 막혀 있습니다.**
⚠ 지금까지 몰랐던 이유: 우리끼리 시험할 때는 **회사 주소**를 썼고, 제 확인은
   **admin API 로 링크를 뽑아** 했기 때문입니다 — 그 길은 메일을 안 거칩니다.

## 2. ✅ 「아무 말 없이 멈추면 그것부터 고치라」 — 고쳤습니다

**주소는 멀쩡합니다.** 사장님은 자기 이메일을 몇 번이고 다시 치다가 떠나십니다.

### 고친 «뒤» — 실제로 눌러 확인한 화면


### 🔴 비밀번호 찾기도 **거짓말을 하고 있었습니다**

전에는 무슨 일이 있어도 「메일을 보냈어요」를 띄웠습니다 — **못 보냈을 때도** 그랬습니다.
사장님은 **오지 않는 메일을 영영 기다립니다.** 침묵보다 나쁩니다.
⇒ 우리 쪽 고장일 때만 갈라서 위 문구를 띄웁니다.

⚠ **「없는 주소」는 여전히 구별해 주지 않습니다.** 그때는 Supabase 가 200 을 주고 우리도
   「보냈어요」를 그대로 띄웁니다 — 계정 캐내기를 막기 위해서입니다. 갈라지는 것은 **우리 쪽 고장뿐**입니다.

## 3. 🔴 SMTP 비교표 — **붙이지 않았습니다. 대표님이 고르실 것입니다**

| | 무료로 얼마나 | 돈이 들면 | 붙이는 데 | ⚠ 걸림돌 |
|---|---|---|---|---|
| **지금(Supabase 기본)** | 🔴 **시간당 2통 · 조직 주소만** | — | 이미 붙어 있음 | **오픈 불가** |
| **Resend** ★추천 | **월 3,000통 · 하루 100통** | $20/월 → 5만 통 | SMTP 정보 4줄을 Supabase 에 넣으면 끝 | 보내는 도메인(onstori.com) **DNS 인증** 필요 |
| **AWS SES** | 신규 계정 6개월 크레딧 | **1,000통당 $0.10~0.16** (가장 쌈) | AWS 계정·도메인 인증 | ⚠ 처음에는 «시험 모드»라 **아무에게나 못 보냅니다.** 푸는 신청이 필요합니다(제가 확인 못 했습니다) |
| **SendGrid** | (확인 못 함) | (확인 못 함) | 비슷 | 최근 무료 정책이 자주 바뀝니다 — **확인 필요** |
| **솔라피** | — | — | — | ⚠ 우리가 쓰는 문자 업체입니다만 **이메일을 하는지 확인 못 했습니다** |

### ★ 제 추천 — **Resend 무료**

**이유 셋, 쉬운 말로:**

1. **돈이 0원입니다.** 월 3,000통이면 **하루 100분이 가입**하셔도 남습니다.
   지금 우리는 유료 고객 0명입니다 — **당분간 한 푼도 안 듭니다.**
2. **붙이는 것이 가장 쉽습니다.** Supabase 화면에 **주소·아이디·비밀번호 네 줄**을 넣으면 끝입니다.
   코드는 **한 줄도 안 바뀝니다.**
3. **나중에 커져도 그대로 갑니다.** 모자라면 월 $20 으로 5만 통이 됩니다. 옮길 필요가 없습니다.

⚠ **AWS SES 가 «장기적으로는» 제일 쌉니다**(1,000통에 $0.10~0.16). 다만 지금 규모에서는
   **Resend 무료가 0원**이라 이길 수 없고, SES 는 **시험 모드를 푸는 신청**이 한 단계 더 있습니다.
   **손님이 월 3,000통을 넘길 만큼 커지면 그때 SES 를 보시면 됩니다.**

🔴 **어느 것이든 «보내는 도메인 인증»(onstori.com 에 DNS 두어 줄)이 필요합니다.**
   그건 대표님이 Cloudflare 에서 넣으셔야 합니다 — 제가 못 합니다.
