## 1. 고친 뒤 실제로 어떤 문장이 나오는가 — 권반장이 물으신 것

`npm run dev` 를 띄우고 `/how-it-works` 를 **실제로 받아** 글자를 확인했습니다.

**고치기 전 (손님이 보던 것):**

> 상호명과 업종만 고르면 온스토리가 문구·사진·구조를 채워 onstori.com/name 을 만듭니다. **${COPY.trialShort}.**

**고친 뒤 (지금):**

> 상호명과 업종만 고르면 온스토리가 문구·사진·구조를 채워 onstori.com/name 을 만듭니다. **30일 전 기능 무료.**

```
코드 글자가 남아 있나: 없음
실제 문장: 상호명과 업종만 고르면 온스토리가 문구·사진·구조를 채워
          onstori.com/name 을 만듭니다. 30일 전 기능 무료.
```

⚠ 「30일」은 **제가 적은 숫자가 아닙니다.** `lib/trial.ts` 의 `TRIAL_DAYS` 가 들어간 것입니다
(`COPY.trialShort` = `` `${TRIAL_DAYS}일 전 기능 무료` ``). 규칙 9 그대로, 기간이 바뀌면 이 줄도 따라갑니다.
⇒ **이 고침은 오히려 「숫자의 단일 출처」를 원래대로 되돌린 것**입니다. 전에는 그 연결이 **끊겨 있었습니다.**

---

## 2. 왜 그 줄만 깨졌나

같은 배열의 **여섯 줄 중 그 한 줄만** 큰따옴표였습니다. 나머지 다섯은 치환할 것이 없어
큰따옴표든 백틱이든 상관없었고, 그래서 **눈으로는 티가 안 났습니다.**

```ts
["홈페이지가 먼저 생깁니다", "오늘 · 3분", "… 만듭니다. ${COPY.trialShort}."],   // 🔴 큰따옴표
["매주 질문이 문자로 옵니다", "주 1회 (원하면 매일)", "…"],                      // 치환할 것 없음
```

🔴 **타입 검사도 `npm run check` 도 이것을 못 잡습니다.** 문법으로는 완벽히 올바른 문자열이라
컴파일러가 의심할 이유가 없습니다. **사람이 화면을 보는 것 말고는 잡을 길이 없었습니다.**

경고 주석을 그 자리에 박아 두었습니다 — 「다른 줄에 따옴표를 쓸 때는 치환할 것이 없는지 먼저 본다」.

---

## 3. ★ 같은 병이 저장소에 또 있는지 **전부 찾아봤습니다** — 없습니다

`app` · `components` · `config` · `lib` 를 훑어 「따옴표 안의 `${...}`」를 전수 조사했습니다.
걸린 것 셋은 **전부 정상**이었습니다:

| 자리 | 판정 |
|---|---|
| `app/admin/sns/ui.tsx:92` · `:123` | ✅ JSX 입니다. `$` 는 **달러 기호**이고 `{...}` 는 JSX 표현식이라 「약 $12.34」로 제대로 나옵니다 |
| `lib/generate.ts:48` | ✅ **백틱 안**입니다. 큰따옴표는 AI 프롬프트에서 값을 감싸는 용도입니다 |

⇒ **`app/how-it-works/page.tsx` 그 한 줄이 저장소에서 유일했습니다.**

---

## 4. 못 한 것 · 걱정거리

1. 🔴 **이런 종류는 앞으로도 검사가 못 잡습니다.** 「따옴표 안에 `${` 가 있으면 실패」로 검사를
   만들면 위 세 정상 사례를 **거짓으로 잡습니다**(JSX 의 달러 기호·프롬프트 안의 따옴표).
   그 셋을 예외로 적어 두는 검사는 만들 수 있습니다만 **시키신 범위 밖이라 안 만들었습니다.**
   필요하다고 보시면 30분입니다.
2. **`/how-it-works` 말고 다른 화면은 눈으로 다 보지 못했습니다.** 위 전수 조사는 **`${` 라는 글자**를
   기준으로 한 것이라, 「깨져 보이는 다른 종류」(예: 줄바꿈이 안 먹은 곳)는 대상이 아니었습니다.
3. **배포는 안 했습니다.** `main` 커밋까지입니다. 손님 화면에 반영되려면 배포가 필요하고,
   그 화면은 **ISR 1시간**이라 배포 뒤에도 최대 한 시간 걸립니다.
4. ⚠ **이 고침은 「손님 글은 먼저 여쭙는다」 규칙의 예외로 진행했습니다.** 권반장 판단이었고,
   저도 같은 생각입니다 — `${COPY.trialShort}` 라는 글자가 일부러 쓰인 문장일 수는 없습니다.
   그래도 **결과 문장(「30일 전 기능 무료.」)은 위에 그대로 적어** 대표님이 보시게 했습니다.
