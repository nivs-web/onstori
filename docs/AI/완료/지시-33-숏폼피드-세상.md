## 1. 「통으로 하나의 세상」 — 만들었습니다

> **대표님:** 「pc에서도 **클릭 한번 하면, 틱톡이나 인스타 온 것처럼 전체화면으로 확 바뀌면서
> 숏폼 피드 속으로 들어간 것처럼** … 이 재생 창 자체를 **통으로 하나의 세상**으로 만든다면?
> 그러면 **7편이면 7편 전부** 소리가 나오게 할 수 있지 않을까?」

**실측 — 진짜 크롬으로:**

```
무대에서 보고 있던 편 : 3 / 7
① 클릭하면 세상이 열리나
   화면을 덮나        : true          body 에 붙었나 : BODY
   🔴 소리            : 🔊 켜짐        멈춰 있나      : false
   칸                 : 506×900       비율 : 0.563  (9/16 = 0.563)
   바깥 페이지 스크롤  : hidden
   도움말             : ← → 로 넘기고, ESC 로 나가요
   초점이 닫기 단추에  : world-x
```

### 🔴 「7편이면 7편 전부」 — 소리가 이어집니다

```
② → 키로 넘기면 : 4/7 🔊  →  5/7 🔊  →  6/7 🔊       ← 키 : 5/7
```

**한 번 들어오면 나갈 때까지 소리가 끊기지 않습니다.** 대표님이 말씀하신 그것입니다.

### 나가는 길 셋 — 전부 됩니다

```
③ ESC        : 나감 ✅   바깥 페이지 스크롤이 되돌아오나 : 예
   🔴 원래 자리로 : 3240 → 3240  (한 픽셀도 안 움직였습니다)
④ 바깥 클릭   : 나감 ✅
⑤ [✕]        : 나감 ✅
```

## 3. 🔴 눌러 보고 잡은 것 — **안 눌렀으면 그대로 나갔습니다**

### ① **어느 편을 눌러도 «항상 마지막 편»이 열렸습니다**

```
무대에서 보고 있던 편 : 3 / 7
그런데 열린 것        : 7 / 7     ← 🔴
```

무대는 일곱 편이 **겹쳐 쌓여** 있습니다. 그래서 클릭은 **DOM 의 마지막 편**이 받습니다.
제가 「눌린 편」을 쓰자 **어느 편을 눌러도 7/7** 이 열렸습니다.
⇒ 손님이 **보고 있던** 편은 언제나 `active` 입니다. 그것을 쓰도록 고쳤습니다.

### ② **검은 화면 «위»로 다른 것들이 비쳤습니다**

떠 있는 채널 공·상단 바가 반투명 검정 위로 **얼룩처럼** 비쳤습니다 — 「하나의 세상」이 깨집니다.
⇒ **통째로 검정**(반투명 아님) + **저장소에서 가장 높은 층**으로 올렸습니다.

```
검은 화면 위로 비치는 것 : 전부 world (개발 모드 표시 하나만 예외 — 운영에는 없습니다)
```

### ③ **도움말이 캡션과 겹쳤습니다**

「← → 로 넘기고, ESC 로 나가요」가 「이번 주 가장 바빴던 순간은요?」 위에 겹쳐 있었습니다. 올렸습니다.

**코드·주석에서 이 이름으로 부릅니다.** 전체화면은 **「숏폼피드 세상」**입니다.

⚠ 다만 **화면의 섹션 제목(「사장님 이야기」)은 안 바꿨습니다.** 그것은 **사장님이 자기 홈페이지에
넣은 글**이고, 손님이 보는 글은 먼저 여쭙는 것이 규칙입니다.
🔴 **「숏폼피드」로 바꿀까요?** — `docs/WAITING.md` 에 올렸습니다.

## 5. 🔴 못 한 것 · 걱정거리

### ① **진짜 PC·진짜 소리는 못 들어 봤습니다**

헤드리스 크롬은 **소리를 실제로 내지 않습니다.** 제가 확인한 것은
「**음소거가 풀렸고 재생 중이다**」까지입니다. **진짜 스피커에서 나는지는 대표님이 들어 보셔야** 합니다.
⚠ 특히 **사파리**는 자동재생·소리 정책이 크롬과 다릅니다.

### ② **전체화면은 «우리가 그린» 것**입니다 — 브라우저 전체화면(F11)이 아닙니다

주소창이 남아 있습니다. 진짜 전체화면(`requestFullscreen`)으로 하면 주소창까지 사라지지만,
**브라우저마다 허락 조건이 다르고 ESC 동작이 겹쳐** 나가는 길이 꼬입니다.
🔴 **원하시면 얹을 수 있습니다** — 지금은 안전한 쪽을 골랐습니다.

### ③ **태블릿은 «폰 쪽»으로 갑니다**

`마우스가 있는 기기`로 갈랐습니다(`hover: hover` + `pointer: fine`).
아이패드는 마우스가 없으므로 **폰과 같게** 동작합니다 — 대표님 「폰은 이대로 좋아」와 맞습니다.
⚠ 다만 **마우스를 연결한 아이패드**는 PC 쪽으로 갑니다. 그게 더 자연스럽다고 봤습니다.

### ④ **영상 사이를 넘길 때 «미리 받아 두지» 않습니다**

다음 편으로 넘기면 그때 받기 시작합니다. 느린 회선에서 **잠깐 검게 있을 수** 있습니다.
지금은 편수가 적어 티가 안 납니다만, 30편씩 걸리면 손볼 자리입니다.

### ⑤ **폰에서 「세상」을 열 길은 없습니다**

대표님이 「폰은 이대로 좋아」라고 하셔서 **일부러 안 만들었습니다.**
⚠ 폰에서도 전체화면으로 들어가고 싶으시면 말씀해 주십시오.
