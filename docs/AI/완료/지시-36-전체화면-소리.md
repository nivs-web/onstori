## 1. 🔴 제 실수였습니다 — **끄는 단추가 «0개»**

> 권반장님 조사: 「대표님이 지적하신 「스피커 2개」는 코드상 이미 1개로 고쳐져 있었고,
> **진짜 문제는 전체화면에 소리 «끄는» 단추가 «0개»인데 소리가 켜진 채 열린다**는 점입니다」

[33] 에서 **「클릭했으니 소리를 켜 준다」**까지는 맞았는데 **끄는 길을 안 만들었습니다.**
조용한 사무실에서 연 손님은 **소리를 못 끄고 허둥대다 그냥 나갑니다.**

**고친 뒤 실측:**

```
① 전체화면에 소리 끄는 단추가 있나 : {글:"🔊", 크기:"48×48", 영상 왼쪽 위에서:"16,16"}
   지금 소리 : 🔊
   🔴 누르니 : {소리:"꺼짐 ✅", 단추:"🔇"}
   한 번 더  : 다시 켜짐 ✅
```

★ 자리는 **영상 왼쪽 위 16px** — **유튜브 쇼츠와 같은 자리**입니다(조사 결과 그대로).

### 🔴 「스피커는 언제나 1개」 — **지켜집니다**

```
무대 스피커가 «실제로 보이나» : 그 자리에 있는 것 = world-video · 맨 위인가 = false
```

무대의 스피커는 **전체화면에 완전히 가려집니다**(그 좌표를 찍으면 전체화면 영상이 잡힙니다).
⇒ **손님 눈에 보이는 스피커는 언제나 하나**입니다.

## 2. 폰 「뒤로가기」로 닫힙니다

> 조사: 「지금은 뒤로가기를 누르면 **홈페이지 전체를 떠납니다.**
> 한국 안드로이드 손님이 **제일 먼저 누르는 단추**입니다」

```
⑤ 뒤로가기로 닫히나
   세상이 닫혔나 : true
   홈페이지에 그대로 있나 : true | 보던 자리 : 2160 → 2160

⑥ ✕ 로 닫으면 «뒤로가기 한 번»이 낭비되지 않나
   닫혔나 : true
   그 뒤 뒤로가기 : 홈페이지를 떠남 (정상 — 쓸데없는 기록이 안 쌓였습니다)
```

⚠ ✕·ESC·바깥클릭으로 닫을 때는 **밀어 넣은 기록을 스스로 치웁니다.**
안 그러면 손님의 뒤로가기 한 번이 **아무 일도 안 하는 데** 낭비됩니다.

## 3. 🔴 만들다 잡은 것 — **열자마자 닫혔습니다**

처음 만든 것은 **열리자마자 바로 닫혔습니다.** 원인:

> **React 는 개발 중에 화면 준비 동작을 «두 번» 돌립니다**(StrictMode).
> 제가 「정리할 때 뒤로가기를 부른다」고 짰더니, 그 두 번째 돌림에서 **스스로 닫아 버렸습니다.**

⇒ 기록은 **딱 한 번만** 밀어 넣고, 되돌리는 것은 **닫는 자리**에서 하도록 바꿨습니다.
★ 겸해서 **키·마우스 휠 처리를 전부 전체화면 안으로** 옮겼습니다 — 닫는 길이 **하나**가 되어야
기록이 어긋나지 않습니다.

⚠ **이것도 「눌러 보지 않으면」 절대 안 보이는 종류**입니다. `tsc`·`build` 는 통과했습니다.

## 4. ⌃⌄ 를 오른쪽 끝으로 · 안내 문구

```
③ 위 : 1360,388   아래 : 1360,456   (화면 폭 1440)
   캡션 : 483~957 , 842        캡션을 덮나 : false ✅
④ 안내 문구 : 「↑ ↓ 또는 마우스 휠로 넘기고, 오른쪽 위 ✕ 로 나가요」
```

⚠ 전에는 위·아래 **화면 한가운데**에 있어 **아래 ⌄ 가 캡션을 덮었습니다.**
★ 안내에 **나가는 «자리»**를 넣었습니다 — **마우스만 쓰는 손님은 ESC 를 모릅니다.**

### 🔴 나가기 ✕ 는 **안 옮겼습니다** — 조사 결과를 따릅니다

> 조사: 「**인스타 릴스가 2026년 3월부터 화면 «한가운데»에 ▶(재생)을 띄웁니다.**
> 그 자리에 ✕ 를 두면 **다시 보려고 가운데를 누른 손님을 내보내는 단추**가 됩니다」

대표님은 「가운데에 ［나가기 ✕］」를 원하셨지만 **오른쪽 위에 그대로 뒀습니다.**
대신 **나가는 길을 다섯**으로 늘렸습니다 — **✕ · ESC · 바깥클릭 · 뒤로가기 · 쓸어내리기.**

## 5. 덤 — 🔴 **약관 제11조가 «틀린 상수»를 읽고 있었습니다**

> 조사: 「`app/terms/page.tsx` 제11조가 **사장님 자료의 삭제 기한**을
> **손님 문의용 상수**(`INQUIRY_RETENTION_DAYS`)로 읽고 있습니다」

**맞습니다.** 그 줄은 「**자료가 파기됩니다**」 — **사장님 자료** 이야기인데
**손님 문의 보관 기간**을 읽고 있었습니다.

**지금은 둘 다 60이라 «우연히» 맞습니다.** 한쪽만 바꾸는 날 **약관이 거짓말을 합니다.**

⚠ 🔴 **바꾼 것은 «읽는 상수»뿐입니다. 화면에 나오는 글자는 한 글자도 안 바뀌었습니다** — 실측:

```
제11조 : … 정지된 날부터 60일이 지나면 자료가 파기됩니다. …
```

⇒ **법률 문구 변경이 아닙니다.**

## 6. 🔴 못 한 것 · 걱정거리

### ① **폰에서는 아직 「세상」이 안 열립니다**

뒤로가기·쓸어내리기는 **폰을 위한 것**인데, 지금 전체화면은 **마우스가 있는 기기에서만** 열립니다
(대표님 「폰은 이대로 좋아」). ⇒ **지금은 돌 일이 없습니다.**
★ 다만 조사 8-2 ④(「전부 보기 → 전체화면 무한스크롤」)가 되면 **폰에서도 열립니다** —
그때 바로 쓰이도록 **미리** 넣었습니다.

### ② **진짜 폰에서는 못 눌러 봤습니다**

뒤로가기·쓸어내리기 둘 다 **PC 크롬에 폰 탈을 씌워** 잰 것입니다.

### ③ **속도(8-2)는 아직 손도 안 댔습니다**

🔴 **21편째부터 영상이 사라지는 문제**가 그대로입니다. 다음 작업입니다.

### ④ **「세상」에서 캡션이 짧게 잘리지 않습니다**

긴 캡션이 화면을 많이 먹을 수 있습니다. 조사에 없던 항목이라 그대로 뒀습니다.
