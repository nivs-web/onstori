```

                     ↓
                  MediaRecorder  →  **언제나 720×1280 세로 mp4**
```

| 카카오톡 인앱 | 🔴 가로 | **세로** |

### 만드는 법 — 요점만

```ts
// 1) 캔버스는 세로로 «고정». 절대 바꾸지 않는다
const cv = document.createElement("canvas");
cv.width = 720; cv.height = 1280;
const ctx = cv.getContext("2d", { alpha: false })!;

// 2) 매 프레임 — 가운데를 9:16 으로 «잘라» 그린다 (찌그러뜨리지 않는다)
function draw() {
  const vw = vid.videoWidth, vh = vid.videoHeight;
  if (vw && vh) {
    const want = 720 / 1280;                 // 0.5625
    const have = vw / vh;
    let sx = 0, sy = 0, sw = vw, sh = vh;
    if (have > want) { sw = vh * want; sx = (vw - sw) / 2; }   // 가로가 넓다 → 좌우를 자른다
    else             { sh = vw / want; sy = (vh - sh) / 2; }   // 세로가 길다 → 위아래를 자른다
    ctx.drawImage(vid, sx, sy, sw, sh, 0, 0, 720, 1280);
  }
  raf = requestAnimationFrame(draw);
}

// 3) 캔버스 + 원래 오디오를 합쳐서 녹화한다
const out = cv.captureStream(30);
stream.getAudioTracks().forEach(t => out.addTrack(t));
const rec = new MediaRecorder(out, { mimeType: pickMime("video") });
```
