### 🔴🔴 **이 단계는 위젯이 아니라 «SEO 엔진»입니다 — 이것만은 꼭 읽으십시오**

제가 오늘 경쟁사 **홈ON(homon.co.kr)** 의 실제 HTML 을 받아서 뜯어봤습니다
(보고서: `fable51plandept/AI_Context/BANJANG/SEO-홈온-분석-2026-09-15.md`).

홈ON 고객 사이트가 **네이버 검색 상단에 뜨는 가장 큰 이유**가 이것이었습니다:

```json
"sameAs": [
  "https://blog.naver.com/sm790626/223828908359",
  "https://map.naver.com/p/entry/place/1709629900?..."
]
```

> **네이버는 그 가게를 플레이스로 «이미» 알고 있습니다.** 새 홈페이지를 처음부터 알아봐 달라고
> 조르는 것보다, **이미 아는 것에 붙는 것**이 압도적으로 빠릅니다.

**그래서 저장 위치를 못 박습니다:**

```
sites.settings.channels = { instagram: "https://…", naverPlace: "https://…", … }
```

★ **`lib/jsonld.ts` 가 이미 그 칸을 읽도록 제가 만들어 뒀습니다.** 클코님은 **채우기만** 하면
구조화 데이터의 `sameAs` 가 자동으로 나갑니다. **다른 이름으로 저장하지 마십시오.**
⚠ `https://` 로 시작하지 않는 값은 `jsonld.ts` 가 버립니다. **입력칸에서 먼저 잡아 주십시오.**
