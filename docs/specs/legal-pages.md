## 0. 왜 급한가

세 곳이 이 페이지를 **필수 입력값으로** 요구한다.

| 요구하는 곳 | 필요한 것 | 없으면 |
|---|---|---|

## 1. ★ 회장님 결정 3건 — 빈칸을 채워야 배포된다

이 번들의 페이지 초안에는 `⟪⟫` 로 표시한 **빈칸 5개**가 있다. 사실을 모르면 지어낼 수 없다(규칙 7).

| # | 빈칸 | 왜 필요한가 |
|---|---|---|
| **1** | **온스토리 운영 주체** — 상호 · 대표 · 사업자등록번호 · 주소 · 통신판매업 신고번호 | 기획1 작업표 13번이 "사업자등록·통신판매업 (사람) — 회장님"으로 남아 있다. **닙스(이안월드) 명의로 하실지, 온스토리를 새로 등록하실지** 알려주셔야 한다 |
| **2** | **개인정보 보호책임자** — 이름 · 직책 · 이메일 · 전화 | 법정 필수 기재 사항 |
| **3** | **보유·파기 기준** | 아래 §2 참조 — **E-4 정책과 충돌하는 지점이 있다** |

### ★ 3번을 먼저 정리해야 한다 — E-4 정책과의 충돌

⛔ **폐기됨(2026-09-06 최종 확정).** 현재 정책은 **정지 후 60일에 영구 삭제**(예고 30일 전·7일 전)다.
~~회장님이 확정하신 운영 정책은 "14일이 지나도 절대 삭제 금지(고객 정보이므로)" 다.~~
운영상 옳다 — 사장님이 나중에 결제하면 그대로 살려 드려야 하니까.

그런데 개인정보처리방침에는 **"언제까지 갖고 있다가 언제 지우는지"** 를 반드시 적어야 한다.
"영구 보관"이라고 쓸 수는 없다. 두 개를 모두 만족시키는 문장은 이것이다:

> ⚠ **2026-09-06 확정안으로 대체됨** — 아래 문안은 "보관합니다"에서 끝나 **D+28 자동 삭제를 알리지 않는다.**
> 실제로는 가입 후 28일에 자료가 삭제되므로, 개인정보처리방침·이용약관에 그 사실과 사전 통지를 반드시 적어야 한다.
>
> **"무료 기간이 끝나도 사장님 자료를 즉시 지우지 않고 비공개로 전환해 보관합니다.
> 사장님이 삭제를 요청하시면 지체 없이 파기하며, 마지막 접속일로부터 ⟪3년⟫이 지나면 자동 파기합니다."**

- 자동 파기 기한(⟪3년⟫)만 정해 주시면 된다. 흔한 기준은 **1년(휴면) / 3년 / 5년**이다.
- "삭제 요청 시 지체 없이 파기" 는 **법정 권리**라 뺄 수 없다.
  → **어드민에 삭제 버튼을 만들지 않는다**는 원칙은 유지하되(§4), **삭제 요청 처리 경로**는 있어야 한다.

## 2. 무엇을 수집하는지 — 코드에서 뽑은 실제 목록

**이 표가 이 작업의 핵심이다.** 처리방침에 없는 항목을 수집하면 그 자체가 위반이다.
아래는 저장소 실물에서 확인한 것이다 — 추정 없음.

### 2-1. 사장님(회원)에게서

| 항목 | 어디에 | 근거 |
|---|---|---|
| 이메일 | `auth.users` | 이메일 OTP 로그인 (`app/login`) |
| 카카오 계정 식별자 · 이메일 · 닉네임 | `auth.users` | 카카오 OIDC 직결 (`lib/kakao.ts`) |
| 상호명 · 업종 · 한 줄 소개 | `sites.business_name` · `industry` · `settings` | 온보딩 (`app/new/wizard.tsx`) |
| **전화번호** | `sites.settings.phone` · `quoteForm.phone` · `map.phone` | 온보딩 STEP 3 (필수) |
| **주소** | `sites.settings.address` | 온보딩 STEP 3 |
| 로고 · 사진 | Cloudflare R2 (`img.onstori.com`) | `api/site/logo` · `api/site/upload` |
| **60초 녹화 영상·음성 원본** | R2 (`story_entries.video_key`) | `/rec` (`api/story/upload-url`) |
| **음성에서 뽑은 글(자막)** | `story_entries.transcript` | 자막 워커 (STEP 4, 미구현) |
| 결제 정보 — 승인번호·주문번호·금액·결제수단 | `sites.payment` · `settings.last_payment` | `api/billing/confirm:37` |
| 익명 식별자 | `sites.anon_id` (브라우저 `localStorage: onstori:anonId`) | 로그인 전 사이트 생성 |
| 접속 IP | `rate_limits.key` (예: `gen:1.2.3.4`) | 레이트리밋 (`20260902100000`) |

⚠ **카드번호·CVC·생년월일은 온스토리가 받지 않는다.** 토스페이먼츠 결제창이 직접 받는다.
   처리방침에 이 문장을 넣어야 오해가 없다.

### 2-2. 손님(사장님의 고객)에게서 — ★ 사장님이 아니라 **제3자**의 정보다

| 항목 | 어디에 | 근거 |
|---|---|---|
| 이름 · 연락처 · 문의 내용 | `inquiries` | `api/inquiry/route.ts` |
| 사진 (최대 3장) | R2 | 견적 문의 폼 |
| **IP 해시** | `inquiries.ip_hash` | `sha256(ip + 날짜 + INQUIRY_SALT)` — **원 IP 는 저장하지 않는다** (`20260904020000:16`) |

⚠ 이 정보의 **주인은 손님**이고, **받는 사람은 사장님**이며, **온스토리는 처리를 대신하는 위치**다.
   처리방침에 이 관계를 명확히 적어야 한다. 이용약관에도 사장님의 의무로 넣는다(§3).

### 2-3. 국외로 나가는 것 — ★ 반드시 표로 적어야 한다

| 받는 곳 | 무엇을 | 어디로 | 왜 |
|---|---|---|---|
| Supabase | 계정 · 사이트 · 문의 데이터 | 국외 | 데이터베이스·인증·저장소 |
| Vercel | 접속 로그 | 국외 | 웹 호스팅 |
| Cloudflare (R2) | 사진 · 영상 파일 | 국외 | 이미지·영상 저장 (`img.onstori.com`) |
| Google Cloud (Vertex AI) | 상호명·업종·한 줄 소개 (문구 생성용) | 국외 | AI 문구·이미지 생성 |
| Resend | 이메일 주소 · 알림 내용 | 국외 | 문의 알림 이메일 |
| 솔라피 | 전화번호 · 문자 내용 | 국내 | 문의 알림 문자·녹화 링크 |
| 토스페이먼츠 | 결제 정보 | 국내 | 결제 처리 |
| 카카오 | 로그인 인증 | 국내 | 카카오 로그인 |
| 네이버 · 카카오 (지역검색 API) | 검색어(상호명) | 국내 | 온보딩 "플레이스에서 불러오기" |

⚠ **국외 이전은 별도 고지 항목**이다. 위 4곳(Supabase·Vercel·Cloudflare·Google·Resend)을 빠뜨리면 안 된다.
⚠ F 커밋 ③에서 **네이버 클라우드 플랫폼(지도)** 이 추가된다. 그때 이 표에 한 줄 더한다.

## 4. "삭제 버튼을 만들지 않는다"와 "삭제 요청 처리"를 어떻게 같이 두나

- **어드민의 [삭제] 버튼은 계속 만들지 않는다.** 실수로 누르면 되돌릴 수 없다.
- **삭제 요청 경로는 사람이 처리한다.** 방침에 이렇게 적는다:
  > "삭제를 원하시면 ⟪개인정보 보호책임자 이메일⟫로 요청해 주세요. 확인 후 지체 없이 파기하고 결과를 알려드립니다."
- 요청이 오면 운영자가 **`/admin/members` 의 메모에 요청일을 적고**, DB 에서 직접 파기한다.
  자동화는 하지 않는다 — 한 해에 몇 건 없고, 자동화하면 사고가 난다.

## 5. 초안의 성격 — 반드시 읽어 주세요

- 이 번들의 두 페이지는 **기술참모가 코드에서 사실을 뽑아 만든 초안**입니다.
  **저는 변호사가 아닙니다.** 결제 가맹 심사와 Meta 심사가 걸려 있으니
  **배포 전에 변호사 검토를 한 번 받으시길 권합니다.**
- 다만 **수집 항목·위탁처·국외 이전 표(§2)** 는 코드에서 직접 뽑은 사실이라,
  변호사가 검토할 때 가장 오래 걸리는 부분을 미리 끝내 둔 셈입니다.
- 빈칸 `⟪⟫` 5개를 채우기 전에는 **배포하지 마세요.** 빈칸이 남은 채 나가면 심사에서 반려됩니다.

## 6. 완료 조건

1. `npm run build` 성공 · ESLint 경고 0.
2. `onstori.com/privacy` · `onstori.com/terms` 가 열린다.
3. 두 페이지에 `⟪` 가 **한 글자도 없다** (`grep -c "⟪" app/privacy app/terms` → 0).
4. 푸터에서 두 페이지로 갈 수 있고, 옛 "개인정보 · 보안"(`/faq#privacy`) 링크는 없다.

6. `sitemap.xml` 에 두 주소가 있다.
7. `reserved_slugs` 에 `privacy` · `terms` 가 있다.
8. 모바일에서 글자가 읽히고 표가 가로로 스크롤된다(`overflow-x-auto`).
