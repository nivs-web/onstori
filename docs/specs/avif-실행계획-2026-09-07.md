## ★ 먼저 — 범위를 줄였다. 손댈 곳은 생각보다 적다

조사하다 보니 **고객 업로드 사진은 건드릴 필요가 없다.** 이유가 결정적이다:

> 손님 사이트 사진은 이미 **`next/image` 를 거친다**(`components/sections/index.tsx` 의 `Photo`).
> `next/image` 는 **브라우저의 `Accept` 헤더를 보고 AVIF/WebP 를 알아서 골라 내보낸다.**
> 즉 **원본이 WebP 여도 손님은 이미 AVIF 를 받고 있다.**

원본을 AVIF 로 바꿔도 손님이 받는 바이트는 **그대로**다. 바뀌는 건 R2 저장 용량과
origin 이 한 번 읽는 바이트뿐인데, 그 대가로 **에디터 미리보기(`<img>` 생짜)가
구형 기기에서 깨질 위험**을 진다. 남는 장사가 아니다.

| 대상 | 결정 | 이유 |
|---|---|---|
| `/api/site/upload` 손님 사진 | ❌ **WebP 유지** | next/image 가 이미 AVIF 로 내보낸다. 바꿔도 이득 0 |
| `/api/site/logo` 로고 | ❌ **WebP 유지** | 28px. 이득 몇 KB · 구형 폰에서 브랜드 마크 깨짐 |
| `/api/inquiry` 문의 사진 | ❌ **WebP 유지** | 비공개 · 사장님이 에디터에서 생짜 `<img>` 로 본다 |
| ★ **스크린샷 12장 (913KB)** | ✅ **여기가 전부다** | **생짜 `<img>` 로 원본 그대로 나간다. next/image 를 안 거친다** |
| 로컬 PNG 2개 | ✅ next/image 로 | `signature.png` · `on-mark-64.png`. 고정 크기라 안전 |
| 히어로 폰 80KB 폰-낭비 | ✅ 같이 | `<picture>` 를 어차피 넣으므로 |

**결론: (라)는 「스크린샷 파이프라인 하나」다.** 원래 생각한 전수 교체가 아니다.

## 1. 왜 스크린샷만 next/image 를 못 쓰나

`.tcard-shot` 은 `position:absolute; width:100%` 에 **높이가 자연 높이 그대로**다
(카드보다 길게 깔고 마우스를 올리면 위로 민다). 사이트마다 길이가 달라
**우리가 세로 크기를 모른다.** `next/image` 는 `width`/`height` 나 `fill` 을 요구하고,
틀린 비율을 주면 사진이 찌그러진다. `fill` 은 상자 크기로 강제해 미는 동작 자체를 없앤다.

→ **`<picture>` + `<source type="image/avif">` 가 유일하게 맞는 도구다.** 자연 높이가 보존된다.

## 5. 기존 12장 백필 — ⚠ **프로덕션 쓰기다. 회장님 승인 뒤**

이미 찍힌 12장에는 AVIF 트윈이 없다. 코드만 고치면 **아무 변화가 없다**(지뢰 3 때문에
`<source>` 를 안 내므로 안전하긴 하다 — 깨지지는 않고 그냥 지금 그대로다).

`scripts/avif-backfill.ts` 로 처리한다. **더하기만 하는 작업이라 되돌릴 수 있다:**

1. **먼저 백업** — `sites.settings` 를 파일로 덤프하고 **덤프가 실제로 읽히는지 확인**한다
2. R2 의 기존 WebP 를 내려받아 AVIF 로 인코딩 → **새 키로 업로드**(기존 파일은 손대지 않는다 · 규칙 10)
3. `settings.shots.pcAvif`·`phoneAvif` **키만 추가**. 기존 `pc`·`phone` 은 그대로 둔다
4. 되돌리려면 그 두 키만 지우면 끝. WebP 는 계속 살아 있다

⚠ 백필은 **이미 손실된 WebP 를 재인코딩**하는 것이라 새로 찍은 것보다 화질이 떨어진다.
사무실 PC 에서 `scripts/site-shots.ts` 를 다시 돌릴 수 있으면 **재촬영이 더 낫다.**

## 6. 검증 — 「캡처로 눈으로」보다 확실한 방법이 있다

회장님 조건: **390·768·1440 전 화면에서 사진이 빠짐없이 뜰 것.**
눈으로 훑으면 놓친다. **브라우저에게 직접 물어본다:**

```js
// 각 폭에서 이걸 돌린다. 결과가 [] 가 아니면 그 자리에서 멈춘다.
[...document.images]
  .filter(i => !i.complete || i.naturalWidth === 0)
  .map(i => i.currentSrc || i.src)
```

`naturalWidth === 0` 은 **「요소는 있는데 그림이 안 들어왔다」**는 뜻이다.
`<picture>` 가 없는 AVIF 를 물어 깨진 경우가 정확히 여기 걸린다.
⚠ lazy 사진이 있으니 **끝까지 스크롤한 뒤에** 재야 한다.

## 7. 착수 조건

**한 배치에 4~6번(코드) + 6장(검증)을 다 끝낼 수 있을 때만 시작한다.**
백필(5번)은 승인이 필요하므로 **코드와 분리해서** 나중에 돌려도 된다 —
지뢰 3 처리 덕분에 **코드만 먼저 나가도 화면은 지금과 똑같다.** 이게 안전판이다.

> 순서: **코드 + 검증 → (승인 뒤) 백필 또는 재촬영 → 다시 검증**
