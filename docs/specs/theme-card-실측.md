# [A-0] 아임웹 테마 카드 실측 (2026-09-07)

<https://imweb.me/theme> 을 크롬으로 열어 잰 값. **알아낸 건 "무엇으로 어떻게 움직이는가" 뿐이고
코드·이미지·문구는 가져오지 않았다** (CLAUDE.md 규칙 8).

| # | 물음 | 실측 |
|---|---|---|
| 1 | iframe 인가 이미지인가 | **이미지다.** iframe 0개. PC용 PNG **996×1620 (1,246KB)**, 폰용 PNG **330×642 (196KB)** |
| 2 | 움직임 방식 | **`transform: translateY`**. 사진을 카드보다 크게(`height: 130%`) 깔고 `object-fit: cover; object-position: center top` 으로 위를 맞춘 뒤, 30% 만큼 위로 민다. background-position 도 scroll 도 아니다 |

## 우리가 가져갈 것 / 다르게 할 것

**가져갈 것 — 기법 하나뿐이다.**
살아 있는 사이트를 iframe 으로 띄우지 않고, **미리 찍어둔 긴 스크린샷 한 장을
`overflow:hidden` 안에서 `transform: translateY` 로 민다.** 이래서 스크롤바도, 흰 여백도,
느려짐도 없다. 지금 우리 첫 페이지의 문제가 정확히 이것 때문이다.

**다르게 할 것 (회장님 [A-2] 지시가 아임웹보다 세밀하다):**
| | 아임웹 | 우리 |
|---|---|---|
| 이동 시간 | 0.8초 linear | **5~7초 ease-in-out** (사진 길이 비례) |
| 시작 지연 | 없음 | **150ms** (스쳐 지나갈 때 안 움직이게) |
| 되돌아오기 | 0.8초 | **절반(2.5~3.5초) ease-out** |
| 폰 등장 | 흐릿→선명만 | **80ms 늦게 + opacity·translateY 24px·scale 0.96 → 420ms** |
| 폰 테두리 | 2px / 12px 모서리 | **6~7px / 바깥 34px · 안쪽 27px(바깥−두께)** |
| 폰 그림자 | 없음 | **0 24px 48px rgba(26,39,34,.28)** |
| 사진 형식 | PNG 1.44MB | **webp/avif, 장당 80KB 이하** |
| 390px | 세로 격자 | **가로 밀어넘기기(다음 카드 1.4개 노출)** |

⚠ 아임웹은 PNG 1.44MB 를 그대로 쓴다. 우리는 80KB 이하로 간다 — 카드 8장이면
아임웹 방식은 11.5MB, 우리 방식은 0.64MB 다.
