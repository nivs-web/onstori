### ⚠ contrast.js 오탐 하나 — «이정표» 1.39:1

`/our-story` 의 «이정표» 를 흰 배경 위 연한 초록(1.39:1)이라고 신고하는데, **실제로는 아니다.**
직접 재 봤다:

```
글자색 rgb(168, 220, 198)   ← --green-200
섹션   surface-900 section reveal
섹션 배경 rgb(26, 39, 34)    ← 어두운 배경. 실제 대비 약 9.9:1
```

원인은 도구 쪽이었다 — `data-c` 표시를 스크롤 단계마다 지우지 않아 **지난 화면의 요소 좌표**를
갖다 쓰는 경우가 있었다. 지우도록 고쳤고(`scripts/contrast.js`), 대기 시간도 300→700ms 로 늘렸다.
그래도 1440 에서만 가끔 남는다. **화면 문제가 아니다** — 다음에 손볼 때 도구를 더 고친다.

### 이번에 고친 것 (검사 도구 자체)

| 도구 | 무엇 |
|---|---|
| `contrast.js` | `protocolTimeout` 30초→180초. **첫 페이지는 섹션 18개라 검사 자체가 중간에 끊기고 있었다** — 즉 지금까지 `/` 는 대비 검사를 못 받고 있었다 |
| `contrast.js` | 스크롤 단계마다 `data-c` 지우기 |
| `audit.js` | `.sr-only`(화면낭독기 전용) 제외 — 일부러 1px 로 감춘 것이라 잘림이 아니다 |
| `audit.js` | 제목 안에 자식 요소가 있으면 줄 수를 세지 않음 — `/faq` 의 «3녹화» 를 10줄로 오해했다 |

⚠ 세 도구는 이제 **임시 폴더가 아니라 `scripts/` 에 있다.** 전에는 세션이 끝나면 사라질 자리에 있었다.
