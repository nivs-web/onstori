## 검사 도구 — 「건너뜀」과 「통과」를 구분한다 ([E])

전에는 검사가 실패해도 조용히 넘어가 **"미달 0건"** 으로 보고했다. 첫 페이지가 실제로 그 상태였다.

이제 이렇게 나온다:

```
   390 | 봄 누를것  43·글 141 | ✅ 통과      ← 실제로 몇 개를 봤는지 나온다
   768 | ⏭ 건너뜀 — 잰 글자 0개              ← 통과가 아니다
── 검사함 6칸 / 건너뜀 0칸 (전체 6칸 = 주소 2 × 폭 3)
```

건너뛴 칸이 하나라도 있으면 **결과 맨 위에 경고 띠**가 뜨고, 종료 코드 2 로 끝난다.
