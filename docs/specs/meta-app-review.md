# Meta 앱 심사 신청 — 지금 시작하기 전에 막힌 것 하나

작성 2026-09-06 (기술참모) · 회장님 답변 "주소 입력 + 심사는 지금 신청"에 대한 실무 준비 메모
관련: 기획2 `meta-review`(planned·결정 대기) · `autopost`(planning·결정 대기)

---

## 1. 왜 지금 신청하나

기획2 `meta-review` 항목이 이유를 이미 적어 뒀다:

> "심사가 20일~6주(실무 6~8주)라 지금 신청하지 않으면 위젯·시연이 끝나고도 autopost 를 못 켠다.
> 오늘 신청하면 10월 말~11월 초 개통. **이것 하나만 늦어도 1순위 기능 전체가 밀린다.**"

C(SNS 위젯)는 주소 입력만 하므로 심사와 **무관하게** 진행된다. 두 갈래는 서로 기다리지 않는다.

---

## 2. ★ 먼저 막힌 것 — **개인정보처리방침 페이지가 없다**

Meta 앱 심사는 신청서에 **개인정보처리방침 URL** 과 **데이터 삭제 요청 URL** 을 필수로 받는다.
빈칸으로는 제출 버튼이 눌리지 않는다.

지금 온스토리에 있는 것:

- `components/site/chrome.tsx:93` 푸터 링크 "개인정보 · 보안" → `/faq#privacy`
- `config/faq.ts:46~50` — **FAQ 3문항**이 전부다
  ("영상 원본은 어디에 있나요?" / "로그인 방식은요?" / "손님 후기에 별점이 없는 이유는요?")

**FAQ 3줄은 개인정보처리방침이 아니다.** Meta 심사에서 반려된다.
(같은 서류를 **토스페이먼츠 가맹 심사**도 요구한다. 한 번 만들면 두 곳에 쓴다.)

### 필요한 것 — 별도 페이지 2개

| 페이지 | 주소(제안) | Meta 신청서 칸 |
|---|---|---|
| 개인정보처리방침 | `onstori.com/privacy` | Privacy Policy URL |
| 데이터 삭제 요청 안내 | `onstori.com/privacy#delete` | User Data Deletion |
| (같이) 이용약관 | `onstori.com/terms` | 심사 필수는 아니나 결제·가맹 심사에 필요 |

**이건 코드 작업이 아니라 문서 작업이다.** 회장님이 내용을 확정해 주시면
기술참모가 초안을 쓰고 클코팀장이 정적 페이지 2개로 올린다(반나절).

⚠ 지금 만드는 개인정보처리방침에는 **Meta 에서 받아올 항목**을 미리 넣어야 한다 —
인스타/쓰레드/페이스북 계정 식별자·페이지 접근 토큰·게시 이력. 나중에 고치면 심사를 다시 받는다.

---

## 3. Meta 가 요구하는 나머지 서류

기획2 `meta-review` 의 `needs` 3개 중 하나(개인정보처리방침)가 위에서 막혔고, 나머지 둘:

| 서류 | 상태 | 누가 |
|---|---|---|
| 사업자등록증 | 있음 (닙스 = 이안월드, 139-24-01865 — nivs.com 공개 정보 기준) | 회장님 |
| 개인정보처리방침 URL | **없음 — 위 2번** | 회장님 확정 → 기술참모 초안 → 클코팀장 배포 |
| 기능 시연 영상 | **없음** | 위젯·발행 화면이 나온 뒤에야 찍을 수 있다 |

⚠ **시연 영상이 두 번째 병목이다.** Meta 는 "심사원이 그대로 따라 할 수 있는 화면 녹화"를 요구한다.
지금은 발행 기능 자체가 없어 찍을 게 없다. 즉 **완전한 신청은 autopost 1차 구현 뒤**에나 가능하다.

→ **지금 할 수 있는 것은 여기까지다:**
   ① Meta 개발자 계정 + Business 타입 앱 **생성** ② **비즈니스 인증**(사업자등록증 — 이것만으로 며칠~2주)
   ③ 개인정보처리방침 페이지 올리기
   이 셋을 먼저 끝내 두면, 발행 기능이 나온 날 시연 영상만 붙여 바로 제출할 수 있다.

---

## 4. 통과한 뒤에도 남는 위험 — 기획2가 이미 적어 둔 것

> "통과 후에도 **연 1회 DPA(개인정보 보호 평가)와 Data Use Checkup** 이 오고,
> DPA 는 통보 후 **60일 안에** 완료하지 않으면(답이 모호해도) 플랫폼 접근을 잃는다
> — 그 순간 **전 고객의 SNS 자동 게시가 한꺼번에 멈춘다.**
> 알림은 **앱 관리자 이메일로만** 오므로 캘린더 등록 필수."

→ 앱 관리자 이메일을 회장님 개인 메일이 아니라 **여러 사람이 보는 주소**로 두시길 권합니다.

---

## 5. 회장님께 필요한 결정 2건

1. **개인정보처리방침·이용약관 초안을 기술참모가 써도 될까요?**
   (법무 검토 없이 쓰면 초안일 뿐입니다. 결제 가맹 심사까지 걸려 있어 변호사 검토를 한 번 받으시길 권합니다.)
2. **Meta 개발자 앱을 지금 만들까요?**
   앱 생성 + 비즈니스 인증만 먼저 돌리면, 발행 기능이 나오는 날 심사 대기 시간을 절반으로 줄일 수 있습니다.
   (클코팀장이 앱 등록, 회장님이 사업자등록증 업로드)

## 6. 이 메모의 위치

기획2 `meta-review` 항목의 `status` 에 **"개인정보처리방침 페이지 부재로 신청 불가 — 2026-09-06 확인"** 한 줄을 넣어야 합니다.
그 파일(`content/plandept/data.js`)은 저장소 안이라 코워크가 직접 쓰지 않습니다 — 클코팀장이 A/B 커밋에 함께 넣거나, 별도 한 줄 커밋으로 처리하시면 됩니다.
