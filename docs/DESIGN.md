# DESIGN.md — 온스토리 디자인 시스템 v5

확정 2026-09-07 (회장님 v5 지시서). **값의 단일 출처는 `app/globals.css` 의 `:root`** 다.
이 문서는 그 값들을 **왜 그렇게 쓰는지** 적은 규칙서다. 값을 여기에 복사해 적지 않는다 —
숫자가 필요하면 `globals.css` 를 보고, 코드에서는 토큰 이름으로만 쓴다.

## 0. v5 에서 바뀐 것 (v1 을 읽었던 사람용)

1. **명조(Noto Serif KR)를 완전히 폐기했다.** 글꼴은 **Pretendard 하나**다.
   제목은 서체가 아니라 **굵기와 자간**으로 낸다.
   이유: 화면당 서른 글자 남짓 쓰자고 한글 세리프 **405KB** 를 받고 있었다(Lighthouse 실측).
   빌드 산출물 `.next/static/media` 가 **6.4MB → 64KB** 로 줄었다.
2. **본문이 16px → 17px**, 행간 1.68, 자간 -0.015em.
3. **보조 버튼이 테두리에서 "면"으로 바뀌었다.** 테두리 버튼이 여럿이면 화면이 격자처럼 보인다.
4. **사진 카드에 호버를 넣었다.** v1 에서 뺐던 것을 v5 에서 규칙을 정해 되살렸다(§6).
5. 간격·모서리 값이 촘촘해졌다(`--s-2` 8→6, `--r-md` 12→10 등).
6. 섹션 모양을 **여덟 가지로 못 박았다**(§7).

## 1. 토큰 (globals.css `:root`)

| 갈래 | 토큰 | 쓰임 |
|---|---|---|
| 초록 | `--green-50` … `--green-900` | 브랜드. **`--green-700` 이 로고 ON 그린이자 주 버튼 색** |
| 중성 | `--n-0` … `--n-900` | 바탕·글자·테두리. 화면의 대부분 |
| 포인트 | `--accent` `--accent-soft` `--accent-ink` | 주황. **"남은 자리"·가격 강조에만** |
| 경고 | `--danger` `--danger-soft` | 오류·삭제·결제 실패 |
| 글꼴 | `--sans` | **하나뿐이다.** Pretendard Variable(자체 호스팅) |
| 글자 크기 | `--t-display` … `--t-caption` | clamp 로 폰↔PC 를 잇는다 |
| 굵기 | `--w-bold`(700) `--w-semi`(600) `--w-med`(500) `--w-reg`(400) | **이 넷 밖은 금지** |
| 자간 | `--ls-display` … `--ls-eyebrow` | 컴포넌트에 letter-spacing 을 적지 않는다 |
| 행간 | `--lh-display` `--lh-h1` `--lh-h2` `--lh-body` `--lh-lead` | |
| 간격 | `--s-1`(4) … `--s-10`(120) | 사이값을 만들지 않는다 |
| 모서리 | `--r-xs`(4) `--r-sm`(6) `--r-md`(10) `--r-lg`(16) `--r-full` | |
| 그림자 | `--shadow-1` `--shadow-2` `--hv-shadow` | 셋뿐 |
| 모션 | `--dur-1`…`--dur-4` · `--ease*` · `--hv-*` · `--enter-*` | MOTION.md |
| 레이아웃 | `--container` `--gutter` `--section-y` `--measure` `--control-h` `--btn-px` `--tap` `--bar-h` `--dock-h` | |

### Tailwind 유틸리티도 토큰이다

`@theme inline` 으로 등록해 뒀다 — `bg-n-50` · `text-green-700` · `border-danger` 가
곧 `var(--n-50)` 이다. **`neutral-500` · `teal-600` 같은 Tailwind 기본색은 쓰지 않는다.**

### 레거시 별칭

`--forest` `--lime` `--cream` `--muted` `--line` 등 옛 이름 수백 곳이 남아 있다.
전부 위 토큰을 가리키도록 값만 바꿨다. **새 코드에서는 쓰지 않는다.**

⚠ **`--accent` 는 의미가 바뀌었다.** 예전엔 초록, 지금은 **포인트 주황**이다.
⚠ **`--font-display` 는 이제 명조가 아니라 Pretendard 다.** `.font-display` 클래스도 마찬가지.

### 고객 사이트는 별개다

`app/[slug]` 는 사장님이 고른 팔레트를 `--s-bg` 등으로 인라인 주입한다. 그 스코프는
이 토큰 체계와 **무관**하다. 여기 규칙은 본사 화면(랜딩·메뉴·위저드·에디터·어드민)에 적용된다.

## 2. 색 — 비율이 규칙이다

| 몫 | 비율 | 무엇 |
|---|---|---|
| 중성 바탕 | **70%** | `--n-0` 흰색 · `--n-50` 연회색 · `--n-900` 어두운 섹션 |
| 글자 회색 | **20%** | `--n-700` 본문 · `--n-900` 제목 · `--n-500` 보조 |
| 초록 | **8%** | 주 버튼 · 링크 · 선택 상태 |
| 포인트 주황 | **2%** | **"남은 자리"·가격 강조에만.** 그 외 사용 금지 |

주황을 아이콘·배지·구분선에 뿌리기 시작하면 2%가 아니게 되고, 정작 가격이 눈에 안 띈다.

## 3. 글자 — 서체는 하나, 차이는 굵기로

- **글꼴은 Pretendard Variable 하나다.** 자체 호스팅(`app/fonts.css`, `ascent-override: 92%`).
- 굵기: **Display·H1 = 700 / H2·H3 = 600 / 라벨 = 500 / 본문 = 400.** 그 외 금지.
- 본문 **17px** · 행간 **1.68** · 자간 **-0.015em** · `word-break: keep-all`.
- ⚠ **한글은 라틴보다 행간이 필요하다. 제목 행간을 1.2 아래로 내리지 않는다.**
  (`--lh-h1` 1.36 · `--lh-h2` 1.4 · `--lh-display` 1.32)
- 본문 한 줄 최대 **38em**(`.measure`). 중앙 정렬 헤드는 **36em**(`.head-center`).
- 숫자는 `tabular-nums` — body 에 전역으로 걸었다.
- 클래스: `.t-display` `.t-h1` `.t-h2` `.t-h3` `.t-lead` `.t-body` `.t-small` `.t-caption` `.kicker`.

**본문 글자는 어디서도 17px 미만으로 내려가지 않는다.** 보조 정보는 `--t-small`(15) 까지,
캡션·법적 고지만 `--t-caption`(13).

## 4. 버튼

- **주 버튼(초록 면)은 뷰포트당 1개.** 두 개가 같이 보이면 손님은 무엇을 눌러야 할지 모른다.
- 높이 **52** (모바일 48) · **17px/600** · 좌우 패딩 **20** · 모서리 `--r-md`.
- **터치 목표 최소 48×48.** 아이콘 버튼도 예외 없다.

```
.btn .btn-primary     초록 면 · 흰 글자      hover --green-500   — 뷰포트당 1개
.btn .btn-secondary   연회색 면 --n-100      hover --n-200       — 그 외 전부
.btn .btn-text        글자만                                     — 부수적 행동
.btn .btn-danger      --danger 면                                — 삭제·해지
어두운 배경 위 보조 = 흰 면 14% + 흰 글자 (.surface-900 .btn-secondary)
```

⚠ **보조 버튼은 테두리가 아니라 면이다.** 테두리 버튼이 여럿 있으면 화면이 격자처럼 보인다.

## 5. 카드와 사진

- 카드: 배경 `--n-0` · 테두리 1px `--n-200` · 모서리 `--r-lg` · **기본 그림자 없음**.
- **사진에 테두리·여백을 두지 않는다.** 사진이 주인공이다.
- **사진 카드는 4:3 고정**(`.photo`). 비율을 고정해야 로딩 중 화면이 안 튄다(CLS).

---

## 6. 호버 — 사진이 있는 모든 곳

```
.card-photo          → 카드는 8px 떠오르고(300ms) 그림자가 생기며 테두리가 사라진다
.card-photo img      → 사진만 1.08 배로 커진다 (400ms)
```

**왜 사진만 커지나** — 카드를 키우면 옆 카드를 밀어 레이아웃이 통째로 흔들린다.
카드는 **위로 뜨기만** 하고, 확대는 사진에만 건다. 부모에 `overflow: hidden` 이 필수다.
카드 300ms / 사진 400ms 로 **시간을 다르게 준다** — 같으면 움직임이 납작하다.

**적용**: 실적·포트폴리오·갤러리·블로그 카드, 좌우 교대 사진, 전폭 사진(1.04로 약하게).
**미적용**: 히어로 · 로고 · 아이콘.

**폰에서는 호버를 흉내 내지 않는다.** `@media (hover: hover)` 로 감쌌고,
손가락 화면에서는 `:active` 에 `scale(0.98)` 120ms 만 준다.

## 7. 섹션 — 여덟 가지만

| # | 모양 | 클래스 |
|---|---|---|
| ① | 히어로 | (페이지별) |
| ② | 중앙 정렬 헤드 (최대 36em) | `.head-center` |
| ③ | 좌우 교대 (둘째 줄부터 반전) | `.alt-row` |
| ④ | 카드 격자 (3열 → 모바일 1열) | `.reveal-stagger` + grid |
| ⑤ | 단계 흐름 (번호 원) | `.step-num` |
| ⑥ | 어두운 강조 띠 (흰 글자 · 가격 크게 · 흰 버튼) | `.surface-900` |
| ⑦ | 전폭 사진 (21:9 + 그라데이션 캡션) | `.wide-photo` |
| ⑧ | FAQ 아코디언 (+/−) | `details.faq` + `.plusminus` |

**이 밖의 모양은 만들지 않는다.**

- 배경은 **흰(`.surface-0`) / 연회색(`.surface-50`) / 어두운(`.surface-900`)** 셋을 번갈아.
  **같은 배경 연속 금지** — 경계가 사라져 한 덩어리로 보인다.
- 섹션 세로 여백 **모바일 64 / PC 120** (`.section`).
- 컨테이너 **1200**, 좌우 여백 **모바일 20 / PC 32** (`.wrap`).

## 8. 입력창 · 배지 · 표

- 입력창 높이 **52** · 모서리 `--r-md` · focus 시 `--green-500` 2px + `--green-100` 4px 링.
  placeholder 를 라벨 대신 쓰지 않는다 — 입력하면 사라진다.
- 배지: 알약(`--r-full`) **13px/600** (`.chip`).
- 표: 폰에서 화면을 옆으로 밀면 안 된다. `.table-scroll` 로 감싼다 —
  표는 자기 안에서 스크롤하고 **첫 열은 고정**된다.

### 문서화된 예외 5가지

1. **라벨이 감싼 체크박스** — 네모는 24px 이지만 누르는 자리는 `<label>`(높이 48)이다.
2. **손님 사이트 푸터의 숨은 에디터 진입로** — 손님에겐 그냥 글자로 보여야 한다.
3. **남의 브랜드 색** — 카카오 노랑 `#FEE500` · 채널 아이콘 6종(유튜브·인스타·쓰레드·X·네이버).
   토큰은 온스토리 화면의 색을 정하는 것이지 남의 로고 색을 정하는 게 아니다.
4. **PWA 매니페스트**(`app/manifest.ts`) — JSON 이라 CSS 변수를 쓸 수 없다.
5. **자동 생성 로고 SVG**(`app/new/wizard.tsx`) — 사장님 파일로 저장되는 그림이다.
   보는 사람 컴퓨터의 글꼴로 그려지므로 var() 를 넣을 수 없다.
