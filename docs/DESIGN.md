## 1. 토큰 (globals.css `:root`)

| 갈래 | 토큰 | 쓰임 |
|---|---|---|
| 초록 | `--green-50` … `--green-900` | 브랜드. **`--green-700` 이 로고 ON 그린이자 주 버튼 색** |
| 중성 | `--n-0` … `--n-900` | 바탕·글자·테두리. 화면의 대부분 |
| 포인트 | `--accent` `--accent-soft` `--accent-ink` | 주황. **"남은 자리"·가격 강조에만** |
| 경고 | `--danger` `--danger-soft` | 오류·삭제·결제 실패 |
| 글자 크기 | `--t-display` `--t-h1` `--t-h2` `--t-h3` `--t-lead` `--t-body` `--t-small` `--t-caption` | clamp 로 폰↔PC 를 잇는다 |
| 간격 | `--s-1`(4) … `--s-10`(128) | 4의 배수. 사이값을 만들지 않는다 |
| 모서리 | `--r-sm` `--r-md` `--r-lg` `--r-full` | |
| 그림자 | `--shadow-1` `--shadow-2` | 두 개뿐 |
| 모션 | `--dur-1`…`--dur-4` · `--ease` `--ease-in` `--ease-spring` | MOTION.md |
| 레이아웃 | `--container` `--gutter` `--section-y` `--measure` `--control-h` `--field-h` `--tap` `--bar-h` `--dock-h` | |

### 레거시 별칭에 대하여

`--forest` `--lime` `--cream` `--muted` `--line` 등 옛 이름 수백 곳이 남아 있다.
전부 **위 토큰을 가리키도록 값만 바꿨다.** 이름만 남은 통로이니 **새 코드에서는 쓰지 않는다.**

⚠ **`--accent` 는 의미가 바뀌었다.** 예전엔 초록이었고 지금은 **포인트 주황**이다.
초록이 필요하면 `--green-700` 을 쓴다.

### 고객 사이트는 별개다

`app/[slug]` 는 사장님이 고른 팔레트를 `--s-*` 로 인라인 주입한다. 그 스코프는
이 토큰 체계와 **무관**하다. 여기 규칙은 본사 화면(랜딩·메뉴·위저드·에디터·어드민)에 적용된다.

## 2. 색 — 비율이 규칙이다

| 몫 | 비율 | 무엇 |
|---|---|---|
| 중성 바탕 | **70%** | `--n-0` 흰색 · `--n-50` 연회색 · `--n-900` 어두운 섹션 |
| 글자 회색 | **20%** | `--n-700` 본문 · `--n-900` 제목 · `--n-500` 보조 |
| 초록 | **8%** | 주 버튼 · 링크 · 선택 상태 |
| 포인트 주황 | **2%** | **"남은 자리"·가격 강조에만.** 그 외 사용 금지 |

주황을 아이콘·배지·구분선에 뿌리기 시작하면 2%가 아니게 되고, 정작 가격이 눈에 안 띈다.

## 3. 글자

- **Display · H1 · H2** — Noto Serif KR 600. 자간 H1 `-0.03em`, H2 `-0.025em`.
- **H3 이하 · 본문 · UI** — Pretendard Variable (자체 호스팅, `ascent-override: 92%`).
  라틴 메트릭을 그대로 두면 한글 행간이 뜬다. 값은 `app/fonts.css`.
- 본문 16px / 행간 1.75 / 자간 -0.02em / `word-break: keep-all`.
- 숫자는 `tabular-nums` — 가격·건수·D-day 가 흔들리지 않게. body 에 전역으로 걸었다.
- **본문 한 줄 최대 폭 38em** (`.measure`). 넘으면 눈이 줄을 놓친다.
- 클래스: `.t-display` `.t-h1` `.t-h2` `.t-h3` `.t-lead` `.t-body` `.t-small` `.t-caption`.

**본문 글자는 어디서도 16px 미만으로 내려가지 않는다.** 보조 정보는 `--t-small`(14) 까지,
캡션·법적 고지만 `--t-caption`(12).

---

## 4. 버튼

- **주 버튼(초록 배경)은 뷰포트당 1개.** 두 개가 같이 보이면 손님은 무엇을 눌러야 할지 모른다.
  나머지는 테두리만 있는 보조 버튼(`.btn-secondary`)이나 글자 버튼(`.btn-text`).
- 높이 **52** (모바일 48) · 모서리 `--r-md` · 글자 16px 600.
- **터치 목표 최소 48×48.** 아이콘 버튼도 예외 없다 — 보이는 원이 작아도 눌리는 영역은 48이다.
- 눌림은 `translateY(1px)` 120ms (MOTION ③).

```
.btn .btn-primary     초록 배경 · 흰 글자   — 뷰포트당 1개
.btn .btn-secondary   흰 배경 · 테두리      — 그 외 전부
.btn .btn-text        글자만                — 부수적 행동
```

레거시 `.btn-lime`(주) `.btn-ghost`(보조) `.btn-forest`(어두운)는 같은 규격으로 맞춰 뒀다.

---

## 5. 카드와 사진

- 카드: 배경 `--n-0` · 테두리 1px `--n-200` · **그림자 없음**. hover 에만 `--shadow-1`.
- **사진에 테두리·여백을 두지 않는다.** 사진이 주인공이다.
- **사진 카드는 4:3 고정** (`.photo`). 비율을 고정해야 로딩 중 화면이 안 튄다(CLS).

---

## 6. 섹션

- 배경은 **흰(`--n-0`) / 연회색(`--n-50`) / 어두운(`--n-900`, 흰 글자)** 3종을 번갈아 쓴다.
  **같은 배경 연속 금지** — 경계가 사라져 한 덩어리로 보인다.
  클래스: `.surface-0` `.surface-50` `.surface-900`.
- 세로 여백 **모바일 64 / PC 128** (`.section`).
- 컨테이너 **1200px**, 좌우 여백 **모바일 20~24 / PC 32** (`.wrap`).

---

## 7. 입력창

- 높이 **48** · 모서리 `--r-md` · 테두리 `--n-300`.
- focus: 테두리 `--green-500` 2px + 바깥 `--green-100` 4px 링 (`.field:focus`).
- placeholder 는 `--n-400`. **placeholder 를 라벨 대신 쓰지 않는다** — 입력하면 사라진다.

## 8. 표

폰에서 표가 화면을 옆으로 밀면 안 된다. `.table-scroll` 로 감싼다 —
표는 자기 안에서 가로 스크롤하고 **첫 열은 고정**된다. 어드민 회원 목록이 이 경우다.

## 10. 48×48 규칙의 문서화된 예외 2가지

1. **라벨이 감싼 체크박스** — 네모 자체는 24px 이지만 누르는 자리는 `<label>`(높이 48)이다.
   체크박스를 48px 로 키우면 화면이 이상해지고, 실제 터치 목표는 이미 48이다.
2. **손님 사이트 푸터의 숨은 에디터 진입로** (`app/[slug]/page.tsx`) — 상호명 글자에
   `/edit` 링크가 숨어 있다. 손님에게는 그냥 글자로 보여야 하므로 48px 줄로 만들지 않는다.
   손님용 조작 장치가 아니라 사장님만 아는 문이다.
